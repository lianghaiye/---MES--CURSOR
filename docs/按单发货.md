# 按单发货：需求与实施方案

本期只改**销售发货链路**。领料、外协发料、采购退货仍走全局先进先出。

## 1. 背景与问题

现网出库规则是全仓「先进先出 + 整批/余料优先」。销售审核只做**数量级软占用**，成品入库虽会生成条码/批次，但批次上**没有销售单所有权**。申请发货不选批，确认出库时可能扣到别单按单生产的库存。

## 2. 目标

从销售订单排产到成品入库生成的批次/条码，发货时必须精确匹配到**本单库存**，不得用全局 FIFO 抢走他单按单货。

## 3. 库存分类

- **按单库存**：成品/半成品入库时打上 `salesOrderId` / `salesOrderNo` / `salesLineId` / `workOrderNo` 的在库批次（一物一码含件码）。
- **自由备货**：未打销售单的在库批次（含本单超产切开的部分、MTS 备货、采购入库未挂销售单的货）。

按单库存只能发给对应销售单；自由备货继续 FIFO，可供「优先现货 / 仅现货」使用。

## 4. 与库存履约的关系

| 履约方式         | 审核后                           | 生产入库                           | 发货扣批                                                                |
| ---------------- | -------------------------------- | ---------------------------------- | ----------------------------------------------------------------------- |
| **优先现货**     | 先软占用自由备货数量；缺口进排产 | 按单入库批次挂本单；超产进自由备货 | **先扣本单按单批次**，缺口再扣自由备货 FIFO；**禁止跨单扣他单按单批次** |
| **强制按单生产** | 不吃自由备货，全量排产           | 同上                               | **必须本单按单批次**；批次不足 **禁止提交发货**                         |
| **仅现货**       | 只吃自由备货；不足则审核失败     | 本身不生成按单排产，通常无本单批次 | 走自由备货 FIFO                                                         |

## 5. 超量排产 / 超量入库

切分点在**确认入库**，不卡死排产。

**「未满足按单数量」：**  
`还差 = max(0, 订货数量 − 本行已按单入库累计)`（已按单入库累计含仍在库 + 已发给本单）。

本次入库先补「还差」→ 打本单；补完仍有多的 → 不挂销售单，进自由备货。

同编码多行：按销售明细顺序依次填满各行「还差」，仍有多余进自由备货。采购入库等类型不强制挂销售单。

## 6. 入库（成品 / 半成品）

1. 表头销售订单必填（可从工单带出）。
2. 明细写入 `salesOrderNo`、`salesLineId`。
3. 确认入库自动切开：预览「本单入库 x / 自由备货 y」。
4. 入库详情批次 Tab 展示销售单号。

## 7. 库存查询：两层交互

- **台账汇总**（默认）：仓库 + 物料；现存量、软占用、可用、按单在库。
- **批次明细**：行内「查看批次」抽屉；或「按批次查询」入口（销售单号/批次号）。

## 8. 发货与出库

- 申请发货时预分配本单批次，写入出库单 `batchAllocations`。
- 确认出库只扣预锁批；销售出库禁止全仓 FIFO。
- 本期散件、发运附件仍 FIFO。
- 跨单调拨须同时转移批次所有权。

## 9. 验收要点

- 台账与批次两层不混排。
- 强制按单：A 单批次不能被 B 单 FIFO 发走；不足禁止提交发货。
- 订 10 入 13：10 打本单、3 自由备货。
- 领料出库仍 FIFO。

## 10. 演示种子

刷新后（批次 seed v17 / 销售单 DATA_VERSION 10）自动注入：

| 项       | 值                                    |
| -------- | ------------------------------------- |
| 销售单   | `1-20260819-DED`（强制按单，订货 10） |
| 按单批次 | `B-260819-D10` ×10 @ 成品仓           |
| 自由备货 | `B-260819-F03` ×3 @ 成品仓（超产）    |
| 物料     | `CP-DEDICATED-DEMO-01`                |

验收路径：库存台账看按单在库 → 按批次查询筛该销售单 → 申请发货应锁到 `B-260819-D10`；他单不可扣该批。
