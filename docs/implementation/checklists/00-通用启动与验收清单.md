# 00｜通用启动与验收清单

适用于所有场景。分场景清单见 S1～S5。

## 启动

- [ ] 四维诊断已做（组织 / 职能需求 / 数据 / 信息化认知）
- [ ] 场景编码已书面确认（一～五），范围外模块已砍掉
- [ ] 项目对接人、兼职岗位表已列出
- [ ] 《计薪口径确认表》已签（凡含工资的场景）
- [ ] 试点车间/班组/产品范围已定
- [ ] 账号与角色映射已定（一人多岗已合并）

## 配置（通用）

- [ ] 组织、人员、角色已建
- [ ] 功能参数：工资推送模式已设
- [ ] 小程序入口与人员已开通
- [ ] （场景二及以上，对内）库存相关参数与仓管权限已配，**对外材料未写「扣减卖点」**

## 验收（通用）

- [ ] 试点范围内关键用户能独立完成主路径操作
- [ ] 与原有Excel/台账完成一次对账说明
- [ ] 明确「本期不做」清单双方签字
- [ ] 扩场景建议已口头/书面告知客户
