# 场景一｜快速报工 + 工资核算

**一句话**：工人手机报工，主任审核，计件/计时工资算得出。

## 适合谁（四维速判）

| 维度       | 信号                                            |
| ---------- | ----------------------------------------------- |
| 组织       | 有主任/班组长能审即可；仓管采购质检可不进系统   |
| 职能需求   | 先要解决产量与工资扯皮，暂不强求库存/采购系统化 |
| 数据       | 能整理产品、工序、工价                          |
| 信息化认知 | 工人愿用手机报一次数；弱则小范围试点            |

## 优势

- 1～2 周可见闭环
- 主数据门槛低
- 一人多岗友好
- 为后续场景打底座

## 重点调研 → 功能

报工与审核人 → 快速报工 + 工序报工审核  
计薪公式与不良 → 工时配置 + 计薪口径表  
推送时机 → 工资推送模式 + 工资核算

## 分步路径

口径签字 → 主数据（试点产品）→ 配置 → 试运行 3～5 天 → 与原工资对账 → 验收

## 话术

「先不谈上全部系统。就一件事：工人手机报工，月底工资有据可查。」

## 下一步

数据/认知提升后 → 场景二（加领料入库）或场景三（改任务报工）。
