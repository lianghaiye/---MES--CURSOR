# 场景三｜任务报工 + 工资核算 + 领料 + 成品入库

**一句话**：有工单有任务再报工，产量、物料、工资挂在任务上。

## 适合谁（四维速判）

| 维度       | 信号                           |
| ---------- | ------------------------------ |
| 组织       | 主任/计划能下发任务；仓管配合  |
| 职能需求   | 要过程可追溯，不只快速记一笔   |
| 数据       | 工艺路线稳定，工序与工价可匹配 |
| 信息化认知 | 接受「先有任务再报工」         |

## 优势

- 过程可控、交期更好管
- 计薪匹配更准
- 上承一/二，下接场景四

## 重点调研 → 功能

工单谁开、如何派到人 → 生产工单 + 小程序待领/今日待报工  
是否并存快速报工 → 业务规则「生产模式」  
领料/入库是否绑单 → 领料多模式 + 成品入库

## 分步路径

主数据 → 生产模式 → 主任下发培训 → 工人领任务报工 → 仓管领料入库 → 全流程样例验收

## 话术

「已经在派工，就用任务报工：每笔产量挂在任务上，交期和工资都更好管。」

## 下一步

接单后要拆计划/采购 → 场景四；有出厂检硬要求 → 场景五。
