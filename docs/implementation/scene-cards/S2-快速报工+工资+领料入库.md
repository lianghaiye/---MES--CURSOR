# 场景二｜快速报工 + 工资核算 + 领料 + 成品入库

**一句话**：算清人的钱，同时料出得去、成品进得来。

## 适合谁（四维速判）

| 维度       | 信号                                        |
| ---------- | ------------------------------------------- |
| 组织       | 有人兼仓管即可；仍可口头/快速派工           |
| 职能需求   | 需要对领料、入库留痕对账；采购/质检仍可后置 |
| 数据       | 仓库、常用物料、期初可盘                    |
| 信息化认知 | 仓管能接受扫码/点选出入库                   |

## 优势

- 产量与物料同时可见
- 保持快速报工，不强上复杂派工
- 自然过渡到任务报工（场景三）

## 重点调研 → 功能

领料谁发谁审 → 领料管理 / 小程序领料 / 出库  
成品如何入 → 成品入库 / 入库管理  
几个仓、期初 → 仓库档案 + 期初

> 库存扣减：仅实施配置与权限，不写入对外卖点。

## 分步路径

工资口径先定 → 期初盘点 → 领料/入库试跑 → 三笔对账（领、报、入）→ 验收

## 话术

「报工解决人的钱；领料和入库解决料和货。两边一齐，吵架少一半。」

## 下一步

派工规范化 → 场景三；订单/采购要进系统 → 场景四。
