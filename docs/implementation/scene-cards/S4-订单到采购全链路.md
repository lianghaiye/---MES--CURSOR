# 场景四｜销售订单 → 采购闭环

**全称**：销售订单 + BOM 设计 + 计划排产 + 生产管理 + 任务报工 + 工资核算 + 库存管理 + 采购管理

**一句话**：从接单到设计、计划、生产、库存、采购一条链。

## 适合谁（四维速判）

| 维度       | 信号                                                     |
| ---------- | -------------------------------------------------------- |
| 组织       | 销售/技术/计划/生产/仓管/采购职责能分清（可兼职）        |
| 职能需求   | 接单后要能说清：何时交货、差哪些料、哪天开工、该采购什么 |
| 数据       | 客户、物料、BOM（或可设计）、供应商基础可用              |
| 信息化认知 | 关键用户能接受订单驱动下游；忌主数据极差硬上             |

## 优势

- 一张订单牵出下游，减少三头不通气
- BOM/设计有落点
- 计划可连工单与采购
- 车间复用场景三能力

## 重点调研 → 功能

订单评审与非标 → 销售订单 + 设计任务/EBOM + 产品 BOM  
如何排产 → 生产计划  
自制外购拆分 → 采购申请/订单 + 供应商  
车间闭环 → 工单、任务报工、工资、出入库

## 分步路径

四维诊断与主数据差距 → 车间最小试点（若未上）→ 主数据月 → 订单到工单样例 → 采购入库样例 → 制度（插单/改BOM）→ 验收

## 话术

「接单之后自动问清楚：设计好了没、料齐了没、谁在干、货进仓了没。」
