# 场景五｜场景四 + 质量管理

**全称**：销售订单 + BOM 设计 + 计划排产 + 生产管理 + 任务报工 + 工资核算 + 库存管理 + 采购管理 + 质量管理

**一句话**：订单到采购跑通后，出厂质检与报废可留痕、可回放。

## 适合谁（四维速判）

| 维度       | 信号                                     |
| ---------- | ---------------------------------------- |
| 组织       | 有质检员（可兼职）                       |
| 职能需求   | 客户/行业要检验记录，或不良争议影响回款  |
| 数据       | 场景四底座已有或同步建设；检验项可模板化 |
| 信息化认知 | 质检愿按模板勾选，不靠纯口头放行         |

## 优势

- 出厂有记录、客诉能回放
- 与生产一体，不另起一套表
- 在场景四上叠加，不推倒重来

## 重点调研 → 功能

出厂检项与放行人 → 质检模板 + 出厂质检 + 小程序质检任务  
不良与计薪 → 不良品项 + 计薪口径  
报废与补料 → 报废品管理  
是否独立质检工单 → 质检工单

## 分步路径

场景四样例稳定 → 1～2 个产品质检模板 → 角色与小程序 → 出厂检+报废试点 → 与报工不良对齐 → 验收

## 话术

「质量不是为了看起来正规，是为了出厂有记录、客诉能回放。建议生产和订单先跑顺再加模板。」
