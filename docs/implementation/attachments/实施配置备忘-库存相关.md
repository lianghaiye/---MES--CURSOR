# 附件｜实施配置备忘（库存相关，仅内部）

> **不对客户散发。** 对外场景二/三/四只讲领料、成品入库、库存管理；扣减是系统算账手段。

## 配置检查

| #   | 项                                                 | 结果 |
| --- | -------------------------------------------------- | ---- |
| 1   | 功能参数「库存扣减方式」已选                       |      |
| 2   | 领料/成品入库自动审核参数已按企业习惯设置          |      |
| 3   | 仓管或管理员角色已授权扣减记录等相关菜单           |      |
| 4   | 试点单据已完成预扣→确认（若适用）                  |      |
| 5   | 对外 PPT/合同/手册未将「库存扣减」列为独立卖点场景 |      |

## 客户问到时的口径

「按你们选的领料/报工习惯，系统保证库存账和现场一致；具体扣账在后台按约定规则完成，你们日常只要把领料和入库做对。」
