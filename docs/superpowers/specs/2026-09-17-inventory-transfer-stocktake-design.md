# 库存调拨与盘点模块设计

**日期：** 2026-09-17  
**仓库：** i-doms-web  
**状态：** 两段式调拨已对齐（2026-09-17）

## 1. 背景与目标

库存管理已具备出入库主从列表、确认入账与三层库存台账（汇总 / 批次 / 件码），类型枚举中已有「调拨出库/入库」「盘点出库/入库」。销售侧「跨单库存调拨」只改软占用与批次销售归属，**不换仓**，与本模块无关。

**目标：** 独立「调拨管理」「盘点管理」；调拨采用 **出库方确认 +（可选）入库方签收** 两段流程；盘点确认时按差异生成盘盈入库/盘亏出库。

## 2. 已确认决策

| 项           | 选择                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| 产品形态     | 独立单据模块                                                             |
| 调拨流程     | 两段：出库方确认 →（可配置）入库方签收                                   |
| 入库签收配置 | **全局开关**；关则自动入库并完结；开则待入库出现在调入仓列表             |
| 调拨单操作   | **不做**行级/列表「部分确认」按钮；**无拒绝**，改为 **作废**（仅待确认） |
| 部分确认状态 | **保留**：由调拨入库单部分入库/部分拒绝驱动                              |
| 在途库存     | **仍挂调出仓**，软锁定不可再调/再出                                      |
| 按单在库     | **不改**销售归属；**批次号复用**，调拨迁仓不改批次号                     |
| 入库拒绝     | **红冲**关联调拨出库（对应明细），解锁软锁                               |
| 权限         | 出库确认 / 入库签收分权限；演示数据不做权限拦截                          |
| 盘点         | 本期不动两段式；仍按原盘点规则                                           |
| 列表 UI      | 仅表格；样式对齐出库管理                                                 |

## 3. 调拨状态机

| 状态         | 含义                                               |
| ------------ | -------------------------------------------------- |
| 待确认       | 已保存，出库方未确认                               |
| 待入库方确认 | 出库方已确认；需签收且入库尚未开始                 |
| 部分确认     | 调拨入库进行中（仍有待入库明细）                   |
| 已完成       | 入库侧全部落定：全部签收，或 **部分签收+部分拒绝** |
| 已拒绝       | 入库侧 **全部拒绝**                                |
| 已作废       | 出库方在待确认时作废                               |

### 入库明细 → 调拨单头

| 调拨入库明细结果                    | 调拨单状态   |
| ----------------------------------- | ------------ |
| 全部已入库                          | 已完成       |
| 全部已拒绝                          | 已拒绝       |
| 部分已入库 + 部分已拒绝（无待入库） | 已完成       |
| 仍有待入库，且已有入账或拒绝        | 部分确认     |
| 全部待入库（刚生成）                | 待入库方确认 |

## 4. 调拨流程

1. 新建/编辑 → **保存**（待确认）或 **保存并确认**（直接走出库确认）。
2. **出库方确认**（整单）：生成调拨出库（业务凭证）+ **软锁**调出仓数量；按配置：
   - **无需签收**：自动调拨入库入账（批次迁至调入仓、同批次号）→ 已完成；
   - **需要签收**：生成调拨入库（待入库）→ 待入库方确认。
3. 入库方在待入库/入库管理中签收或拒绝（可部分）。
4. **作废**：仅 **待确认**；无库存影响。
5. 删除：仅新增来源且待确认（未软锁）可删。

### 软锁与批次

- 软锁期间：数量仍计在调出仓账面，但可用量扣除软锁，不可再出库/再调拨占用。
- 签收：释放软锁，**原批次改 warehouse=调入仓**，保留 batchNo / salesOrder\*。
- 拒绝：释放软锁，关联出库明细/单据 **红冲（作废）**。

## 5. 列表字段

调拨数量展示：**已签收数量 / 全部数量**（已签收=入库已入账行数量合计）。

## 6. 盘点管理

仍按原设计：确认时按差异生成盘盈入库/盘亏出库；本期不改两段式。
