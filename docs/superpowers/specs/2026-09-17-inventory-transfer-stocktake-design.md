# 库存调拨与盘点模块设计

**日期：** 2026-09-17  
**仓库：** i-doms-web  
**状态：** 已开工实施（2026-09-17）

## 1. 背景与目标

库存管理已具备出入库主从列表、确认入账与三层库存台账（汇总 / 批次 / 件码），类型枚举中已有「调拨出库/入库」「盘点出库/入库」，但缺少独立业务单据与菜单。最接近仓间调拨的现成能力是「领料出库 + 领入仓自动入库」。销售侧「跨单库存调拨」只改软占用与批次销售归属，**不换仓**，与本模块无关。

**目标：** 在库存管理下新增独立「调拨管理」「盘点管理」，交互与状态机对齐出入库；确认时编排生成标准出入库单并入账，保证流水与库存真相源一致。

## 2. 已确认决策

| 项         | 选择                                                                  |
| ---------- | --------------------------------------------------------------------- |
| 产品形态   | 独立单据模块（非仅强化出入库类型）                                    |
| 调拨入账   | 一单调拨 + 确认时自动生成并入账「调拨出库 + 调拨入库」                |
| 盘点入账   | 确认时按差异自动生成「盘点入库」（盘盈）/「盘点出库」（盘亏）         |
| 盘点起单   | 按仓库起单，勾选物品/批次带入账面，可删行                             |
| 状态与操作 | 对齐出入库：待确认 / 部分确认 / 已确认 / 已拒绝；支持按明细确认、拒绝 |
| 列表 UI    | **仅表格**，不做卡片/左右分栏视图                                     |
| 实现路径   | 编排单 + 复用现有出入库入账链路                                       |

## 3. 信息架构

挂在 **库存管理** 侧栏，建议顺序：

1. 库存明细
2. 待出库列表
3. 出库管理
4. 待入库列表
5. 入库管理
6. **调拨管理** `/inventory/transfer`（详情 `/inventory/transfer/:id`，编辑 `/inventory/transfer/:id/edit`）
7. **盘点管理** `/inventory/stocktake`（详情/编辑同构）
8. 出入库详情及其他现有项

一期不单独做「待调拨 / 待盘点」菜单，用状态筛选即可。

每个模块提供：表格列表、新增/编辑、详情、确认/拒绝/删除；打印二期。

## 4. 调拨管理

### 4.1 单据头

| 字段                | 说明                                               |
| ------------------- | -------------------------------------------------- |
| 调拨单号            | 自动生成，新建时可改                               |
| 状态                | 待确认 / 部分确认 / 已确认 / 已拒绝                |
| 调出仓库 / 调入仓库 | 必填且不能相同                                     |
| 调拨日期            | 默认当天                                           |
| 申请人              | 默认当前用户                                       |
| 来源                | 默认「新增」（`manual`）；后续业务驱动可标「业务」 |
| 备注                | 可选                                               |
| 联动单据            | 确认后记录关联调拨出库/入库单号                    |

### 4.2 明细行

| 字段                      | 说明                                     |
| ------------------------- | ---------------------------------------- |
| 物品编码/名称、规格、单位 | 从库存选择带入                           |
| 调出仓库库存（账面）      | 选品时展示，只读                         |
| 调拨数量                  | 必填，>0；受可调量与负库存仓规则约束     |
| 批次/件码                 | 有批次时按出库规则拣选；确认时迁到调入仓 |
| 行状态                    | 待确认 / 已确认 / 已拒绝                 |
| 货位                      | 一期可选展示，不进入库存键               |

### 4.3 按单在库与软占用

| 类型     | 处理                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------- |
| 自由备货 | 默认可调；扣调出仓、调入仓建同等批次；**不改**软占用                                                        |
| 按单在库 | **不默认带入**；可显式勾选该仓该批；调后 **销售单归属不变**（只换仓库）。禁止借仓间调拨把 A 单批次改成 B 单 |
| 软占用   | **台账不动**；可调量按调出仓实物批次计算，不用全仓「总库存−软占用」卡单仓                                   |

可调量（调出仓、该物料）= 该仓自由备货数量 + 用户主动勾选的本仓按单批次数量。

与「销售跨单库存调拨」分离：后者改占用与销售归属、不换仓。

### 4.4 确认联动

1. 整单或按行确认：生成并入账 **调拨出库**（调出仓）+ **调拨入库**（调入仓），数量/批次一致。
2. 出库失败则该行不入账、不生成入库。
3. 拒绝：未确认行→已拒绝；全拒→头「已拒绝」；有确认与待确认/拒绝并存→「部分确认」。
4. 删除：来源「新增」且（待确认或部分确认）可删；**任一已确认行存在则不可整单删除**。业务来源不可删。
5. 联动出入库单：`sourceChannel=business`，`sourceOrderNo=调拨单号`，不可删。

## 5. 盘点管理

### 5.1 单据头

| 字段     | 说明                                |
| -------- | ----------------------------------- |
| 盘点单号 | 自动生成                            |
| 状态     | 待确认 / 部分确认 / 已确认 / 已拒绝 |
| 盘点仓库 | 必填（一期单仓一张单）              |
| 盘点日期 | 默认当天                            |
| 申请人   | 默认当前用户                        |
| 来源     | 默认「新增」                        |
| 备注     | 可选                                |
| 联动单据 | 确认后记录盘盈入库 / 盘亏出库单号   |

### 5.2 起单与明细

1. 选仓库 → 从库存勾选物品/批次带入（可删行）。
2. 带入时记录账面数量；确认前再读一次账面，防并发漂移。
3. 用户填实盘数量；差异 = 实盘 − 账面。

| 字段                        | 说明                     |
| --------------------------- | ------------------------ |
| 物品、规格、单位、批次/件码 | 带入为主；件码行按件盘   |
| 账面数量                    | 只读                     |
| 实盘数量                    | 必填，≥0                 |
| 差异数量                    | 只读                     |
| 行状态                      | 待确认 / 已确认 / 已拒绝 |

### 5.3 按单在库与软占用

- 账面按该仓实物（自由备货 + 勾选的按单批次），不减软占用。
- 盘盈入库：新建批次默认自由备货，不自动挂销售单。
- 盘亏出库：优先扣本行对应批次；不改软占用台账（释放占用二期）。
- 禁止用盘点改销售单批次归属。

### 5.4 确认联动

| 差异        | 动作                                     |
| ----------- | ---------------------------------------- |
| 实盘 > 账面 | 生成并入账 **盘点入库**（数量=差异）     |
| 实盘 < 账面 | 生成并入账 **盘点出库**（数量=\|差异\|） |
| 实盘 = 账面 | 行直接已确认，不生成出入库单             |

出入库失败则该行状态不变。拒绝/删除规则同调拨。联动单 `sourceChannel=business`，`sourceOrderNo=盘点单号`。

## 6. 技术落地

### 6.1 主要新增

| 项        | 调拨                                   | 盘点                          |
| --------- | -------------------------------------- | ----------------------------- |
| Store     | `transferOrderStore.js`                | `stocktakeOrderStore.js`      |
| Options   | 状态色、来源                           | 同左                          |
| 列表 View | `TransferManagementView.vue`（仅表格） | `StocktakeManagementView.vue` |
| 表单/详情 | FormModal + DetailView                 | 同左                          |
| 种子      | 少量跨仓自由备货演示                   | 盘盈/盘亏各一例               |

菜单：`menus.js`；路由：`router/index.js`。

### 6.2 确认编排

1. 调拨：编排创建类型为「调拨出库」「调拨入库」的出入库单并走现有入账（含批次迁仓，保留 `salesOrder*`）。
2. 盘点：按差异创建「盘点入库」或「盘点出库」并入账。
3. 主单写 `linkedOutboundIds` / `linkedInboundIds`。
4. **不**调用销售 `confirmStockTransfer`，不改 soft allocation。

### 6.3 一期不做

卡片视图、待办独立菜单、打印、货位强制校验、盲盘、释放软占用、整仓一键全盘。

## 7. 验收要点

- 调拨：自由备货 A→B，汇总与批次仓别正确；勾选按单批后归属不变、软占用不变。
- 盘点：盘盈/盘亏生成对应出入库并入账；无差异不生成单。
- 部分确认、拒绝、删除与出入库规则一致；联动单为业务来源不可删。
- 列表仅为表格视图。

## 8. 范围边界

- 本设计仅覆盖 i-doms-web 前端 mock 能力，与现网 MES 库存规则对齐演示。
- 不替代 WMS 规划中的完整上架/拣货/盘点体系。
- 不改造销售跨单调拨产品语义。
