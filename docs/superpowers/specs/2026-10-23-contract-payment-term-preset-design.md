# 合同账期与预设回款节点设计

## 已确认

1. 基本信息去掉账期起算；账期天数默认 30；签署人后加签署日期，默认有效期开始日。
2. 起算日：签订日→签署日期/有效期开始；发货日→关联订单首张发货单关联出库确认日；验收/开票/对账不带入。
3. 回款节点区蓝色提示说明各起算类型。
4. 全公司一套预设（非按客户）；合同列表工具栏入口；标准/框架两套；新增合同按类型带入。

## 数据

- `contract.signedAt`：签署日期 YYYY-MM-DD
- `contract.paymentTermDays`：默认 30（合同级默认，节点可共用）
- 预设 store：`{ standard: nodes[], framework: nodes[] }` localStorage
