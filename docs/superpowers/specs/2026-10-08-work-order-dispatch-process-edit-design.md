# 工单下发 · 本单工序结构编辑（双模）

**日期：** 2026-10-08  
**仓库：** i-doms-web  
**状态：** 前端一期已落地  
**范围：** 生产/总装工单「工单下发」Tab；仅本单快照，不写工艺路线主数据

## 1. 目标

对待下发、尚未生成小程序任务的工单，允许调整本单工序结构（增/删/调步/并行/完成方式），且：

- 默认仍用扁平表做派工（执行人、外协、选做、下料等）
- 需要改结构时，打开与工艺路线同款的网格编辑器
- 换工艺路线时二次确认后整表重置

## 2. 决策摘要

| 项     | 选择                                       |
| ------ | ------------------------------------------ |
| 能力   | 结构级增/删/调步/并行/完成方式             |
| 时机   | 仅 **待下发** 且 **无小程序任务**          |
| UI     | **双模**：扁平表（派工）+ 按需网格（结构） |
| 换路线 | 二次确认后整表重置为新快照                 |
| 主数据 | 不写回工艺路线                             |

## 3. 两层分工

| 层       | 职责                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| 扁平表   | 展示步骤/完成方式；选执行人、工序内容、外协勾选、选做勾选、下料               |
| 网格弹窗 | 增删工序、调步序、并行、改完成方式；确认写回本单 `processes` + `stepPolicies` |

扁平表不提供结构级增删/调步（避免双入口）。可编辑结构时显示「用网格调整本单工序」；已下发或已有任务则隐藏。

## 4. 合并与校验

- 网格确认：同 `processId` + `stepNo` + `rowNo`（或原 `id`）尽量保留执行人、工序内容、外协勾选、`includeInDispatch`、下料/投料等
- 新增格：工序库默认执行人等
- 校验：`validateProcessRouteGrid`；至少一道工序；选做步下发规则不变
- 文案：仅影响本工单，不修改工艺路线主数据

## 5. 换路线

更换「工艺路线」→ 确认「更换路线将重置本单工序列」→ `applyRouteSnapshotToWorkOrder`；取消则保持原路线与工序列。

## 6. 一期不做

- 下发后 / 有任务后改结构
- 扁平表上再做一套结构操作
- 本单改动另存为新工艺路线
