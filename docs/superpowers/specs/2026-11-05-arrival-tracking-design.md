# 关键件到货跟踪设计

**日期：** 2026-11-05  
**仓库：** i-doms-web  
**状态：** 前端一期已落地  
**需求 MD：** `docs/yunxiao/淄博泵产业互联网平台-机泵1.6.3-到货跟踪需求.md`  
**云效：** NYVC-2737（到货跟踪页）、NYVC-2736（入库确认通知与工作台未读）

---

## 1. 目标

给生产侧一个「关键件到了没有、还差多少」的跟踪台：

- **已到货**：入库已确认的关键件，可一键去领料
- **预计到货**：采购未关单、关键件仍有待入量；含逾期/今日到期提示

与工作台「关键件到货」卡片打通：入库确认写提醒，卡片数字=今日到货，点击进本页已到货 Tab（不弹抽屉）。

| 项             | 选择                                                           |

## 4. 页内结构

### 4.1 概览 KPI

| 指标                    | 口径                                      |
| ----------------------- | ----------------------------------------- |
| 已到货（近 7/15/30 天） | 关键件入库确认条数，随时段切换            |
| 今日到货                | 当天入库确认；**不**随时段切换            |
| 预计待到                | 未关闭采购单中关键件且待入 > 0 的明细行数 |
| 已逾期                  | 预计待到中，交货日 < 今天且未到齐         |
| 今日到期                | 预计待到中，交货日 = 今天且未到齐         |

- 各指标旁问号 Tooltip 说明口径
- 概览区可折叠，折叠态写 localStorage

### 4.2 已到货 Tab

**筛选**

- 到货时段：近 7 / 15 / 30 天（默认 7）
- 关键词：供应商 / 单号 / 仓库
- 物料编码、名称、规格型号

**列表列（建议）**

入库时间、物料、规格、数量、供应商、采购/入库单号、仓库、操作（去领料）

**交互**

- 点采购/入库单号 → 对应详情
- 「去领料」→ 领料相关页，带物料与仓库

### 4.3 预计到货 Tab

**筛选**

- 状态：全部 / 已逾期 / 今日到期 / 未到期
- 供应商、物料关键词、交货日区间

**列表列（建议）**

预计交货日、物料、待入数量、采购数量、已入数量、供应商、采购单号、逾期标记

**交互**

- 点采购单号 → 采购详情
- 行状态色：逾期强调、今日到期次强调

## 5. 数据流

```
采购入库确认
    │
    ├──► 写 keyPartArrivalStore（仅关键件）
    │         │
    │         ├──► 到货跟踪「已到货」列表 / 概览已到货·今日到货
    │         └──► 工作台「关键件到货」未读 / 今日数字
    │
    └──► 库存与入库单（既有链路）

未关闭采购单 + 关键件 + 待入>0
    └──► 到货跟踪「预计到货」/ 概览预计·逾期·今日到期
```

**未读约定（NYVC-2736）**

- 入库确认产生提醒 → 工作台卡片未读
- 进入到货跟踪「已到货」或等价已读动作后清未读
- 卡片点击 **只跳转**，不打开消息抽屉
