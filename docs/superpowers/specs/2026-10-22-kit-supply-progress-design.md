# 齐套与供应进度（计划工作台 + 车间投屏）

**日期：** 2026-10-22  
**仓库：** i-doms-web  
**状态：** 前端一期已落地

## 1. 目标

在系统中落地「工单/计划齐套与采购、外协回货」类生产管控能力（对标装配齐套、零件工序、外协准时、长周期预警、材料利用率），并贴合现有按单库存、生产计划缺口与外协单据。

- **计划侧**：日常跟单、下钻、跳转业务单据
- **车间侧**：同一套数据的大屏投屏
- **不包含**：订单成本分析（仍只在报表中心）

## 2. 决策摘要

## 3. 落点与双端结构

### 3.1 计划侧工作台

- 菜单位置：`计划排产` →「齐套与供应进度」（与「生产计划」「库存预警」等并列）
- 形态：搜索、KPI、表格、点行下钻、跳转业务单
- 不挂在「报工管理」（报工/工资模块，易混名）

### 3.2 车间投屏

- 挂在 `看板管理`，与工单监管看板同级
- 与计划侧共用同一计算层与 Tab 定义
- 布局：大字号、弱化操作按钮、适合投屏与轮播

### 3.3 报表中心

- 本期不新增主入口
- 后续若需导出，再从五块抽切片挂到生产/外协报表组

## 4. 页内结构

计划侧与大屏共用 Tab 顺序：

1. 装配齐套看板
2. 零件工序进度
3. 外协进度准时率
4. 长周期件预警
5. 材料利用率

统一搜索：当前 Tab 内按订单号 / 客户 / 物料 / 工序 / 供应商过滤。

### 4.1 装配齐套看板

- 二级 Tab：**按生产计划** | **按销售订单**
- 汇总列：单号、客户、泵型号/产品、数量、计划装配日、齐套率、缺件项、状态（可装配 / 基本齐套 / 缺料）
- 点行下钻：缺件明细（物料、需求、可用、缺口、供应型态、在途覆盖、来源单号）
- 齐套率：**按零件项种**（该行缺 ≥1 即未齐），不做数量加权
- 状态默认：100% → 可装配；≥80% → 基本齐套；否则 → 缺料

### 4.2 其余 Tab

| Tab            | 主内容                               | 下钻                    |
| -------------- | ------------------------------------ | ----------------------- |
| 零件工序进度   | 按零件/工单看工序链完成态            | 对应生产/总装工单或报工 |
| 外协进度准时率 | KPI + 按厂商准时率排名               | 该厂商标的外协订单      |
| 长周期件预警   | 供货期长且临近需求日、仍有风险的物料 | 计划行 / 采购或外协来源 |
| 材料利用率     | 理论需求 vs 实发/实耗                | 工单或下料结算          |

## 5. 数据口径

### 5.1 装配齐套

- **需求**：生产计划物料行，与现有 `productionPlanMaterial` / 计划页缺口同一套，不另起 BOM 引擎
- **可用**：优先本销售单占用/按单库存，再可调配自由备货；**他单占用不算可用**
- **在途**：采购未到、外协未回、自制在制；有覆盖 → 黄；无来源 → 红
- **按销售订单**：合并该单下各生产计划的零件项种后算齐套率
- **按生产计划**：仅单张计划

### 5.2 零件工序进度

- 复用工单监管看板 / 工序报工的工序链状态，扩展到计划 BOM 中的自制件维度
- 不新建第二套工序进度引擎

### 5.3 外协进度准时率

- 外协订单：承诺回厂日（或交期）vs 实际回厂/收货日
- KPI：本月准时回厂率、在外订单数、逾期未回、平均逾期天数
- 厂商表：近 90 天准时率排名；协作类型取外协单工序/类型，无则「—」

### 5.4 长周期件预警

- 物料（或采购行）`leadTimeDays` + 计划需求日 / 计划装配日
- 示意条件：`今天 + 供货期 > 需求日` 且仍有缺口（或尚无覆盖采购/外协）
- 与「库存预警（补货中心）」分工：补货偏 MTS 安全库存；本页偏订单/计划交期风险

### 5.5 材料利用率

- 优先接领料扣减 / 下料结算：理论需求（BOM×计划或工单数量）vs 实发/实耗
- 先做工单或计划维度汇总，不做空泛「全厂利用率」大盘

### 5.6 共用原则

- 计划侧与大屏只读同一聚合层（建议 `kitSupplyDashboard` 一类模块），不写回业务 store
- 跟单动作一期以 **跳转** 现有生产计划 / 采购 / 外协页为主
