# 齐套与供应进度（计划工作台 + 车间投屏）

**日期：** 2026-10-22  
**仓库：** i-doms-web  
**状态：** 前端一期已落地

## 1. 目标

在系统中落地「工单/计划齐套与采购、外协回货」类生产管控能力（对标装配齐套、零件工序、外协准时、长周期预警、材料利用率），并贴合现有按单库存、生产计划缺口与外协单据。

- **计划侧**：日常跟单、下钻、跳转业务单据
- **车间侧**：同一套数据的大屏投屏
- **不包含**：订单成本分析（仍只在报表中心）

## 4. 页内结构

计划侧与大屏共用 Tab 顺序：

1. 装配齐套看板
2. 零件工序进度
3. 外协进度准时率
4. 长周期件预警
5. 材料利用率

统一搜索：当前 Tab 内按订单号 / 客户 / 物料 / 工序 / 供应商过滤。

### 4.1 装配齐套看板

- 二级 Tab：**按生产计划** | **按销售订单**
- 汇总列：单号、客户、泵型号/产品、数量、计划装配日、齐套率、缺件项、状态（可装配 / 基本齐套 / 缺料）
- 点行下钻：**物料明细**（含已齐套行，便于看占用）；页头展示产品名称 · 规格型号 · 材质 · **外部工号**；表内列含物料、需求、本单/他单占用、在途、缺料状态等；上方「缺料项」仍只统计有缺口的行
- 齐套率：**按零件项种**（该行缺 ≥1 即未齐），不做数量加权
- 状态默认：100% → 可装配；≥80% → 基本齐套；否则 → 缺料

#### 缺件明细 · 缺料状态判定（一期约定）

- **缺口** = 需求 − 本单占用（本单占用含自动预占 + 手动锁定）
- 判定顺序（先匹配先生效）：
  1. **已齐套**：缺口 ≤ 0（即便他单占用 > 0，只要本单已分够，仍为已齐套）
  2. **被高优先占用**：缺口 > 0，且他单占用 > 0，且在途 = 0（用于区分「库存被更高优先单据拿走」与「纯实物不足」）
  3. **待到货**：缺口 > 0，且在途 ≥ 缺口
  4. **部分缺口**：缺口 > 0，且 0 < 在途 < 缺口
  5. **严重缺料**：缺口 > 0，且在途 = 0，且他单占用 = 0
- 补充说明（一期不另开状态）：
  - 他单占用 > 0 且在途 > 0 且仍有缺口时，**不**标「被高优先占用」，按在途落入「待到货 / 部分缺口」
  - 下钻页脚展示上述口径文案；占用分摊规则：可用池 = 实物 − 手动锁定；按「紧急度 → 计划日期 → 创建时间」自动预占，手动锁定优先保留后再重算

#### 物料占用视图（一期）

- **不单独建页**。缺件明细行点「占用明细」打开抽屉，即物料视角：该物料实物、手动锁定、按优先级排队的各单据（需求 / 占用 / 缺口 / 在途 / 缺料状态）。
- **物料视角操作（不限入口单）**：行上 **「转入本单」**（默认=需求，可改；输入多少锁多少，覆盖该行原手动锁；上限 = min(需求, 实物−其他单已锁)）+ **「释放」**；顶部亦可按锁条释放。抽屉分 Tab：**占用明细** | **操作日志**。入口高亮为「当前查看」。行内「本单在途」取各单据物料行上的在途/在制（用于该单缺料状态），**不是**物料仓总在途，故同物料各行可不同。
- 演示数据：物料 `KIT-SHARE-CAST-01` 实物 7，挂在 4 张演示计划上（特急已齐套 / 紧急部分缺口 / 正常待到货 / 正常部分缺口），便于联调多单争用。
- 二期若需要「按物料编码全局检索占用」再考虑独立查询页；一期从齐套行进入即可。

## 5. 数据口径

### 5.1 装配齐套

- **需求**：生产计划物料行，与现有 `productionPlanMaterial` / 计划页缺口同一套，不另起 BOM 引擎
- **本单占用 / 可用池**：可用池 = 实物 − 手动锁定；无人手动时按「紧急度 → 计划日期 → 创建时间」自动预占（计划维用计划紧急度，工单维用工单紧急度）；有手动锁定则优先保留后再重算剩余池。列表与占用同分摊优先级排序
- **缺口**：需求 − 本单占用；他单占用仅作说明/挡位，不计入本单可用
- **在途**：采购未到、外协未回、自制在制；缺料状态见 §4.1
- **二级 Tab 顺序**：按生产工单（默认）→ 按总装工单 → 按生产计划；缺件页头含外部工号

### 5.2 零件工序进度

- 复用工单监管看板 / 工序报工的工序链状态，扩展到计划 BOM 中的自制件维度
- 不新建第二套工序进度引擎

### 5.3 外协进度准时率

- 外协订单：承诺回厂日（或交期）vs 实际回厂/收货日
- KPI：本月准时回厂率、在外订单数、逾期未回、平均逾期天数
- 厂商表：近 90 天准时率排名；协作类型取外协单工序/类型，无则「—」

### 5.4 长周期件预警

- 物料（或采购行）`leadTimeDays` + 计划需求日 / 计划装配日
- 示意条件：`今天 + 供货期 > 需求日` 且仍有缺口（或尚无覆盖采购/外协）
- 与「库存预警（补货中心）」分工：补货偏 MTS 安全库存；本页偏订单/计划交期风险

### 5.5 材料利用率

- 优先接领料扣减 / 下料结算：理论需求（BOM×计划或工单数量）vs 实发/实耗
- 先做工单或计划维度汇总，不做空泛「全厂利用率」大盘

### 5.6 共用原则

- 计划侧与大屏只读同一聚合层（建议 `kitSupplyDashboard` 一类模块），不写回业务 store
- 跟单动作一期以 **跳转** 现有生产计划 / 采购 / 外协页为主
