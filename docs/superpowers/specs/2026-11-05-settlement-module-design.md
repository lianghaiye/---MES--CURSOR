# 往来结算模块设计

**日期：** 2026-11-05  
**仓库：** i-doms-web  
**状态：** 前端一期已落地（菜单归集 + 对账/往来/票款）  
**需求 MD：** `docs/yunxiao/淄博泵产业互联网平台-机泵1.6.3-往来结算需求.md`  
**云效：** STL-163-01～11（NYVC-2692～2710）

---

## 1. 目标

把分散在销售、采购、基础配置的「钱货往来」能力收拢到一级菜单 **往来结算**，形成两条主链路：

1. **应付侧**：入库可结量 → 账期对账 → 收票/付款 → 供应商往来
2. **应收侧**：销售回款/开票 → 客户往来

并提供 **票款流水** 横切查询、**争议挂账** 处理差额/整笔争议。

---

## 2. 决策摘要

| 项                     | 选择                                                                   |
| ---------------------- | ---------------------------------------------------------------------- |
| 一级菜单名             | 往来结算（由「对账结算」更名）                                         |
| 路径前缀               | `/settlement/*`                                                        |
| 旧路径                 | 重定向保留（销售回款、采购对账、结算规则等）                           |
| 页面实现               | 优先复用原销售/采购页面组件，仅改挂载路由与菜单                        |
| 结算规则优先级         | 供应商覆盖 → 工厂默认                                                  |
| 对账生成维度           | 按入库 / 按采购单（已完成）                                            |
| 草稿占量               | 草稿即占可结量，防重复出单                                             |
| 未入库退货             | **不入**对账单                                                         |
| 已入库退货（出库完成） | 对账红冲行（数量为负）                                                 |
| 行级争议               | 差额/整笔；**不阻断**确认与付款                                        |
| 票款流水               | 回款+开票+付款+收票四类统一查询                                        |
| 本期不做               | 折让索赔专单、预付款冲抵、期初未结批量转入、总账凭证、税票直连、小程序 |

细则场景矩阵见：`docs/ai-agent-kb/reference/05-采购对账退货红冲规则.md`。

## 4. 页面形态

### 4.1 采购对账列表

- 筛选：供应商、账期、状态、关键词
- 工具栏：按账期生成、追加未结算量、导出
- 行操作：详情、打印、确认/反确认（受状态约束）

### 4.2 对账详情

- 头：供应商、账期、金额汇总、收票/付款进度
- 明细：来源（入库/采购/退货）、来源单号跳转、数量（退货为负）、金额
- 能力：确认、反确认（未开票未付款）、费用补差行、行级争议挂起、收票、付款与账龄分配

### 4.3 结算规则

- 工厂默认 + 供应商覆盖两层
- 字段含：账期、生成维度、是否追加未结算量等
- 变更日志抽屉

### 4.4 供应商 / 客户往来

- 汇总台账：应付/应收、已付/已回、余额、账龄
- 下钻：对账单 / 回款 / 开票 / 付款 / 争议

### 4.5 回款管理

- 复用销售回款页能力：登记、关联订单分配、开票、节点维护、统计面板
- 与合同付款节点预设联动（见合同账期设计稿）

### 4.6 争议挂账

- 列表：来源对账、性质（差额/整笔）、挂出金额、状态
- 核销：采纳我方 / 对方 / 折中

### 4.7 票款流水

- Tab 或类型筛选：回款 | 开票 | 付款 | 收票
- 统一列：日期、对象、金额、关联单号、跳转

## 5. 数据流（简图）

```
采购入库确认 ──占量/扫账期──► 对账单(草稿→确认)
      │                              │
      │                              ├──收票/付款──► 供应商往来
      │                              └──行争议──► 争议挂账
销售回款/开票 ──────────────────────────────► 客户往来
以上流水 ──────────────────────────────────► 票款流水
```

---

## 6. 关键交互约定

1. **反确认**：仅未开票且未付款；释放草稿/确认占量。
2. **打印**：对账单可给供应商；预览独立路由。
3. **企业抬头**：基础配置企业信息供打印引用（STL-163-10）。
4. **采购单入账状态**：订单侧可看对账/入账进展并可穿透（STL-163-09）。
