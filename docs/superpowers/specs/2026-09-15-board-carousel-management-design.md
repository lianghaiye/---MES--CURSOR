# 看板轮播管理 — 设计说明

**日期：** 2026-09-15  
**项目：** i-doms-web（看板管理）  
**状态：** 待用户审阅后进入实施计划

## 1. 背景与目标

看板管理下当前仅有「工单监管看板」，页内分页轮播不等于多看板投屏轮播。现场需要**多套命名轮播方案**，在大屏上按配置在多个看板（及外部页面）之间自动切换。

**目标：**

- 在「看板管理」下提供**看板列表（台账）**与**轮播管理**
- 支持多套方案：停留时间、切屏动效、一轮后循环/停住
- 支持系统内看板 + 外部 URL
- 支持管理页预览/全屏播放 + 可分享播放链接

**非目标（本期不做）：**

- 首页「数据驾驶舱 / 车间主任工作台」纳入台账（除非后续登记到看板列表）
- 单独权限角色拆分
- 后端 API（先 localStorage，模型预留对接）
- 单看板页内翻页参数的统一后台（仍由各看板页自身配置）

## 2. 方案选型

采用 **方案 1：两个菜单 + 独立播放页（iframe 切屏）**。

| 方案 | 说明                                             | 结论                         |
| ---- | ------------------------------------------------ | ---------------------------- |
| 1    | 看板列表 + 轮播管理 + `/board/carousel/play/:id` | **采用**                     |
| 2    | 不做台账，内置写死 + 外部 URL                    | 与「后续扩充看板」冲突，否决 |
| 3    | 单页 Tab 兼管台账与轮播                          | 职责混杂，否决               |

## 3. 菜单与路由

侧栏 `board`：

| 菜单             | 路径                             | 说明                                   |
| ---------------- | -------------------------------- | -------------------------------------- |
| 工单监管看板     | `/board/work-order-monitor`      | 保持现状；`browserTabPath` → `/screen` |
| 看板列表         | `/board/catalog`                 | 系统内看板台账                         |
| 轮播管理         | `/board/carousel`                | 方案列表                               |
| （无菜单）播放页 | `/board/carousel/play/:schemeId` | `meta.standalone`，无壳布局            |

顶栏「看板管理」`/board`：默认重定向到 **`/board/catalog`**。

## 4. 对象模型

### 4.1 看板（台账）`BoardCatalogItem`

| 字段      | 类型    | 说明                                                |
| --------- | ------- | --------------------------------------------------- |
| id        | string  | 主键                                                |
| code      | string  | 稳定编码，如 `work-order-monitor`；创建后只读       |
| name      | string  | 显示名称                                            |
| playPath  | string  | 独立全屏路由，如 `/board/work-order-monitor/screen` |
| enabled   | boolean | 停用后不可新加入轮播；已引用条目播放时跳过          |
| updatedAt | string  | 更新时间                                            |

种子数据：一条「工单监管看板」。本期不做物理删除。

**外部 URL 不进台账**，仅作为轮播条目来源。

### 4.2 轮播方案 `CarouselScheme`

| 字段                | 类型                         | 说明                          |
| ------------------- | ---------------------------- | ----------------------------- |
| id                  | string                       | 主键（用于播放链接）          |
| name                | string                       | 方案名称                      |
| enabled             | boolean                      | 停用后打开链接提示不可播      |
| defaultDwellSeconds | number                       | 默认停留秒数（>0）            |
| transition          | `'cut' \| 'fade' \| 'slide'` | 硬切 / 淡入淡出 / 左右滑动    |
| afterRound          | `'loop' \| 'stop'`           | 播完一轮：循环 / 停在最后一页 |
| items               | CarouselItem[]               | 有序条目，至少 1 条才能播放   |
| updatedAt           | string                       |                               |

### 4.3 播放条目 `CarouselItem`

| 字段         | 类型               | 说明                             |
| ------------ | ------------------ | -------------------------------- |
| id           | string             | 条目主键                         |
| source       | `'board' \| 'url'` | 台账看板或外部 URL               |
| boardId      | string?            | source=board 时必填              |
| externalUrl  | string?            | source=url 时必填，http(s)       |
| displayName  | string?            | 播放角标；空则看板名或 URL 摘要  |
| dwellSeconds | number?            | 空则用方案 `defaultDwellSeconds` |
| sort         | number             | 排序                             |

允许：同一看板多次出现；系统看板与外部 URL 混排。

### 4.4 存储

- Key 建议：`i_doms_board_catalog`、`i_doms_board_carousel_schemes`（带 version）
- 通过 store 模块读写；后续可替换为 API 而不改页面契约

## 5. 管理页交互

### 5.1 看板列表

- 表格：名称、编码、播放地址、启用、更新时间、操作
- 操作：新建、编辑、启用/停用
- 新建：名称、编码、播放地址；编码唯一
- 种子项：编码只读，可改名称与启用

### 5.2 轮播管理列表

- 表格：名称、条目数、默认停留、切屏效果、一轮后行为、启用、操作
- 操作：新建、编辑、复制方案、启用/停用、预览、复制播放链接、全屏播放

### 5.3 方案编辑（抽屉）

1. 基本信息：名称、启用、默认停留、切屏效果、播完一轮
2. 条目列表：拖拽排序；来源切换；可选显示名、停留覆盖
3. 校验：名称非空；≥1 条有效条目；外部 URL 须 http(s)；引用已停用看板时保存前提示并要求处理

## 6. 播放页

### 6.1 行为

- 按条目顺序用 **iframe** 加载系统 `playPath`（同源）或外部 URL
- 切屏按方案 `transition` 执行
- 停留：条目秒数优先，否则方案默认；到点切下一页
- `afterRound=loop`：回到第一条；`stop`：停在最后一页并显示「已播完」（可重播）
- 控件（移入或快捷键）：上一页 / 下一页 / 暂停·继续 / 退出；角标「当前名 · n/N」
- 跳过：看板停用、URL 空、方案整体停用（整页提示不可播）

### 6.2 开播入口

| 入口     | 行为                                                |
| -------- | --------------------------------------------------- |
| 预览     | 同标签打开播放页                                    |
| 全屏播放 | 打开后尽量 `requestFullscreen`                      |
| 复制链接 | 绝对 URL：`{origin}/board/carousel/play/{schemeId}` |

### 6.3 外部页无法嵌入

- 占位：「该页面不允许嵌入」+「打开原址」
- 到点仍切下一页，不阻塞整轮

## 7. 与现有能力关系

| 现有                     | 关系                                               |
| ------------------------ | -------------------------------------------------- |
| 工单监管页内列表翻页轮播 | 保留，与方案轮播无关                               |
| `/screen` 独立大屏       | 作为台账 `playPath` 被 iframe 引用                 |
| 数据驾驶舱等             | 本期不进台账；若需轮播可后续登记为看板或用外部 URL |

## 8. 验收要点

1. 侧栏可见「看板列表」「轮播管理」；`/board` 进看板列表
2. 台账含工单监管种子；可新建启用看板
3. 可建多套方案；条目可混选台账 + 外部 URL；可设默认/分条目停留、切屏、循环/停住
4. 预览、全屏、复制链接均可开播；链接在无壳页独立运行
5. 停用方案/停用看板/不可嵌入外部页时行为符合第 5～6 节

## 9. 实施边界（给计划用）

- 仅改 `i-doms-web`：menus、router、views/board/\*、store/mock
- 不改小程序、不改工单监管看板业务取数逻辑（仅被引用）
