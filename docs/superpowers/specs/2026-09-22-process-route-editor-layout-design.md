# 工艺路线新增/编辑页布局与适用范围改造

**日期：** 2026-09-22  
**仓库：** i-doms-web  
**状态：** 已口头确认，待书面审阅  
**范围：** 工艺路线创建/编辑页（`ProcessRouteEditorModal` + `ProcessRouteGridEditor`）

## 1. 目标

1. 基本信息卡片移到标题区下方，间距对齐工序配置新增页。
2. 「工艺应用范围」改为「适用范围」，交互对齐设计稿（单选 + 条件出现的适用对象）。
3. 左侧工序选择区独立盒子，支持拖拽调宽。
4. 中间网格支持在步与步、行与行之间插入列/行（方案 B：间隙常驻「+」）。
5. 右侧「工序信息」独立盒子，只读 `字段名：字段值`；保留下方「文件配置」。

## 2. 布局结构

```
FormCreateShell（标题 + 底栏取消/保存）
├── 基本信息卡片（全宽）
├── 温馨提示条（可选保留）
└── 编辑区（左 | 中 | 右，各自独立白底盒子，有间距）
    ├── 左：工序（分类 + 磁贴，可拖宽）
    ├── 中：工艺路线网格
    └── 右：工序信息 + 文件配置
```

- 基本信息不再嵌在中间列底部。
- 左/中/右用独立 `panel-box`，中间留 gap；左侧默认宽约 220px，拖拽手柄改宽，建议范围 180–360px。

## 3. 适用范围

| 展示文案 | 存储值（兼容现网） |
| -------- | ------------------ |
| 全局     | `全部产品`         |
| 单产品   | `单个物品`         |
| 产品类别 | `物品类别`         |

交互：

- 单选「适用范围」必填。
- 选「全局」：不展示「适用对象」。
- 选「单产品」：展示「适用对象」——可搜编码/名称的选择控件 +「查看更多」（打开现有 `SelectProductMaterialModal`）。
- 选「产品类别」：展示「适用对象」——类别树选（可简化为产品类别为主；物料类别若现网仍依赖则保留类型切换或并入树，实现时优先不破坏 `applyScope=物品类别` 匹配逻辑）。
- 切换适用范围时清空已选适用对象。

列表/详情展示文案同步为「适用范围」，枚举展示映射为 全局/单产品/产品类别。

## 4. 中间网格插入（方案 B）

- 相邻「第 N 步」与「第 N+1 步」表头之间常驻「+」；点击在第 N 步之后插入一列空步。
- 相邻行标之间常驻「+」；点击在该行之后插入一空行。
- 末列右侧、末行下方保留追加「+」（与现网一致）。
- 插入后若已达 `MAX_ROUTE_STEPS` / `MAX_ROUTE_PARALLEL` 则禁用并 toast。
- 插入后选中态：若选中单元格索引 ≥ 插入点，索引顺延，避免错位。

工具函数建议落在 `processRouteGrid.js`：`insertStepAfter(grid, index)`、`insertRowAfter(grid, index)`。

## 5. 右侧工序信息

有选中网格工序时：

**工序信息**（只读文本行，非表单项输入框）

- 工序名称：…
- 工序编号：…（`process.code`）
- 资源类型：…
- 报工类型：…
- 工序配置项：…（下料 + `getOperationLabels`，多标签或顿号拼接）

**文件配置**（保留）

- 工艺文件：可清空下拉，写入当前 cell 的 `processFileId`。

无选中时：空态「请点击网格中的工序」。

`getSelectedCellMeta` 扩展返回 code / resourceType / reportMode / 配置项文案所需字段。

## 6. 非目标

- 不改工艺路线匹配业务算法（仍按现有 `applyScope` 存储值）。
- 不改最大步数/并行上限数值。
- 不做工艺文件以外的右侧新字段编辑。

## 7. 涉及文件（预期）

- `ProcessRouteEditorModal.vue` — 基本信息上移、适用范围 UI
- `ProcessRouteGridEditor.vue` — 三栏盒子、左栏拖宽、间隙插入、右侧只读信息
- `processRouteGrid.js` — 插入列/行工具；meta 扩展
- `ProcessRouteView.vue` / `ProcessRouteDetailView.vue` — 文案映射（如需）
- `processRouteStore.js` — 校验文案「请选择适用范围」（如需）

## 8. 验收

1. 新增/编辑工艺路线：基本信息在标题下，与编辑区有清晰间隔。
2. 适用范围三选一；全局无适用对象；单产品/产品类别有适用对象与「查看更多」。
3. 左侧可拖宽，刷新后可用默认宽（一期可不持久化宽度）。
4. 可在任意步间隙、行间隙插入，漏配工序可补进中间。
5. 点选网格工序后右侧只读信息完整，文件配置仍可改。
