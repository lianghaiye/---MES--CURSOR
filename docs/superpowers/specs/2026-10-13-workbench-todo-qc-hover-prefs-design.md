# 工作台待办：待质检悬停分项 + 个人配置

**日期：** 2026-10-13  
**仓库：** i-doms-web  
**状态：** 前端一期已落地

## 1. 目标

1. 「待质检」卡片悬停展开五类质检待办数量，点击分项跳转对应列表。
2. 用户可配置工作台展示哪些待办卡片及顺序（个人偏好）。

## 2. 决策

| 项           | 选择                                          |
| ------------ | --------------------------------------------- |
| 配置范围     | 每人/本机自配（localStorage，随工作台 store） |
| 待质检主数字 | 五类合计                                      |
| 主卡点击     | 不跳转；仅分项可跳                            |
| 侧栏角标     | 不改                                          |

## 3. 待质检分项

来料质检、外协回货检、生产过程检、成品检、出厂检；计数口径对齐侧栏（待质检/检验中/检测中；出厂检用 factoryQc）。

## 4. 个人配置

- 入口：待办标题旁「配置」
- 勾选显隐 + 上移下移；至少 1 项
- 默认：现网 8 项全开、原顺序

## 5. 一期不做

管理员强制默认集；移动端长按；卡片拖拽排序。
