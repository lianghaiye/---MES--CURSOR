# 工单下发 · 自动生成工序外协单设计

**日期：** 2026-09-17  
**仓库：** i-doms-web  
**状态：** 已实现（2026-09-18 闭环调整）  
**关联云效：** NYVC-2363（工单工序外协入口）、NYVC-2364（外协订单工序外协）

## 1. 目标

生产/总装工单下发成功时，对可外协工序按本批数量生成工序外协单；下发页可按工序勾选「本次不出」或「下发前确认」；事后可在「排产信息」补单；外协工序本厂不派小程序任务、不校验执行人。

## 2. 决策

| 项         | 选择                                                             |
| ---------- | ---------------------------------------------------------------- |
| 出单粒度   | 每个可外协工序 × 每个下发批次各 1 张                             |
| 数量       | 本批排产/下发数量                                                |
| 本次不出   | 勾选则本批该工序**直接跳过**出单                                 |
| 下发前确认 | 勾选则下发后打开工序外协表单；保存=出单，取消=跳过               |
| 互斥       | 两勾选**可同时不选**，**不可同时选**                             |
| 均未勾选   | **自动出单**                                                     |
| 事后补单   | 排产信息 Tab：外协状态「未生成」且批次未完成 →「生成工序外协单」 |
| 批次绑定   | 外协单写 `sourceScheduleBatchId`                                 |

## 3. 下发页

可外协工序在「外协」标签后两个 Checkbox：`本次不出`（`skipProcessOutsourceOnDispatch`）、`下发前确认`（`outsourceConfirmBeforeDispatch`）。勾选其一会自动取消另一项。

## 4. 排产信息

- 工序名后「工序配置」；报工时间后「外协状态」（订单状态 / 未生成）
- 外协工序：操作列不支持修改执行人、重置状态、终止
- 未生成且批次已下发、非完成/已完成：显示「生成工序外协单」

## 5. 下发差异

外协工序跳过执行人校验与小程序任务。
