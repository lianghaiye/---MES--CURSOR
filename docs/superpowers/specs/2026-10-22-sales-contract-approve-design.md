# 销售合同审核设计

## 目标

合同管理对齐销售订单审核流：草稿 → 提交 → 独立审核页（只读核对 + 意见）→ 通过生效 / 驳回；新建不可直接生效。新增合同页视觉与新增销售订单一致。

## 状态机

| 状态   | 可操作                                     |
| ------ | ------------------------------------------ |
| 草稿   | 编辑、提交审核、删除                       |
| 待审   | 撤回→草稿、进入审核页                      |
| 已驳回 | 编辑、重新提交→待审、删除                  |
| 生效中 | 发起变更、确认签署、完成、终止（无反审核） |
| 已完成 | 履约结束（与「已终止」区分：正常完结）     |
| 已终止 | 删除（沿用现规则）                         |

## 审核页

- 路由：`/sales/contracts/:id/approve`
- 只读：基本信息、明细/协议价、回款节点、扫描件
- 审批意见：通过可选；驳回必填
- 通过→生效中；驳回→已驳回；记录 `approvalRecords`

## 新建/编辑表单

- 按钮：保存草稿、保存并提交审核（去掉「保存并生效」）
- 样式：与 `CreateSalesOrderModal` 一致（FormCreateShell、section-title-row、horizontal-form、控件 size=small、可折叠基本信息）

## 入口

- 列表：工具栏「审核」、行内提交/撤回/审核
- 详情：同步上述操作
- 不新增侧栏「合同审核」菜单

## 非目标

- 合同变更单审核流程不变
- 生效后反审核
