# 状态机速查

> 用于 Agent 回答「现在是什么状态、能不能操作」。具体按钮以现场版本为准。

---

## 1. 销售订单

| 状态   | 说明     | 常见可操作                                      |
| ------ | -------- | ----------------------------------------------- |
| 待提交 | 草稿     | 编辑、提交                                      |
| 待审核 | 已提交   | 审核通过/拒绝、撤回（若允许）                   |
| 进行中 | 已审核   | 变更、申请发货、关联计划/生产；可反审（有约束） |
| 已完成 | 业务完结 | 查询为主                                        |
| 已拒绝 | 审核未过 | 修改后重提（视流程）                            |
| 已作废 | 作废     | 不可再编辑                                      |

**行发货状态：** 未发货 / 部分发货 / 已发货  
**发货单：** 待发货 / 待出库 / 已发货

**注意：** 存在待审核的订单变更时，通常 **不可申请发货**。

---

## 2. 设计任务

待设计 → 设计中 → 待审核 → 审核通过 / 已驳回

---

## 3. 生产计划

| 状态     | 说明             |
| -------- | ---------------- |
| 待下达   | 未下达           |
| 部分下达 | 部分工作项已下达 |
| 执行中   | 执行中           |
| 已完成   | 完成             |

工作项另可能有：待 BOM、设计中、进行中、已关闭等。

---

## 4. 生产工单

| 状态   | 说明                     |
| ------ | ------------------------ |
| 待下发 | 已开立未下发             |
| 已下发 | 已下发到执行侧           |
| 执行中 | 有领取/报工进行中        |
| 已完成 | 完工（可能触发库存扣减） |
| 暂停   | 暂停执行                 |
| 终止   | 终止                     |

**派工/小程序任务常见状态：** 待领取、待报工、待开始、执行中、已报工、已终止  
**控制动作：** 暂停 / 终止 / 终止保留

---

## 5. 工序报工

| 状态   | 说明                       |
| ------ | -------------------------- |
| 待审核 | 工人已报，待主任审         |
| 已审核 | 通过                       |
| 已拒绝 | 拒绝（可要求重报，视口径） |

**来源：** 任务报工 / 快速报工

**报工确认：** 待确认 / 待工人确认 / 已确认

**工资推送标记：** 未推送 / 已推送 / 已自动推送

---

## 6. 领料 / 出入库

**领料申请：** 待处理/待审核 → 已通过 / 已拒绝  
**出库单：** 待出库 → 部分出库 / 已出库 / 已拒绝；另有待申领人确认  
**入库单：** 待入库 → 部分入库 / 已入库 / 已拒绝；小程序成品入库常表现为「待审批」

---

## 7. 调拨 / 盘点

**调拨：** 待确认 → 待入库方确认 / 部分确认 → 已完成；另有已拒绝、已作废  
**盘点：** 待提交 → 待审核 → 审核通过 / 已拒绝；过账可能自动或手动

---

## 8. 采购 / 外协

**采购申请：** 草稿 → 待处理 → 处理中 → 处理完成；可作废  
**采购订单：** 待提交 → 待审核 → 进行中 → 已完成；另有已拒绝、已终结、已作废

外协订单状态与采购类似（提交审核、撤回、作废等）。入库状态机细节见云效「采购外协订单入库状态机」需求文档。

---

## 9. 质检

**任务状态：** 待质检 → 已完成 / 已终止  
**结果：** 质检通过 / 不通过 / 部分通过  
**五类：** 来料、外协回货、生产过程、成品、出厂

---

## 10. 库存扣减记录

常见：待确认 → 已确认（失败则行/单标记失败，可按规则重试）  
锁定：确认超过 N 天后单据锁定不可再操作（以现场规则为准）。

---

## 11. 状态问答模板（Agent）

用户问「为什么不能 XXX」时按序检查：

1. 当前单据状态是否允许该动作？
2. 是否存在关联待审单据（如订单变更）？
3. 功能参数/业务规则是否关闭该路径？
4. 角色是否有菜单/按钮权限？
5. 库存/数量约束是否触发校验？
