# 系统总览与模块地图

## 1. 产品是什么

**I-DOMS** 是面向离散制造（机加、装配、泵阀、非标等）的 MES/制造协同系统，覆盖：

- 主数据：产品、BOM、工艺、工序、工价、仓库、客户、供应商
- 订单与计划：销售订单、设计任务、生产计划、补货
- 生产执行：工单、派工、报工、领料、成品入库
- 计薪：工时管理、工资核算与推送
- 供应链：采购、外协、库存出入、调拨、盘点
- 质量：来料/外协回货/过程/成品/出厂五类质检、报废
- 移动端：微信小程序报工、领料、入库、质检、工时查看

演示站示例：`https://zb.mes.iipcloud.com/login`（以现场环境为准）。

对外介绍品牌可为「泵小智」；实施与 Agent 答疑以 **I-DOMS 菜单与功能参数** 为准。

## 4. 小程序功能地图

Tab：工作台 / 我的。

| 入口                | 能力                                           | 与 PC 关系                      |
| ------------------- | ---------------------------------------------- | ------------------------------- |
| 工序报工            | 待领、今日待报工、快速报工、我的记录、扫码报工 | 审核在 Web「工序报工」          |
| 报工确认            | 仅车间主任：调整、补贴、推送确认               | 与 Web 报工确认协同             |
| 工时工资            | 已报工/已审核、良品不良、补贴、本月计薪        | 可见性受「工资推送模式」控制    |
| 领料管理            | 工单/订单/快速/批量领料                        | 写出库；可否免审看自动审批      |
| 成品入库            | 工单/批量/快速入库                             | 常入「待审批」入库单            |
| 质检任务            | 五类分流执行                                   | 建议质检单由 Web 生成后手机执行 |
| 盘点管理            | 建单录实盘提交                                 | **审核过账在 PC**               |
| 待办任务            | 拆解等任务领取执行                             | 与拆解工单相关                  |
| 扫码查单 / 铭牌任务 | SN→销售单；刻录/装牌                           | 工业标识模块                    |
| 审批管理            | 多为占位                                       | 勿承诺完整移动审批              |

## 5. Web ↔ 小程序责任边界（答疑要点）

| 动作                                          | 推荐端                                           |
| --------------------------------------------- | ------------------------------------------------ |
| 主数据、功能参数、业务规则                    | 仅 Web                                           |
| 开单、审核、工资推送、扣减确认、盘点过账      | 优先 Web                                         |
| 工人报工、领任务、现场领料/入库、现场质检填报 | 小程序                                           |
| 打印标签/工单二维码                           | Web 浏览器打印预览（非智衣 Electron 打印客户端） |

## 6. 与「打印客户端」的区分

| 体系                  | 识别依据                                                                                |
| --------------------- | --------------------------------------------------------------------------------------- |
| I-DOMS Web 打印       | 浏览器 `window.print`、标签/报工二维码预览                                              |
| 智衣 OMS 打印客户端   | 日志 `print_client_service`；安装目录 `zhiyi-print-client`；MQTT `/zhiyi/device/print/` |
| 智衣通 MES 打印客户端 | `mes_print_client_service`；MQTT `/device/print/`                                       |
| Java 打印后台         | `zhiyi_print_service`（非 Electron 客户端）                                             |

Agent 回答打印问题时，先根据日志/安装目录/MQTT 识别体系，再给操作建议。
