# 功能参数与业务规则

> 入口：
>
> - **系统管理 → 功能参数**（`/system/function-params`）
> - **系统管理 → 业务规则**（`/system/business-rules`）  
>   演示环境可能将配置存于浏览器 localStorage（如 `i_doms_function_params`）；生产环境以服务端配置为准。

## 2. 工资推送模式 `salaryPushMode`

| 值          | 中文             | 行为                                        |
| ----------- | ---------------- | ------------------------------------------- |
| `on_report` | 报工即推送       | 工人报工后即可在小程序「工时工资」看到      |
| `on_audit`  | 审核后推送       | 主任审核通过后才对工人可见                  |
| `manual`    | 手动推送（默认） | 需在工资核算/确认流程中手动推送后，工人可见 |

**说明文案（系统内）：**  
报工即推送：报工即展示在工时工资列表。审核后推送：审核通过后展示。手动推送：手动操作推送后展示。

**答疑要点：**

- 「工人报完工看不到工资」→ 先查本参数；若为 `manual`/`on_audit`，属正常。
- 历史值 `auto` 在 Web 侧常归一为 `on_report`；若小程序仍只认旧值，需核对两端一致性。

**关联文档：** 计薪口径确认表（实施启动必签）。

## 3. 库存扣减方式 `inventoryDeductMode`

| 值                        | 中文标签                                         | 适用             | 要点                                                                               |
| ------------------------- | ------------------------------------------------ | ---------------- | ---------------------------------------------------------------------------------- |
| `no_issue`                | 不领料（极简报工 / 无工单）                      | 场景一偏快速报工 | **不生成**工单完工库存扣减                                                         |
| `post_complete_by_report` | 完工后预扣+确认（无领料，按 BOM×完工数扣发料仓） | 有工单但不走领料 | 完工预扣，**必须人工确认**，不可自动确认                                           |
| `self_issue_by_actual`    | 自主领料+完工后预扣+确认（扣线边仓）             | 场景二/三常见    | 领料=发料仓→线边仓；完工按 BOM×完工扣线边；**可**勾选自动确认；库存不足则行/单失败 |

**下料结算叠加：**

- 物料勾选「需要下料结算」且参数为「需下料结算」：扣减单上显示「下料结算扣减」（本单不实扣），线边实耗在下料结算完成。
- 参数为「无需下料结算」：仍在库存扣减中按 BOM×完工数实扣。

**对外口径（重要）：**  
不对客户把「库存扣减」宣传为独立场景。客户问账怎么扣时说：「按你们选的领料/报工习惯，系统保证库存账和现场一致；日常把领料和入库做对即可。」  
对内菜单：**库存管理 → 库存扣减记录**。

## 4. 业务规则 · 生产模式 `productionMode`

| 值               | 中文       | 要点                                                                 |
| ---------------- | ---------- | -------------------------------------------------------------------- |
| `standard`       | 标准模式   | 下发 → 领取 → 时序报工 → 审核 → 核算 → 推送                          |
| `minimal`        | 极简报工   | 再选 `minimalReportType`：`quick` 快速报工 / `task` 任务报工（互斥） |
| `minimal_salary` | 下发即报工 | 跳过现场报工与确认（特殊简化）                                       |

**答疑：** 「能不能又快速报工又任务报工？」→ 极简模式下快速/任务互斥；标准模式以任务为主。是否允许并存以现场业务规则配置为准。

## 5. 自动审批 `autoApproveDocs`

勾选后对应单据提交即自动通过。

| 类型 key                    | 中文                                                         |
| --------------------------- | ------------------------------------------------------------ |
| purchaseOrder               | 采购订单                                                     |
| salesOrder                  | 销售订单                                                     |
| salesOrderPriceChange       | 销售订单变更                                                 |
| purchaseOrderPriceChange    | 采购订单价格变更                                             |
| outsourcingOrderPriceChange | 外协订单价格变更                                             |
| outsourcingOrder            | 外协订单                                                     |
| finishedInbound             | 成品入库                                                     |
| materialRequisition         | 领料申请                                                     |
| inventoryDeduct             | 库存扣减                                                     |
| scrapOrder                  | 报废单审批（配置项可能已展示，业务侧是否完全接入以版本为准） |

**关键约束：**

- 「库存扣减」自动确认 **仅** 对 `self_issue_by_actual` 生效。
- `post_complete_by_report` **永远**须人工确认。
- 未勾选「领料申请」时：待审核 → 审核通过/驳回。

## 7. 库存与出库相关参数

### 7.1 出库规则 `outboundIssueRule`

本期实质开放 **FIFO（先进先出）**；LIFO/自主拣选可能置灰。

- 普通料：按批次先进先出。
- 需下料结算料：FIFO + 优先整批/余料优先等策略（见系统说明文案）。
- 领料、外协发料走本项。

### 7.2 发货出库规则 `salesOutboundIssueRule`

| 值         | 中文     | 行为                                                      |
| ---------- | -------- | --------------------------------------------------------- |
| `by_order` | 按单发货 | 优先/必须扣本销售单挂标批次；强制按单生产行不可拿他单货凑 |
| `fifo`     | 先进先出 | 不区分是否本单库存，按仓内批次先后扣                      |

只作用于 **销售发货**；领料/外协不受影响。

### 7.3 随货附件确定时机 `shipAttachmentDecideStage`

| 值          | 中文                                 |
| ----------- | ------------------------------------ |
| `apply`     | 申请发货时确定（销售勾选纳入、套数） |
| `warehouse` | 仓管发货时确定（申请页不展示附件）   |

无论哪种，仓管均可在 **库存 → 随货查询** 维护。

### 7.4 调拨签收 `transferRequireInboundConfirm`

- `true`：出库确认后生成调拨入库待签收。
- `false`：出库确认后自动入库完结。

### 7.5 盘点过账 `stocktakeAutoPostOnApprove`

- `true`：审核通过即生成盘盈入库/盘亏出库。
- `false`：审核通过后需手动「生成盘盈盘亏」。

### 7.6 下料结算策略 `dualUnitIssueStrategy`

| 值                   | 中文                             |
| -------------------- | -------------------------------- |
| `partial`            | 无需下料结算（余料留线边仓）     |
| `whole_with_remnant` | 需下料结算（登记实耗，余料回库） |

确认出库一律按出库单数量扣库；本项只管 **余料** 是否再结算回库。

### 7.7 BOM 级 MTS `enableBomLevelMts`

默认关闭。开启后生产计划展开 BOM 时，子件可按库存 MTS 裁剪下层需求。关闭则仅成品级计划策略相关逻辑生效。  
**软占用/补货中心** 与「BOM 级 MTS」不是同一能力，见流程文档 P02。

## 8. 质量门控 `qcGatePolicyByBizScope`

五类业务：来料质检、外协回货检、生产过程检、成品检、出厂质检。

| 策略                      | 行为                               |
| ------------------------- | ---------------------------------- |
| `soft` 弱管控（当期开放） | Toast 预警，不拦截入库/报工/出库   |
| `hard` 强管控             | 阻断下游（当期选项可能置灰未开放） |

## 9. 辅助工具

| 开关     | 作用                                                |
| -------- | --------------------------------------------------- |
| 面积换算 | BOM 下料尺寸 / 采购订货尺寸弹窗；㎡ 入库可长×宽换算 |
| 重量计算 | 型材/密度估算重量并回填                             |

默认常为开启；不需要的客户可关。

## 10. 实施配置速查（答「先配什么」）

| 场景 | 必查参数                                             |
| ---- | ---------------------------------------------------- |
| 一   | 工资推送；业务规则生产模式（快速报工）；计薪口径签字 |

| 五   | 四 + 质检模板；质检门控；报废审批                    |
