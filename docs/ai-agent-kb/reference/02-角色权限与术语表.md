# 角色权限与术语表

## 1. 岗位 → 系统角色映射

一人多岗时合并菜单，按「职责」而非「编制人数」开账号。

| 岗位（可兼职）    | 典型能力                                               | 常用端               |
| ----------------- | ------------------------------------------------------ | -------------------- |
| 系统管理员        | 组织人员、角色、功能参数、业务规则、基础档案、字典     | Web                  |
| 车间主任 / 班组长 | 工单、工序报工审核、报工确认、工时/工资查看            | Web + 小程序主任入口 |
| 工人 / 操作工     | 领任务、报工、查看工时工资；授权后领料/入库            | 小程序为主           |
| 仓管              | 领料发料、出入库、仓库；对内可含库存扣减确认、随货查询 | Web + 小程序         |
| 计划员            | 生产计划、设计任务协同、补货中心                       | Web                  |
| 采购              | 采购申请/订单、供应商、收货协同                        | Web                  |
| 销售              | 销售订单、客户、发货申请                               | Web                  |
| 技术 / 工艺       | 产品、BOM、工艺路线、工序、ECN                         | Web                  |
| 质检              | 质检模板、五类质检、报废、小程序质检任务               | Web + 小程序         |
| 财务 / 老板       | 工资核算查询、关键报表（按需授权）                     | Web                  |

> 前端演示环境可能无完整 permission code；现场以 RBAC/租户产品包授权为准。Agent 回答「看不到菜单」时：查角色授权 → 查场景是否开通 → 查账号是否绑定正确组织。

## 2. 对外说法 ↔ 系统能力

| 对外说法            | 系统能力（实施配置）                                       | 对客是否强调       |
| ------------------- | ---------------------------------------------------------- | ------------------ |
| 快速报工            | 小程序「工序报工·快速报工」和/或登记产出；Web 工序报工审核 | 是                 |
| 任务报工            | 工单下发 → 小程序待领/今日待报工；Web 审核                 | 是                 |
| 工资核算            | 工时配置 + 工时管理 + 工资核算；功能参数「工资推送模式」   | 是                 |
| 领料 / 成品入库     | 领料管理、出入库；小程序领料/成品入库                      | 是                 |
| 库存管理            | 仓库、出入库、库存明细、调拨盘点等                         | 场景四起对外讲     |
| 库存扣减 / 预扣确认 | 功能参数「库存扣减方式」+ 扣减记录菜单                     | **否**（内部配置） |
| 订单到采购闭环      | 销售→设计/BOM→计划→工单/采购→库存                          | 场景四             |
| 质量管理            | 五类质检、模板、报废                                       | 场景五             |

## 3. 业务术语表

| 术语             | 含义                                                                      |
| ---------------- | ------------------------------------------------------------------------- |
| 主数据           | 产品、工序、BOM、仓库、客商等基础档案                                     |
| 供应型态         | 物料自产/外购/外协等，影响自动生成工单或采购                              |
| 计划策略         | 产品上「按单 / 以库存」等标签；**不再**单独作为「审核绝不建计划」唯一开关 |
| 软占用           | 销售审核后按 `min(行需求, 自由备货)` 占用库存，未硬锁批次前的占用账       |
| 自由备货         | 现存量 − 全部软占用                                                       |
| 跨单调拨（占用） | 急单调用他单未发货占用；确认后转移占用并记偿还欠量                        |
| 补货中心         | 计划排产 → 库存预警；可生成补货计划 `BH…` 或采购申请                      |
| 工艺路线         | 产品加工步骤序列；可含并行、选做完成                                      |
| 工序报工         | 按工序登记良品/不良/工时；来源含任务报工、快速报工                        |
| 批量计件         | 按件数报工计薪                                                            |
| 时长报工         | 按工时报工；计薪仅支持计时工资                                            |
| 作业分项         | 工序下可勾选的作业细项（一期多用于追溯；计薪口径以现场配置为准）          |
| 线边仓           | 车间现场仓；自主领料模式下发料入线边，完工从线边扣                        |
| 发料仓           | 仓库侧发料仓；无领料预扣模式常直接扣发料仓                                |
| 下料结算         | 板材/型材等领出后登记实耗、余料回库的结算                                 |
| 按单发货         | 发货优先扣本销售单挂标入库批次                                            |
| 质检门控         | 未检/不合格时对下游的弱预警或强阻断                                       |
| ECN              | 工程变更单                                                                |
| EBOM             | 工程/设计 BOM，常经设计任务审核后落入产品 BOM                             |
| SN / 工业标识    | 单件追溯码；装牌、出库关联                                                |
| 五场景           | 实施分步路径：一报工工资 → 二领料入库 → 三任务报工 → 四订单采购 → 五质量  |

## 4. 报工相关易混概念

| 概念         | 别混淆为                                            |
| ------------ | --------------------------------------------------- |
| 快速报工     | ≠ 不审核；仍可走 Web 审核                           |
| 任务报工     | ≠ 必须有销售订单；可以是手工工单                    |
| 报工确认     | ≠ 工序报工审核；确认侧重主任调整/补贴/推送          |
| 工资推送     | ≠ 工资已发到银行卡；仅系统内对工人可见/进入核算列表 |
| 领料出库     | ≠ 完工消耗；领多少可以不等于 BOM 理论耗用           |
| 库存扣减确认 | ≠ 领料审核；是完工按 BOM 预扣后的账实确认           |

## 5. 计薪口径关键词（实施必对齐）

见 `docs/implementation/attachments/计薪口径确认表.md`，Agent 应引导客户确认：

1. 工资以报工数还是审核调整后数量为准
2. 审核可否改数量/工时
3. 拒绝后能否重报
4. 推送模式：报工即推送 / 审核后 / 手动
5. 计件/计时公式、不良是否计薪
6. 补贴规则
7. 工资归属：报工人 / 执行人 / 其他
8. 多人协作：均分 / 主操作人 / 按比例

**未签字不得导入工价、不得开始试点。**
