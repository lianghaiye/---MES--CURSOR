# FAQ · 实施顾问常见问题

> 面向：售前、实施顾问、交付经理。  
> 与 `docs/implementation/I-DOMS场景化实施手册.md` 配套；冲突时以实施手册+现场版本为准。

---

## 1. 选型与场景

### 1.1 客户张口就要「全套 MES」，如何压场景？

用四维诊断：组织分工、仓管/采购/质检是否要系统化、数据基础、人员认知。  
数据弱或认知弱 → **场景一**；有仓管诉求但派工随意 → **二**；已有派工 → **三**；组织与主数据中强 → **四**；出厂检硬性 → **五**。

话术：「先卖清一个老板听得懂的结果，两周见效，再往上加。」

### 1.2 五场景依赖的主数据最低集？

| 场景 | 最低主数据                      |
| ---- | ------------------------------- |
| 一   | 人员、产品、工序、工价          |
| 二   | 一 + 仓库、常用物料             |
| 三   | 二 + 工单/任务习惯、工艺路线    |
| 四   | 三 + 客户/供应商、BOM、计划逻辑 |
| 五   | 四 + 质检模板/不良项            |

### 1.3 「库存扣减」能不能写成合同场景名？

**不能。** 对内配置、对外不出现为独立卖点。检查清单见 `attachments/实施配置备忘-库存相关.md`。

### 1.4 场景二和场景三怎么选？

- 派工仍口头、要先留出入库痕迹 → **二（快速报工）**
- 愿意工单任务约束 → **三（任务报工）**  
  路径：一→二或一→三均可，再汇合到四。

### 1.5 能不能跳过一直接上四？

组织与主数据强可以直上四，仍建议 **小范围先跑通报工工资**，避免四条线同时炸。

## 2. 启动与口径

### 2.1 第一周必做哪几件事？

1. 启动会：书面确认本期场景范围（砍掉超范围期望）
2. 签《计薪口径确认表》（含工资场景时）
3. 主数据采集（Excel 附件 S1～S5）
4. 角色岗位映射（一人多岗合并）
5. 配置业务规则 + 功能参数并截图存档

### 2.2 计薪口径没签字能不能先导工价？

**不能。** 手册明确：未签字不得导入工价、不得开始试点。

### 2.3 工资推送默认选哪个？

多数离散厂试点推荐 **审核后推送** 或 **手动推送**，避免未审数据进工人视野引发争议。老板强要求透明可选报工即推送。

### 2.4 生产模式怎么配？

| 客户现状           | 建议                           |
| ------------------ | ------------------------------ |
| 先跑工资、无工单   | 极简 + 快速报工；扣减=不领料   |
| 有工单要领料       | 标准或极简·任务；扣减=自主领料 |
| 有工单不领料要倒冲 | 完工后预扣+确认（无领料）      |

## 3. 功能参数配置决策树

### 3.1 库存扣减三档怎么选？

| 现场习惯                  | 选                                        |
| ------------------------- | ----------------------------------------- |
| 无工单/极简报工           | `no_issue` 不领料                         |
| 有工单、不领料、按BOM倒冲 | `post_complete_by_report`（不可自动确认） |
| 有工单、先领到线边再耗用  | `self_issue_by_actual`（可自动确认）      |

### 3.2 哪些自动审批建议先关？

销售订单、采购订单、价格变更——管理严的企业先关，跑顺再开。  
领料/成品入库——小厂可开，减少仓管等待。  
库存扣减自动确认——仅自主领料模式有意义；倒冲无领料模式开了也不自动。

### 3.3 自动生成单据建议？

主数据供应型态未清洗前 **先全关**，手工跑通样例后再按型态打开，避免审核一单炸出一堆错单。

### 3.4 发货选按单还是 FIFO？

- 按订单锁货、防发错单 → **按单发货**
- 标准品大仓混发 → **FIFO**  
  强制按单生产行在按单模式下不能拿自由备货凑。

### 3.5 质检门控怎么跟客户讲？

当期仅弱管控：预警不拦截。若客户要「不检不能出厂」，记录为后续强管控需求，勿承诺当期强拦。

## 4. 主数据清洗

### 4.1 产品编码混乱怎么办？

场景一先定试点产品对照表（旧名→新编码），全厂编码治理放到扩场景前专项。不要一上来全量导入脏数据。

### 4.2 工序口头叫法不统一？

必须先统一工序名再配工价。否则工资永远对不齐——这是场景一核心话术。

### 4.3 BOM 不齐能否上场景四？

标准产品至少 1～2 个完整 BOM 样例才能验收「订单→计划→工单/采购」。非标走设计任务/EBOM，周期要单列。

### 4.4 双单位 / 下料 / 按重结算客户怎么处理？

先读：

- `docs/双物料单位-单物料双计量-vs-SKU拆解-决策说明.md`
- `docs/结算单位-按件库存按重结算.md`
- 功能参数下料结算策略

选型错误会导致库存与结算双账混乱，售前就要拍板。

## 5. 角色与权限

### 5.1 小厂只有三个人怎么开角色？

合并：管理员兼主任兼仓管；工人账号独立。菜单做精简，不要按教科书岗位硬开 10 个账号。

### 5.2 前端没有 permission code？

演示/部分版本可能无细粒度按钮码。现场以实际 RBAC/产品包为准；答疑时引导查角色与租户授权，而非只查前端路由。

### 5.3 扣减记录菜单给谁？

仓管或管理员；**写入实施配置清单**，不写进客户 PPT。

## 6. 试点与验收

### 6.1 场景一验收标准？

工人会报、主任会审、财务/老板认可一版工资结果；系统明细 vs Excel 差异可解释。

### 6.2 场景二多验什么？

领一笔料、报一笔工、入一笔成品能对上；工资链路不被破坏。

### 6.3 场景三多验什么？

工单下发→领取→报工→审核→领料→入库→工资全链路。

### 6.4 场景四验收一句话？

从一张销售订单能追到计划、工单、采购、库存与报工工资。

### 6.5 场景五？

抽一张订单能看到生产记录 + 出厂质检/报废留痕。

检查清单文件：`docs/implementation/checklists/`。

## 7. 现场排障（实施视角）

### 7.1 客户说「自动生成乱了」

立即：关闭自动生成 → 清理错单 → 修供应型态 → 用样例单验证 → 再谨慎打开。

### 7.2 Web 与小程序工资推送不一致

查历史值 `auto` 与 `on_report` 归一；核对两端读取的配置源是否同一环境。

### 7.3 演示环境数据隔夜没了 / 混乱

演示可能用 localStorage。重要培训用正式/稳定环境；教客户区分演示与生产。

### 7.4 客户把 I-DOMS 打印和智衣打印客户端混为一谈

按日志/安装目录/MQTT 纠正：

- `print_client_service` + `zhiyi-print-client` → OMS
- `mes_print_client_service` → 智衣通 MES
- I-DOMS → 浏览器打印

### 7.5 采购入库状态和文档不一致

以云效入库状态机需求为准；mock/演示选项可能简化，交付前对照现场后端。

## 8. 售前话术速查

| 场景 | 30 秒                                                        |
| ---- | ------------------------------------------------------------ |
| 一   | 工人手机报工，主任一审，计件工资自动汇总——先把人的钱算清楚。 |
| 二   | 在算清工资同时，领料、成品入库留单，料和货也对得上。         |
| 三   | 有工单有任务再报工，产量、物料、工资挂在任务上。             |
| 四   | 从销售订单到 BOM、计划、生产、库存、采购一条链。             |
| 五   | 在四基础上加出厂质检和报废，交期与质量都能留痕。             |

### 8.1 客户问「你们有没有 AI」？

本素材库即支撑智能问答 Agent：操作指导、FAQ、报错、流程。回答边界：不编造未上线模块；参数以现场配置为准。

### 8.2 客户问能否定制？

记录需求进云效/版本规划；实施期区分「配置可满足」与「需研发」。勿现场口头承诺工期。

## 10. 实施高频「坑」清单

1. 未签计薪口径就导工价
2. 供应型态未洗就开自动生成
3. 倒冲模式误开库存扣减自动确认（无效且误导）
4. 对外 PPT 写了「库存扣减场景」
5. 场景四与车间报工同时全厂铺开
6. 盘点只教小程序不教 PC 过账
7. 质检承诺强管控但当期仅弱管控
8. 按单发货与 FIFO 讲反
9. 线边仓未建就上自主领料
10. 把演示环境当生产环境培训老板
