# FAQ · 客户常见问题

> 面向：现场工人、车间主任、仓管、销售、采购、质检、老板。  
> Agent 回答时给出菜单路径；涉及库存扣减用业务语言，不主动推销「扣减」概念。

---

## A. 登录账号与权限

### A1. 为什么我登录后很多菜单是空的 / 没有？

**可能原因：** 角色未授权；租户产品包未包含该模块；账号进错组织/环境。  
**处理：** 联系管理员核对角色；确认当前环境（测试/正式）；场景未购买的模块本来就没有。

### A2. 小程序和电脑不是同一个账号体系吗？

人员在 Web 基础档案维护，小程序账号需绑定。未绑定会出现能登 Web 不能报工，或反之。

### A3. 我是主任，为什么小程序没有「报工确认」？

该入口仅主任类角色。检查角色是否含主任权限，或是否被做成仅 Web 审核。

## B. 报工相关

### B1. 工人不会报工，最短怎么教？

1. 打开小程序 → 工序报工
2. 有任务：待领 → 领取 → 今日待报工 → 填良品数 → 提交
3. 无任务（快速）：快速报工 → 选产品工序 → 填数 → 提交
4. 告诉工人：报完要等主任审，工资不一定马上能看见

### B2. 提示「请先领取任务后再报工」？

当前是任务报工模式。先到「待领」领取，再报工。若企业要用快速报工，让管理员改业务规则生产模式。

### B3. 提示「报工数量不能超过待报 n 件」？

不能超过本任务剩余可报数量。检查是否重复报、是否领错任务、主任是否改过排产数。

### B4. 快速报工入口没有了？

业务规则为标准任务模式或极简·任务时，可能关闭快速报工。属配置而非故障。

### B5. 扫码提示「二维码无效或已损坏」？

重新在 Web 打印工单/工序码；勿用截图模糊码；确认扫的是本系统码而非他厂标签。

### B6. 扫码提示「工单已关闭超过 7 天」？

超期工单不允许再扫码报。需主任在 Web 侧按制度处理（重开/补单/线下），不要强行扫码。

### B7. 提示「该工序已报工」？

该任务工序已有报工记录。查看「我的记录」；若被拒可按口径重报；若要改数需主任按规则撤回/拒绝后处理。

### B8. 时长报工能不能算计件？

不能。系统规则：**时长报工仅支持计时工资**。

### B9. 不良数量怎么填？提示「请分配全部不良原因」？

不良总数必须按不良品项分摊完毕，各项之和等于不良数。

### B10. 多人一起干一个工序，工资算谁的？

以《计薪口径确认表》为准：均分 / 主操作人 / 按比例。实施时必须签字，避免月底扯皮。

### B11. 报工填错了怎么办？

- 未审核：联系主任拒绝后重报（若口径允许）
- 已审核：通常不可再改数量/单价；走主任/管理员制度内调整，勿自行改主数据凑数

### B12. 电脑上可以代替工人报工吗？

支持导入或 Web 侧录入（视权限）。但试点阶段建议工人自己手机报，保证现场习惯养成。

## C. 工资相关（最高频）

### C1. 工人报完了，工时工资里为什么是空的？

按序查：

1. **系统管理 → 功能参数 → 工资推送**
   - 手动推送：主任是否已推送？
   - 审核后推送：是否已审核通过？
   - 报工即推送：是否报工成功？
2. 是否看错人员/月份筛选
3. 是否被拒绝的报工

### C2. 审核通过了还是没有工资？

若模式是「手动推送」，审核≠推送。到 **报工管理 → 工资核算** 勾选推送。

### C3. 工资金额和原来 Excel 不一致？

对账检查：工价主数据、审核是否改过数量、不良是否计薪、补贴、归属人、是否含未推送明细、多人协作规则。

### C4. 系统工资会直接打到银行卡吗？

不会。系统提供核算明细与推送可见性；发放仍走企业财务/银行流程。

### C5. 主任能不能改工人报的数量？

以计薪口径为准。若允许，在审核前/报工确认中调整；已审核后通常锁定。

### C6. 次品有没有工资？

口径表约定：不计或按百分比。系统按不良品项与规则执行。

### C7. 改了产品单价，以前的报工会变吗？

已审核记录通常不随主数据回溯改价。新报工用新价。历史调整走制度。

## D. 工单与生产

### D1. 工单下发了，工人小程序看不到？

检查：是否已下发；任务是否派到该人/组别；小程序是否刷新；工单是否暂停/终止。

### D2. 为什么不能改工单报工数量？

若已有任务完成报工，系统可能拦截：需先撤回报工状态再修改。

### D3. 工单完成后库存怎么少了？

完工可能按 BOM 做库存扣减（预扣+确认）。日常表现为原料账减少。具体规则由管理员配置；现场把领料和入库做对即可。

### D4. 能不能暂停/终止工单？

可以。暂停后不可继续正常执行；终止需注意已报工与物料处理制度。

## E. 领料与库存

### E1. 领料提交后一直待审核？

未开启「领料申请」自动审批。找有权限的人在 Web 审核；或管理员评估后打开自动审批。

### E2. 提示「库存不足」/「可用库存不足」？

仓库现存量不够。先查库存明细；走采购/调拨/改数量；按单发货时还要看是否本单批次不足。

### E3. 提示「强制按单：本单按单库存不足」？

发货规则为按单发货或行强制按单生产：不能拿他单或自由备货随便凑。需本单入库或调整发货策略（管理员）。

### E4. 领了很多料，为什么账还对不上完工？

领料数量可以不等于理论消耗。自主领料模式下，领到线边仓；真正按 BOM 消耗在完工确认。需做下料结算的物料还要登记实耗。

### E5. 小程序成品入库后，库存为什么没增加？

入库单可能仍待审批。到 Web 入库管理审核，或开启成品入库自动审批。

### E6. 盘点提交了为什么库存没变？

小程序只负责录入提交；**审核过账在电脑上**。还要看是否需手动「生成盘盈盘亏」。

### E7. 调拨出库了，对方仓怎么还没有？

若开启「调拨需入库方签收」，对方需确认入库；未开启则应自动完结——查调拨单状态。

## F. 销售与发货

### F1. 订单审核后为什么自动出了工单/采购单？

功能参数「自动生成单据」已勾选，且物料供应型态匹配。不需要可让管理员关闭对应勾选。

### F2. 为什么不能申请发货？

常见：订单非进行中；存在待审核订单变更；可发数量不足；权限不足。

### F3. 库存明明有，为什么订单提示要补货？

看的是 **自由备货**（现存量 − 他单软占用）。库存被他单占用。可走跨单调拨占用或等他单释放。

### F4. 能不能把 A 单的货先发给加急的 C 单？

通过库存提醒中的跨单调拨（占用转移），确认后占用转到 C，A 记偿还欠量。不是直接乱发批次（还受按单发货规则约束）。

### F5. 出厂没质检能不能出库？

当期质检门控多为 **弱管控**：可出库但预警。强管控未开放前不会强拦。

## G. 采购与外协

### G1. 采购申请从哪来的？

计划缺料、补货中心、销售审核自动、或手工创建。

### G2. 外协发出去的料怎么管？

走外协发料出库；收回走外协收货，可做外协回货检。

### G3. 采购价改了订单怎么变？

走采购订单价格变更单；自动审批开启则提交即回写。

## H. 质量

### H1. 质检任务小程序没有？

未授权或未生成待检任务。建议 Web 先建任务再手机填。

### H2. 部分合格怎么填？

须填写处置数量，且合格入库+退货+换货等合计不超过质检数量。

### H3. 不质检能入库/出库吗？

弱管控下通常可以但有预警；以功能参数门控为准。

## I. 主数据与变更

### I1. 产品名/工序名改了，工资乱了？

编码与工序名变更会导致工价失配。应走变更流程，并冻结期间报工规则。

### I2. BOM 改了，在制工单用哪套？

已下发在制一般沿用开单时快照或按 ECN 策略；新单用新 BOM。具体以现场版本与 ECN 为准。

## J. 打印与标签

### J1. 工单二维码怎么打？

在 Web 工单/报工相关页使用浏览器打印预览。  
若现场还有独立「打印客户端」程序，请用安装目录/日志识别：`print_client_service` 为智衣 OMS 客户端，不是本 I-DOMS Web 打印本身。

### J2. SN / 铭牌扫不出来？

检查工业标识是否已申请、是否作废、是否已装牌；码制是否符合 4–64 位规则。

## K. 老板关心的问题

### K1. 上系统要停产多久？

场景一建议 1～2 周试点，不必全厂停产。先一条线。

### K2. 是不是必须上全套订单采购质量？

不是。可按五场景分步：先报工工资，再领料入库，再任务，再订单采购，再质量。

### K3. 和 ERP 什么关系？

I-DOMS 侧重制造执行、报工计薪、车间与库存协同。是否替换 ERP 以合同范围为准，实施忌承诺「一夜替换」。

### K4. 数据会丢吗？存在哪？

以企业部署环境（云/本地）为准；演示环境可能用浏览器本地缓存，正式环境应为服务端持久化。重要操作以正式环境为准。
