# 报错信息库

> 用法：按用户看到的**原文或关键词**检索。  
> 结构：报错文案 → 含义 → 可能原因 → 处理步骤 → 相关模块。  
> 文案来自 Web/小程序业务校验；现场后端可能有额外错误码，一并收录时可追加本节。

---

## 1. 库存 / 出库 / 扣减

### 1.1 库存不足

| 项   | 内容                                                          |
| ---- | ------------------------------------------------------------- |
| 含义 | 目标仓库存不够完成本次扣减/出库                               |
| 原因 | 未入库、被他单占用、仓选错、批次不足                          |
| 处理 | 查库存明细与批次 → 入库/调拨/采购 → 或减少出库量 → 确认仓正确 |
| 模块 | 库存、出库、扣减                                              |

### 1.2 可用库存不足（需 X，可用 Y）

| 项   | 内容                                   |
| ---- | -------------------------------------- |
| 含义 | 可用量（可能已扣软占用）小于需求       |
| 处理 | 对比现存量与占用；释放或调拨占用；补货 |

### 1.3 强制按单：本单按单库存不足（需 X，可用 Y）

| 项   | 内容                                                           |
| ---- | -------------------------------------------------------------- |
| 含义 | 按单发货/强制按单生产，本单可发批次不够                        |
| 处理 | 完成本单入库；或调整发货规则（需管理员评估）；不可随便拿他单货 |

### 1.4 「{产品}」库存 X，订单 Y，库存不足请先补货或改数量

| 项   | 内容                                        |
| ---- | ------------------------------------------- |
| 含义 | 下单/审核时库存预警                         |
| 处理 | 改订单数量；走补货中心；或接受后续生产/采购 |

### 1.5 当前为「不领料」模式，不生成工单完工库存扣减

| 项   | 内容                                                |
| ---- | --------------------------------------------------- |
| 含义 | 功能参数库存扣减=`no_issue`，完工跳过扣减           |
| 处理 | 若业务需要倒冲/领料扣减，改库存扣减模式（实施评估） |

### 1.6 当前库存扣减模式不生成工单完工扣减

| 项   | 内容                                |
| ---- | ----------------------------------- |
| 含义 | 当前模式不适用完工扣减生成          |
| 处理 | 核对 `inventoryDeductMode` 是否配错 |

### 1.7 仅待确认记录可确认 / 扣减明细不能为空

| 项   | 内容                                          |
| ---- | --------------------------------------------- |
| 含义 | 扣减单状态不对或无明细                        |
| 处理 | 打开待确认单据；检查 BOM/完工数量是否生成明细 |

### 1.8 确认已超过 N 天，单据已锁定，不可再操作

| 项   | 内容                                  |
| ---- | ------------------------------------- |
| 含义 | 超时锁定防篡改                        |
| 处理 | 走管理员/制度内冲正流程，勿强改历史单 |

### 1.9 「{物料}」领料数量须大于 0 / 请选择领入仓库

| 项   | 内容                         |
| ---- | ---------------------------- |
| 处理 | 填正数量；选择线边仓或目标仓 |

## 2. 报工 / 工资

### 2.1 该记录已审核 / 已审核记录不可拒绝

| 项   | 内容                               |
| ---- | ---------------------------------- |
| 处理 | 已审数据锁定；制度内冲销或下期调整 |

### 2.2 请填写拒绝原因

| 项   | 内容                               |
| ---- | ---------------------------------- |
| 处理 | 拒绝时报工必须填原因，方便工人重报 |

### 2.3 已审核数据不可调整 / 不可修改单价 / 不可修改计薪方式

| 项   | 内容                               |
| ---- | ---------------------------------- |
| 处理 | 审核前调整；或按财务制度做专项修正 |

### 2.4 请选择待推送明细 / 所选明细当前状态不可推送

| 项   | 内容                                     |
| ---- | ---------------------------------------- |
| 含义 | 手动推送时选择集无效                     |
| 处理 | 筛选未推送且状态允许的明细；确认推送模式 |

### 2.5 仅已报工数据可审核

| 项   | 内容               |
| ---- | ------------------ |
| 处理 | 确认工人已提交报工 |

### 2.6 时长报工仅支持计时工资

| 项   | 内容                                 |
| ---- | ------------------------------------ |
| 处理 | 改计薪方式为计时，或改用批量计件报工 |

### 2.7 请至少勾选一条作业分项 / 分项「xxx」缺少单价，无法计薪

| 项   | 内容                         |
| ---- | ---------------------------- |
| 处理 | 勾选分项；补齐分项单价主数据 |

### 2.8 报工数量不能超过待报 {n} 件

| 项   | 内容                       |
| ---- | -------------------------- |
| 处理 | 降低数量；检查是否重复报工 |

### 2.9 请分配全部不良原因

| 项   | 内容                |
| ---- | ------------------- |
| 处理 | 不良分摊合计=不良数 |

## 3. 小程序扫码报工

### 3.1 二维码无效或已损坏

重新打印；保证清晰；确认码类型正确。

### 3.2 工单已关闭超过 7 天

超期不可扫码报；Web 侧制度处理。

### 3.3 请先领取任务后再报工

先待领领取。

### 3.4 该工序已报工

查我的记录；拒绝后重报或主任处理。

---

## 4. 入库 / 盘点

### 4.1 入库数量须大于 0

填写正数。

### 4.2 工单不存在或未完成

成品按工单入库时，工单需存在且满足完成规则。

### 4.3 请先选择仓库

补选仓库。

### 4.4 已提交，请到 PC 审核

盘点小程序提交成功；到 Web 审核/过账。

---

## 5. 质检

### 5.1 仅待质检任务可提交

任务状态不对；刷新列表。

### 5.2 合格入库+退货+换货不可超过质检数量

调整处置数量。

### 5.3 部分合格请至少填写一项处置数量

部分通过必须填处置。

### 5.4 上游工序质检待完成 / 不合格（预警）

弱管控提示；先完成上游检或按制度放行。

### 5.5 按模板规则「xxx」，以下项未达标，不能判定通过

补测或判定不通过；检查模板关键项配置。

### 5.6 模板规则为「关键项必须达标」，但未勾选任何关键项

先编辑模板勾选关键项。

---

## 6. 销售 / 订单变更

### 6.1 仅「待审核」状态可审核 / 请填写拒绝理由

状态或必填项不满足。

### 6.2 存在待审核的订单变更，通过前不可申请发货

先审完变更单。

### 6.3 仅「进行中」的销售订单可申请订单变更

订单状态不对。

### 6.4 已有待审核的订单变更，请先完成审核

同时只能一单一条待审变更。

### 6.5 「{产品}」销售数量不能小于已占用发货数量 N

变更后数量不能小于已发/已占用发货。

### 6.6 请至少修改一项基本信息或一行明细

空变更不能提交。

### 6.7 存在已装牌或已出库的工业标识，禁止反审

先处理 SN/出库再反审。

单据状态不对。

## 11. Agent 回答模板

当用户粘贴报错时：

1. 原文匹配本库条目
2. 用一句话解释含义
3. 给出 2～4 步处理（含菜单路径）
4. 若涉及参数，指向「系统管理 → 功能参数/业务规则」
5. 仍失败：收集单据号、截图、账号角色、环境，转实施/运维
