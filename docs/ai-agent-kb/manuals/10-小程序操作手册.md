# 操作手册 · 微信小程序

**技术形态：** uni-app（Vue3），主目标微信小程序；Tab：**工作台 / 我的**。

## 1. 登录与权限

- 使用企业分配的小程序账号（与 Web 人员档案绑定）
- 看不到入口：角色未授权或场景未开通该功能
- 「报工确认」仅车间主任类角色可见

## 2. 工序报工

### 2.1 任务报工

1. 工作台 → **工序报工** → **待领** → 领取任务
2. **今日待报工** → 进入填写：
   - 排产/待报数量
   - 报工模式：批量计件 / 时长报工
   - 良品 / 不良数量；不良原因分摊
   - 工作时长（时长模式）
   - 执行人、现场图片
   - 作业分项勾选（若启用）
3. 提交 → 等待 Web 审核

**拦截示例：** 请先领取任务后再报工；报工数量不能超过待报 n 件；请分配全部不良原因；时长报工仅支持计时工资。

### 2.2 快速报工

1. 工序报工 → **快速报工**
2. 选择产品、工序、数量等 → 提交
3. 是否开放取决于业务规则「生产模式」

### 2.3 扫码报工

1. 扫描工单/工序二维码
2. 进入填写页（分项任务走任务报工，不进快速报工）
3. 拦截：二维码无效或已损坏；工单已关闭超过 7 天；该工序已报工

### 2.4 我的记录

查看本人历史报工及状态（待审核/已审核/已拒绝）。

## 3. 报工确认（主任）

1. 调整良品/不良/工时（若口径允许）
2. 补贴录入
3. 推送确认（配合手动推送模式）

## 4. 工时工资

查看已报工/已审核、良品不良、补贴、质量扣款、本月计薪。  
**看不见数据：** 先问工资推送模式，再问是否已审核/已推送。

## 5. 领料管理

| 模式        | 用途       |
| ----------- | ---------- |
| 工单领料    | 按工单领   |
| 订单领料    | 按销售订单 |
| 快速 / 批量 | 少步骤领料 |

提交后写 PC 出库侧；是否免审看 **自动审批 → 领料申请**。  
校验：领料数量须大于 0；请选择领入仓库。

## 6. 成品入库

工单/批量/快速入库 → 生成入库单（常待审批）→ PC 审核或自动审批。  
校验：入库数量须大于 0；工单不存在或未完成（视规则）。

## 7. 质检任务

五类分流执行检验；提交结论与处置数量。仅待质检任务可提交。

## 8. 盘点管理

建单 → 录实盘 → 提交。提示「已提交，请到 PC 审核」。过账只在 Web。

## 9. 其他入口

| 入口     | 说明                       |
| -------- | -------------------------- |
| 待办任务 | 拆解等领取/分发/执行       |
| 扫码查单 | SN → 销售单等              |
| 铭牌任务 | 刻录/装牌确认              |
| 审批管理 | 多为占位，勿当完整审批中心 |

## 10. 与 PC 对齐要点（培训必讲）

| 主题         | 结论                |
| ------------ | ------------------- |
| 审核报工     | 在 Web              |
| 工资可见时机 | 功能参数工资推送    |
| 领料免审     | 自动审批·领料申请   |
| 线边仓       | Web 仓库管理维护    |
| 盘点过账     | 仅 PC               |
| 质检建单     | 建议 Web 建、手机填 |
