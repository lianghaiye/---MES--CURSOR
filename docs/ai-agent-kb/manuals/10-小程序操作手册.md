# 操作手册 · 微信小程序（手把手）

> 适合：工人、班组长、现场质检、兼仓管的现场人员。  
> 建议：第一次使用时，**一边看本文一边在手机上点**；遇到红字提示，先查本文「常见提示」表。

电脑端怎么审报工、怎么推工资：看《05》《06》。本册只教手机。

---

## 0. 打开与登录

1. 微信中找到公司提供的小程序入口（名称以现场为准）。
2. 使用管理员分配的账号登录。
   - 若提示无权限/进不去：联系管理员检查是否建了人员档案并绑定小程序。
3. 底部一般有两个 Tab：
   - **工作台**：所有业务入口
   - **我的**：个人信息等

### 0.1 工作台有哪些入口？

常见卡片（没有的就是没开通或没权限）：

| 入口                | 谁常用                     |
| ------------------- | -------------------------- |
| 工序报工            | 工人必用                   |
| 工时工资            | 工人看自己的钱             |
| 报工确认            | 主任                       |
| 领料管理            | 班组/仓管                  |
| 成品入库            | 班组/仓管                  |
| 质检任务            | 质检员                     |
| 盘点管理            | 仓管                       |
| 待办任务            | 拆解等特殊任务             |
| 扫码查单 / 铭牌任务 | 按企业启用                 |
| 审批管理            | 多为占位，勿当完整审批中心 |

## 1. 工序报工 —— 任务报工（完整点击路径）

> 适用：公司用工单派工。工单必须已被主任 **下发**。

### 1.1 领取任务

1. 工作台点 **工序报工**。
2. 顶部切换到 **待领任务**（或「待领」）。
3. 在列表找到自己的任务（可看产品、工序、工单号）。
4. 点任务进入详情 → 点 **领取任务**。
5. 出现「领取成功」类提示后，任务进入待报工。

**领不到？**

- 主任是否已下发工单？
- 任务是否派给别的班组/别人？
- 下拉刷新列表再看。

### 1.2 去报工

1. 顶部切换到 **今日待报工**。
2. 找到刚领取的任务 → 点 **去报工**。
3. 先看页面上方数字：
   - **排产数量**
   - **待报工**（你最多只能报这么多，超了会被拦）

### 1.3 填写报工页（逐项说明）

根据报工类型，页面字段略有不同：

#### A. 批量计件（最常见）

| 字段       | 怎么填                                                    |
| ---------- | --------------------------------------------------------- |
| 良品数量   | **必填**，今天这道工序合格件数                            |
| 不良品数量 | 有不良就填；没有填 0 或不填（以页面为准）                 |
| 不良原因   | 有不良时，必须把不良数量按原因**分摊完**，加起来=不良总数 |
| 作业分项   | 若显示分项，按要求勾选或填数量；缺单价可能无法计薪        |
| 执行人     | 默认自己；代报按厂规改                                    |
| 现场图片   | 选填，按厂规是否必拍                                      |
| 备注       | 选填                                                      |

#### B. 时长报工

| 字段             | 怎么填                                            |
| ---------------- | ------------------------------------------------- |
| 工作时长（小时） | **必填**                                          |
| 开始/结束时间    | 按页面填                                          |
| 良品/不良        | 按实际                                            |
| 说明             | 时长报工一般 **只能算计时工资**，不要指望按件计价 |

### 1.4 提交

1. 检查无误 → 点 **提交报工**。
2. 成功后可到 **我的记录** 查看，状态一般为 **待审核**。
3. 等待主任在电脑上审核；被拒绝则看原因，用 **重新提交**（若有）或按主任要求重报。

### 1.5 批量报工

1. 在今日待报工勾选多条。
2. 底部出现 **批量报工 (n)** → 按指引一次提交。  
   （适合相同规则的多笔任务，首次建议仍一笔笔练熟。）

## 2. 工序报工 —— 快速报工（完整点击路径）

> 适用：公司允许不领工单、自己选产品工序报工。入口没有则说明管理员关了快速报工。

1. 工序报工 → 顶部 **快速报工**。
2. 点 **+ 新增快速报工**（或点「最近常报工序」）。
3. **选择产品** → **选择工序**。
4. 按计件/时长填写良品不良等（同 §1.3）。
5. 点 **提交报工**。
6. 到我的记录确认待审核。

---

## 3. 扫码报工

1. 使用小程序扫一扫（或报工页扫码入口，以版本为准）。
2. 扫描主任打印的工单/工序二维码。
3. 进入填写页后按 §1.3 填写提交。
4. 注意：带作业分项的任务扫码走 **任务报工**，不会进快速报工。

| 提示                 | 怎么办                     |
| -------------------- | -------------------------- |
| 二维码无效或已损坏   | 让主任重新打印清晰码       |
| 工单已关闭超过 7 天  | 不能再扫，找主任走补单制度 |
| 请先领取任务后再报工 | 先去待领领取               |
| 该工序已报工         | 打开我的记录查看；勿重复报 |

---

## 4. 报工时常见提示（工人速查表）

| 提示原文                  | 你该做什么                   |
| ------------------------- | ---------------------------- |
| 请先领取任务后再报工      | 回待领领取                   |
| 请填写报工数量            | 良品/数量不能空              |
| 报工数量不能超过待报 n 件 | 少报；或确认是否已报过       |
| 请分配全部不良原因        | 把不良按原因分完             |
| 时长报工仅支持计时工资    | 别选计件；或改用计件报工方式 |
| 请至少勾选一条作业分项    | 勾分项                       |
| 分项缺少单价，无法计薪    | 找管理员补工价               |

## 5. 工时工资（工人看自己的钱）

1. 工作台 → **工时工资**。
2. 浏览每笔：报工时间、时长、良品/不良工资、补贴等。
3. 点进详情看计薪构成。
4. 可筛选已审核、查看本月合计。

### 5.1 为什么是空的？

空态常见文案：**暂无已推送的工时工资记录**。

请按顺序问主任/自己：

1. 报工成功了吗？
2. 主任审核通过了吗？
3. 公司工资是「报工就可见 / 审完可见 / 要手动推送」哪一种？
4. 若是手动推送——主任推了吗？
5. 是否登录错账号、看错月份？

**系统里的计薪明细不是银行卡到账通知。**

## 6. 报工确认（仅主任）

若你的工作台有 **报工确认**：

1. 进入后查看待确认任务。
2. **调整**：改良品/不良/工时/补贴（按厂规）。
3. **推送确认**：推给工人确认。
4. 与电脑「报工管理 → 报工确认」配合使用。

普通工人没有此入口是正常的。

## 7. 领料管理（手把手）

1. 工作台 → **领料管理**。
2. 选一种方式：
   - **工单领料**：选工单（可单工单或批量合并，以页面为准）
   - **订单领料**：按销售订单找关联工单
   - **快速领料**：少步骤直接领
3. **必须选择领入仓库**（一般是线边仓）。  
   提示大意：物料从领料仓出库后领入此处暂存。
4. 编辑明细数量（须大于 0）。
5. 点 **提交领料申请** → 「提交成功」。
6. 之后：
   - 若公司要审核：等电脑通过；
   - 仓管在电脑出库确认后，账上才真正出库。

| 提示             | 处理           |
| ---------------- | -------------- |
| 请选择领入仓库   | 先选仓         |
| 领料数量须大于 0 | 填正数         |
| 暂无领料申请…    | 点上方按钮新建 |

---

## 8. 成品入库（手把手）

1. 工作台 → **成品入库**。
2. 选：
   - **工单入库**（单笔/批量）
   - **快速入库**（直接选产品）
3. 填入库数量（须大于 0）。
4. 点 **提交入库申请** → 「提交成功」。
5. 列表可能显示入库单号或「待生成入库单」。
6. **电脑仓管确认入库后，成品仓库存才会增加**（除非开了成品入库自动审批）。

| 提示               | 处理                         |
| ------------------ | ---------------------------- |
| 工单不存在或未完成 | 检查工单；未完成可能不允许入 |
| 入库数量须大于 0   | 填正数                       |

---

## 9. 质检任务（手把手）

1. 工作台 → **质检任务**。
2. 进入对应类型（来料/外协回货/过程/成品/出厂）。
3. 打开 **待质检** 任务。
4. 按项填写/勾选，必要拍照。
5. 选结论；部分合格要填处置数量。
6. 提交。

建议质检单由电脑先生成；手机只填报。

---

## 10. 盘点管理（手把手）

1. 工作台 → **盘点管理** → 新建。
2. 选仓库，录入实盘。
3. 提交。出现「已提交，请到 PC 审核」→ **到此手机工作结束**。
4. 电脑 **库存管理 → 盘点管理** 审核并过账后，库存才变。

## 13. 手机 ↔ 电脑对照（班前会讲 2 分钟）

| 手机做了…    | 电脑谁接着做                     |
| ------------ | -------------------------------- |
| 提交报工     | 主任：报工管理 → 工序报工 → 审核 |
| 仍无工资     | 主任/财务：按推送模式审核或推送  |
| 提交领料     | 审核（若需）+ 库存出库确认       |
| 提交成品入库 | 库存入库确认                     |
| 提交盘点     | 盘点审核 + 过账                  |
| 填实质检     | 质检完成后生成入库等后续         |
