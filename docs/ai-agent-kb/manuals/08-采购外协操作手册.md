# 操作手册 · 采购与外协

**模块路径：** 顶栏 **采购管理**、**外协管理**

## 1. 采购闭环总览

```
需求来源（计划缺料 / 补货中心 / 手工 / 销售审核自动）
  → 采购申请
  → 采购订单（询价/定价）
  → 审核
  → 收货
  → 入库（可关联来料质检）
  → 结算
```

## 2. 采购申请

### 2.1 来源

| 来源         | 说明                                                |
| ------------ | --------------------------------------------------- |
| 生产计划     | 展开 BOM 后外购件生成申请                           |
| 补货中心     | 低库存建议采购                                      |
| 销售审核自动 | 功能参数「自动生成单据 → 采购申请单」+ 供应型态外购 |
| 手工         | 采购员自建                                          |

### 2.2 状态

草稿 → 待处理 → 处理中 → 处理完成；可作废。

## 3. 采购订单

### 3.1 操作

1. 由申请转订单，或直接建单
2. 选择供应商、物料、数量、单价、交期
3. 提交审核 → 待审核 → 进行中
4. 可撤回（回到可编辑）、重新提交、作废

### 3.2 自动审批

功能参数勾选「采购订单」后提交即通过。

### 3.3 价格变更

采购订单价格变更单；勾选自动审批则提交即回写有效价。

### 3.4 结算单位注意

存在「按件库存、按重结算」等企业口径，见 `docs/结算单位-按件库存按重结算.md` 与结算规则菜单。

## 4. 收货与入库

1. **采购收货** 登记到货数量
2. 转入 **入库**；可能触发 **来料质检**（场景五）
3. 入库状态机细节以云效「采购外协订单入库状态机」为准
4. 部分收货 / 部分入库常见

## 5. 结算与退货

- **结算规则**：维护计价、扣款、运费等规则
- **结算单**：对供应商对账付款依据
- **退货**：不合格或多余退回供应商

## 6. 外协管理

### 6.1 外协订单

与采购类似：创建 → 提交审核 → 进行中 → 完成/作废。  
可来自销售审核自动生成（供应型态外协）。

### 6.2 外协发料 / 收货

1. **发料**：将坯料/半成品发给外协厂（走出库规则 FIFO 等）
2. **收货**：收回加工件，可关联 **外协回货检**
3. **异常**：数量短缺、质量问题等闭环（见工单执行与异常、外协质检处置相关需求）

### 6.3 工序外协

工序级外协（机泵 1.6.1 等）：工单工序委外，注意与整单外协区分。详见对应云效需求。

## 7. 库存预警联动

计划排产 → 库存预警：可对低库存物料一键生成采购申请，形成「预警 → 申请 → 订单 → 入库」闭环。

## 8. 检查清单

| #   | 项                                  |
| --- | ----------------------------------- |
| 1   | 供应商档案齐全                      |
| 2   | 物料供应型态外购/外协正确           |
| 3   | 申请→订单→收货→入库样例跑通         |
| 4   | 自动生成/自动审批开关与企业授权匹配 |
| 5   | 结算规则与财务口径确认              |
| 6   | 外协发料/回货/质检路径已培训        |
