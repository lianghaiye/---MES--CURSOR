# 操作手册 · 采购与外协（手把手）

**模块入口：**

- 顶栏 **采购管理**
- 顶栏 **外协管理**

> 适合：采购员、计划员、仓管（收货入库）、实施顾问。  
> 学完应能：从申请到订单到收货入库跑通一笔采购；知道外协发料/收货怎么走。

---

## 0. 采购闭环全景（先记这张图）

```
需求出现
  ├─ 生产计划缺口（外购件）
  ├─ 库存预警补货（采购动作）
  ├─ 销售审核自动生成（功能参数+供应型态）
  └─ 采购员手工建申请
        ↓
采购申请 → 转/生成采购订单 → 提交审核 → 进行中
        ↓
采购收货 →（可选）来料质检 → 生成入库单 → 库存确认入库
        ↓
采购结算 / 退货（按需要）
```

## 1. 采购申请（手把手）

### 1.1 打开页面

顶栏 **采购管理** → **采购申请**。

列表常见列：单据状态、申请单号、紧急度、销售单号、采购单号、计划数量、交货/到货日期、采购员、来源等。

### 1.2 手工新建申请（逐步）

1. 点新增。
2. **必填：期望到货日期**。
3. 选填：销售订单、紧急度、交货日期、收货仓库、采购员、备注。
4. 明细区 **至少加一条有效物料行**（物料、数量等）。
5. 点 **保存** → 提示类似「采购申请已保存」。

### 1.3 从计划/补货来的申请

- 计划排产里对缺口点 **生成采购申请**；
- 库存预警执行补货动作选采购。  
  这类单打开后补充采购员、期望到货日等再往下转订单即可。

### 1.4 后续动作

列表/详情常见：生成采购订单、完成、作废等——按状态点。

## 2. 采购订单（手把手）

### 2.1 打开页面

左侧 **采购订单**。

工具栏可能有：审核订单变更、打印、批量提交、批量作废等。

**状态印象：** 待提交 → 待审核 → 进行中 → 已完成；另有已拒绝、已终结、已作废。

### 2.2 新建或从申请生成（逐步）

1. 从申请点「生成采购订单」，或本页新增。
2. **必填：**
   - **供应商**（先在基础配置建好供应商档案）
   - **交货日期**
3. 明细至少一条采购清单（物料、数量、单价等）。
4. 选填：合同编号、结算信息、交货方式、采购员、关联生产工单等。
5. 保存。

### 2.3 提交与审核

1. 点 **提交审核** → 状态待审核。
   - 若开了采购订单自动审批，可能直接进行中。
2. 审核人打开 → 通过 / 拒绝。
3. 需要改价：走 **价格变更**（是否自动回写看功能参数「采购订单价格变更」）。
4. 可撤回、重新提交、作废、短结/终结（按页面与状态）。

### 2.4 常见报错

| 提示                   | 处理           |
| ---------------------- | -------------- |
| 请选择供应商           | 先建供应商再选 |
| 请选择交货日期         | 必填           |
| 请至少添加一条采购清单 | 加明细         |

## 3. 采购收货 → 入库（手把手）

### 3.1 收货

1. **采购管理 → 采购收货**。
2. 针对进行中的采购订单做收货建单（按页面入口）。
3. 核对供应商、数量。
4. 列表工具常见：**生成质检单**、**生成入库单**、作废、打印。

### 3.2 要不要质检？

- 场景五或来料必须检：收货后先 **生成质检单** → 去质量管理录入结果 → 合格后再入库。
- 不检：可直接 **生成入库单**。

### 3.3 入库确认

1. 生成入库单后到 **库存管理 → 入库管理**。
2. 仓管 **确认入库**。
3. 库存明细增加；采购订单入库状态推进（部分收/部分入很常见）。

### 3.4 建议练习路径

```
手工采购申请（1个外购件）
 → 生成采购订单（选供应商、交货日）
 → 提交并审核通过
 → 采购收货
 → 生成入库单
 → 库存确认入库
 → 库存明细能查到该料
```

## 4. 结算与退货

### 4.1 结算规则 / 结算单

- **结算规则**：维护计价、扣款、运费、按重结算等规则。
- **采购结算**：按规则对供应商做结算单据。  
  若企业是「按件管库存、按重结算」，务必先读专题文档并在实施期拍板，避免双账混乱。

### 4.2 采购退货

不合格或多余退回：走 **采购退货**，注意回写库存与对账。

## 5. 外协管理（手把手）

### 5.1 外协和采购差在哪？

|      | 采购      | 外协                 |
| ---- | --------- | -------------------- |
| 本质 | 买料/买件 | 把活发给外协厂做     |
| 发料 | 通常无    | **有发料**           |
| 收回 | 收货入库  | 外协收货，可做回货检 |

### 5.2 外协订单

1. 顶栏 **外协管理** → **外协订单**。
2. 新建或由销售审核自动生成（供应型态=外协）。
3. 填外协供应商、物料/工序、数量、交期等 → 保存。
4. **提交审核** → 通过后进行中。  
   支持撤回、重新提交、作废（确认框会提示）。

### 5.3 外协发料

1. **发料管理**：把坯料/半成品发给外协厂。
2. 实质走出口库逻辑（拣批规则同出库 FIFO 等）。
3. 确认发料后库存减少，外协在制增加（以页面状态为准）。

### 5.4 外协收货与异常

1. **外协收货**：收回加工件。
2. 需要时生成 **外协回货检**（质量管理）。
3. **外协异常处理**：短缺、质量问题等闭环。

### 5.5 工序外协

若业务是「某一道工序外协」而不是整单外协，见专项需求（如机泵工序外协），操作入口以现场版本菜单为准。

## 6. 自动生成单据——采购最容易踩的坑

功能参数 **自动生成单据** 在销售审核后按供应型态自动建申请/外协/工单。

**实施建议：**

1. 供应型态没清洗前 **先关掉**。
2. 用 1～2 个标准产品手工跑通。
3. 再按型态谨慎打开自动生成。
4. 若客户投诉「审核一单冒出一堆错单」：立刻关闭自动生成 → 清理错单 → 修主数据。

## 7. 检查清单

| #   | 项                         |
| --- | -------------------------- |
| 1   | 供应商档案可用             |
| 2   | 会建采购申请并生成订单     |
| 3   | 会提交审核采购订单         |
| 4   | 会收货并入库，库存能查到   |
| 5   | （质量）会从来料检再到入库 |
| 6   | 会做一笔外协发料+收货      |
| 7   | 清楚自动生成开关状态       |
