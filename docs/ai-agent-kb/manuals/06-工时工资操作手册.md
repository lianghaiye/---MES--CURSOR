# 操作手册 · 工时工资

**模块路径：** 顶栏 **工时工资**、**报工管理**（工资核算）

## 1. 目标

把「报工数据」变成「可核对的计件/计时工资明细」，并按企业规则决定工人何时在小程序可见。

## 2. 前置条件

1. 《计薪口径确认表》已签字
2. 产品/工序工价已维护
3. 功能参数 **工资推送模式** 已选定
4. 不良品项、补贴规则（若用）已配置

## 3. 数据流

```
小程序/导入报工
  →（可选）报工确认调整/补贴
  → Web 工序报工审核
  → 工资核算明细生成/汇总
  → 按 salaryPushMode 推送
  → 小程序「工时工资」可见
```

## 4. 工资推送模式操作

| 模式       | 管理员/主任要做什么     | 工人何时看见 |
| ---------- | ----------------------- | ------------ |
| 报工即推送 | 通常无需手工推送        | 报工提交后   |
| 审核后推送 | 完成审核                | 审核通过后   |
| 手动推送   | 在工资核算/确认中点推送 | 推送成功后   |

路径提示：

- 配置：系统管理 → 功能参数 → 生产与计划 → **工资推送**
- 操作：报工管理 → **工资核算** / 核算详情

## 5. Web 工时管理与核算

1. **工时管理**：查看已报工/已审核工时记录
2. **工资核算**：筛选期间、人员、产品/工序
3. 勾选待推送明细 → 推送
4. 常见拦截：
   - 请选择待推送明细
   - 所选明细当前状态不可推送
   - 已审核数据不可调整单价/计薪方式

## 6. 小程序「工时工资」

工人可见字段示例：

- 已报工 / 已审核
- 良品 / 不良
- 补贴 / 质量扣款
- 本月计薪合计

主任在小程序「报工确认」可做调整与推送确认（权限控制）。

## 7. 计薪公式口径（须与客户确认）

| 类型     | 常见公式                            |
| -------- | ----------------------------------- |
| 计件     | 良品 × 单价；不良：不计或按约定比例 |
| 计时     | 工时 × 小时费率；准备工时是否计入   |
| 时长报工 | 仅计时，不走计件                    |

多人协作：均分 / 主操作人 / 按录入比例——必须在口径表写死。

## 8. 对账方法（试点验收）

1. 选 1 个班组连续 3～5 天
2. 导出系统工资明细 vs 原 Excel
3. 差异分类：主数据工价、审核改数、不良口径、推送范围、归属人
4. 差异讲清再推广全厂
