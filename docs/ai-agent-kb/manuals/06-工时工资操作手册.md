# 操作手册 · 工时工资（手把手）

**模块入口：**

- 顶栏 **报工管理** → 工资核算 / 核算详情
- 顶栏 **工时工资** → 工时管理
- 小程序 → **工时工资**

> 适合：车间主任、财务/劳资、管理员。  
> 学完应能：看懂一笔工资从哪来；按公司推送模式让工人看见；和 Excel 对上账。

---

## 0. 先建立正确预期

1. **系统工资 ≠ 银行已打款。** 这里是核算与可见明细，发放仍走财务。
2. **工人看不见，不等于没算出来。** 很大概率是「推送模式」挡住了。
3. **开工价前必须签《计薪口径确认表》。** 未签字不要导工价、不要试点。

---

## 1. 工资数据从哪来？（给新人的一张图）

```
工人小程序报工（良品/不良/工时）
    ↓
（可选）报工确认：调整、补贴
    ↓
Web 工序报工：审核通过
    ↓
系统按「工序单价 / 工时费率 × 数量或工时」算计薪
    ↓
按「工资推送模式」决定工人何时在小程序可见
    ↓
财务导出核对 → 厂内发薪流程
```

---

## 2. 配置工资推送模式（管理员做一次）

### 2.1 逐步点

1. 顶栏 **系统管理** → **功能参数**。
2. 在左侧分类找到 **生产与计划**（或页面中带「工资推送」的配置块）。
3. 找到 **工资推送模式**，三选一：

| 选项       | 工人何时能在「工时工资」看见 | 主任额外动作              |
| ---------- | ---------------------------- | ------------------------- |
| 报工即推送 | 报工提交后                   | 通常无                    |
| 审核后推送 | 工序报工审核通过后           | 把待审核审完              |
| 手动推送   | 有人点了推送之后             | 必须到核算/工时管理点推送 |

4. 保存配置。
5. **用白话通知全厂**：「我们是 XXX 模式」，避免工人天天问「怎么还没有」。

### 2.2 怎么选？（实施建议）

| 情况               | 建议                   |
| ------------------ | ---------------------- |
| 怕未审数据引发争吵 | 审核后推送 或 手动推送 |
| 老板要极度透明     | 报工即推送（加强抽查） |
| 财务要最终闸口     | 手动推送               |

## 3. 主任：从报到钱的每日操作

### 3.1 第一步：审报工

路径：报工管理 → **工序报工** → 筛 **待审核** → 通过/拒绝。  
（详细点法见《05-生产与报工》）

### 3.2 第二步：看工时 / 核算是否合理

**路径 A：** 工时工资 → **工时管理**  
**路径 B：** 报工管理 → **工资核算**

在工资核算列表你通常能看到：

- 员工工号/姓名、岗位、工作中心
- 完成任务数、报工总数、总工时
- 补贴金额、质量扣款、计薪(元)

1. 选好 **统计时间**、可按员工姓名筛。
2. 点某员工 **详情** 进入核算详情。

### 3.3 核算详情里逐项看什么？

打开详情后，建议按列核对：

| 看什么                         | 为什么             |
| ------------------------------ | ------------------ |
| 来源 / 工单号 / 工序           | 是否报错工序       |
| 报工类型                       | 计件还是时长       |
| 良品 / 不良 / 不良原因         | 是否符合现场       |
| 报工工时 / 最终核算工时        | 时长是否被调整     |
| 计薪方式                       | 计件/计时是否匹配  |
| 良品工资、不良工资、补贴、扣款 | 金额是否异常       |
| 计薪(元)                       | 与口径公式是否一致 |

发现异常：

- 未审核前：拒绝重报或报工确认调整；
- 已审核后：按厂规走修正，一般不能直接改已审单价。

### 3.4 第三步：手动推送（仅手动模式必做）

1. 在工时管理详情或核算相关页，勾选 **待推送** 明细。
2. 点 **推送** 或 **批量推送**。
3. 确认框类似：确认将任务推送至小程序「工时工资」列表，供工人确认？
4. 成功后让工人打开小程序 **工时工资** 下拉刷新。

**常见失败提示：**

| 提示                     | 处理                           |
| ------------------------ | ------------------------------ |
| 请选择待推送明细         | 先勾选行                       |
| 所选明细当前状态不可推送 | 可能已推送、未审核或不满足状态 |

## 4. 工人：小程序怎么看自己的工资

1. 工作台 → **工时工资**。
2. 列表按报工时间看每笔：时长、良品/不良工资、补贴等。
3. 点进详情看「工资核算区」构成。
4. 可筛已审核、看本月合计（底栏「本月计薪」等）。

**若显示「暂无已推送的工时工资记录」：**

按顺序自查/问主任：

1. 我报工成功了吗？（我的记录是否待审/已审）
2. 主任审了吗？
3. 公司是不是手动推送还没推？
4. 是不是看错了月份/账号？

## 5. 计薪口径怎么落到系统里（财务 + 实施）

对照《计薪口径确认表》逐项落地：

| 口径问题                       | 系统落点                         |
| ------------------------------ | -------------------------------- |
| 以报工数还是审核调整后数量为准 | 审核/报工确认是否允许改数        |
| 不良计不计薪、按多少比例       | 不良品项与计薪规则               |
| 计件还是计时为主               | 产品/工序工时配置里的计薪方式    |
| 时长报工                       | 系统限制：时长报工仅支持计时工资 |
| 补贴                           | 报工确认/核算中的补贴字段        |
| 多人协作怎么分                 | 均分/主操作人/比例——培训时讲死   |
| 工资归属谁                     | 报工人还是任务执行人             |

**产品上的工时配置入口：** 产品工艺 → 产品信息 → 启用工时配置 → 按工序维护单价/工时。

## 6. 和 Excel 对账（试点验收必做）

1. 选 1 个班组，连续 3～5 天只在系统报工。
2. 导出工资明细（工资核算批量导出，若有）。
3. 与原 Excel 并排比对，差异分类记录：

| 差异类型   | 举例                     |
| ---------- | ------------------------ |
| 工价主数据 | 系统单价与口头价不一致   |
| 审核改数   | 主任改良品数             |
| 不良口径   | Excel 计了不良，系统不计 |
| 推送范围   | Excel 含未推送/未审核    |
| 归属人     | 代报导致归属不同         |
| 多人协作   | 均分规则不一致           |

4. 差异讲清并签字确认后，再推广全厂。

## 7. 端到端练习（手动推送模式）

1. 确认功能参数=手动推送。
2. 工人报 1 笔计件 → 主任审核通过。
3. 此时工人小程序仍可能看不到（正常）。
4. 主任到工时管理/核算 → 勾选 → 推送。
5. 工人刷新可见；点开核对其金额=数量×单价（按口径）。

再练一遍「审核后推送」：改参数 → 只审核不推送 → 工人应能看见。
