# 操作手册 · 质量管理

**模块路径：** 顶栏 **质量管理**；小程序 **质检任务**

## 1. 五类质检

| 类型       | 业务时机            | 下游影响（门控）                 |
| ---------- | ------------------- | -------------------------------- |
| 来料质检   | 采购到货入库前/过程 | 弱管控预警；强管控未来可阻断入库 |
| 外协回货检 | 外协收回            | 同上                             |
| 生产过程检 | 工序过程            | 可对后续报工预警                 |
| 成品检     | 成品入库相关        | 入库预警                         |
| 出厂质检   | 销售出库前          | 出库确认读取门控                 |

**功能参数 → 质检门控：** 按五类配置弱/强；**当期仅开放弱管控**（强管控可能置灰）。

## 2. 主数据准备

1. **检验项库**：维护检验项、标准、关键项标记
2. **质检模板**：按产品/工序/业务类型组卷；配置合格规则（如关键项必须达标）
3. **不良品项**：报工不良与质检不良分类（可影响计薪）

模板规则不满足时示例：按模板规则「xxx」，以下项未达标，不能判定通过。

## 3. 质检任务执行

### 3.1 Web

1. 在对应质检菜单生成或查看任务
2. 状态：待质检 → 已完成 / 已终止
3. 填写检验结果 → 判定：通过 / 不通过 / 部分通过
4. 部分合格须填写处置数量（合格入库、退货、换货等不可超过质检数量）

### 3.2 小程序

1. 工作台 → **质检任务**
2. 按五类分流进入待检列表
3. 现场勾选检验项、拍照、提交结论
4. 建议：**质检单由 Web 生成**，手机执行填报，避免现场随意建单失控

## 4. 出厂质检与发货

1. 销售发货前可发起出厂质检
2. 弱管控：未检也可出库，但 Toast 预警
3. 强管控（未来）：未检/不合格阻断出库

## 5. 报废品管理

1. 不合格评审后开报废单
2. 审批：可配置自动审批「报废单」（是否完全接入以版本为准）
3. 报废入库至报废仓；关联补料/返工流程按企业制度

## 6. 与报工工资的交叉

- 报工不良原因须分摊完整（「请分配全部不良原因」）
- 不良是否计薪、质量扣款规则须在计薪口径表确认
- 过程检不合格时，上游工序质检待完成/不合格可能对报工产生预警文案

## 7. 质检工单

部分企业使用独立 **质检工单**（生产管理下）组织专检任务；与五类质检任务配合使用。

## 8. 场景五实施顺序

1. 场景四主链路稳定
2. 先做 1～2 个主力产品模板
3. 试点出厂检 + 一次报废
4. 再推广来料/过程检

## 9. 检查清单

| #   | 项                              |
| --- | ------------------------------- |
| 1   | 模板与检验项已建                |
| 2   | 质检角色与小程序入口开通        |
| 3   | 门控策略与客户预期一致（弱/强） |
| 4   | 部分合格处置数量规则已培训      |
| 5   | 报废审批路径明确                |
