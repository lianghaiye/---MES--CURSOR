# 操作手册 · 质量管理（手把手）

**模块入口：** 电脑顶栏 → **质量管理**；现场执行在小程序 → **质检任务**

> 适合：质检员、仓管（来料/入库协同）、主任、实施顾问。  
> 学完应能：建一个质检模板并启用 → 从收货生成来料检 → 录入结果 → 合格后入库；知道出厂检与弱管控含义。

---

## 0. 五类质检分别管什么？

| 菜单       | 什么时候做     |
| ---------- | -------------- |
| 来料质检   | 采购到货       |
| 外协回货检 | 外协加工收回   |
| 生产过程检 | 工序过程       |
| 成品检     | 成品相关检验   |
| 出厂质检   | 销售发货出厂前 |

另外还有：**报废品管理**、**质检模板**、**检验项库**。

**门控（重要）：**  
功能参数里可为五类配置弱/强管控。当期多为 **弱管控=只预警不强制拦截**。不要向客户承诺「不检绝对出不了库」除非现场已开放强管控。

## 1. 先建检验项与模板（管理员/质检主管）

### 1.1 检验项库

1. **质量管理 → 检验项库**。
2. 新增检验项：名称、标准、是否关键项等。
3. 保存，供模板引用。

### 1.2 新建质检模板（逐步）

1. **质量管理 → 质检模板** → 新增。
2. **必填：**
   - 模板名称
   - 业务类型（如来料质检）
   - 适用范围、适用对象（挂到哪些产品/范围）
3. 配置检验字段（从检验项库选或按页面添加）。
4. 配置整单结论选项（合格/不合格等；系统常规定某些结论不可删）。
5. 若规则是「关键项必须达标」，务必勾选关键项，否则提交会报模板配置问题。
6. 点 **保存**。提示类似「已创建模板 xxx，请在列表完成启用」。
7. 回列表找到该模板 → **启用**（停用的模板不能正常用于任务）。

### 1.3 模板常见报错

| 提示                                                | 处理                             |
| --------------------------------------------------- | -------------------------------- |
| 请输入模板名称 / 选择业务类型 / 适用范围 / 适用对象 | 补必填                           |
| 关键项必须达标但未勾选任何关键项                    | 编辑模板勾关键项                 |
| 未满足模板整单合格规则                              | 检验结果未达模板规则，不能判通过 |

## 2. 来料质检完整示例（最适合新手练）

### 2.1 生成质检单

1. 先有一笔采购收货（见采购手册）。
2. 在 **采购收货** 列表点 **生成质检单**。
3. 到 **质量管理 → 来料质检**，应能看到新任务，状态多为 **待质检**。

### 2.2 录入质检结果（电脑逐步）

1. 打开该行 → 点 **录入质检结果**（或同类按钮）。
2. 按模板逐项填写检验值/是否合格。
3. 填写合格数/不合格数（以页面字段为准）。
4. 选择 **整单结论**：通过 / 不通过 / 部分通过。
5. 若部分通过：必须填 **数量处置**（如合格入库、退货、换货、让步等），且合计不能超过质检数量。
6. 提交。成功提示类似「质检完成：xxx」。

### 2.3 合格后入库

1. 列表状态变为已完成，结果为通过或部分通过。
2. 点 **生成入库单**（不通过通常不能入库）。
3. 到库存管理 **确认入库**。

### 2.4 来料检常见报错

| 提示                               | 处理                   |
| ---------------------------------- | ---------------------- |
| 当前状态不可录入质检结果           | 不是待质检，或已完成   |
| 物料未绑定质检模板                 | 先做模板并绑定适用对象 |
| 请填写「…」的某字段 / 选择整单结论 | 按提示补全             |
| 请填写数量处置                     | 部分合格必须填处置     |
| 合格入库+退货+换货不可超过质检数量 | 改处置数量             |

### 2.5 终止任务

对无需再检的待检单，可按权限点 **终止**。

## 3. 小程序执行质检（现场）

1. 工作台 → **质检任务**。
2. 按五类入口进入待检列表。
3. 打开任务 → 勾选/填写检验项 → 可拍照 → 提交结论。
4. **建议：质检单由电脑生成，手机只负责填。** 避免现场随意建单难追溯。

仅待质检任务可提交；状态不对会拦截。

---

## 4. 过程检 / 成品检 / 出厂检要点

### 4.1 生产过程检

- 列表可能含：工单号、工序、物料、检验方式/数量、质检模板。
- 工序配置里若勾了质检类型，工单下发时可能自动生成过程检任务。
- 未完成/不合格时，后续报工可能出现「上游工序质检待完成/不合格」**预警**（弱管控）。

### 4.2 出厂质检

1. 发货出库前可发起/完成出厂检。
2. 仓管确认出库时，系统可能 Toast 预警。
3. 弱管控下仍可能出库——是否允许由厂规决定，参数决定系统是否强拦。

### 4.3 成品检

与成品入库节点配合；具体触发以现场配置与版本为准。

---

## 5. 报废品管理

1. **质量管理 → 报废品管理**。
2. 不合格评审后开报废单。
3. 提交审批（功能参数可配置报废单自动审批；是否完全接入以版本为准）。
4. 审批后入报废仓；补料/返工按厂规另走工单或领料。

---

## 6. 与报工工资的交叉（培训必讲）

- 报工不良原因要分摊完整。
- 不良是否计薪、质量扣款规则写进《计薪口径确认表》。
- 质检不良分类与报工不良品项尽量用同一套字典，避免月底对不上。

---

## 7. 端到端练习（来料）

1. 建来料质检模板并启用，适用到某外购件。
2. 走一笔采购订单 → 收货 → 生成质检单。
3. 录入结果判合格 → 生成入库单 → 确认入库。
4. 再练一笔「部分合格」：填处置数量，体验校验。
5. （可选）小程序打开同一待检任务练习现场填报。

---

## 8. 检查清单

| #   | 项                         |
| --- | -------------------------- |
| 1   | 检验项库有基础项           |
| 2   | 至少 1 个模板已启用        |
| 3   | 会从来料检走到入库         |
| 4   | 会处理部分合格处置         |
| 5   | 知道弱管控≠强拦截          |
| 6   | 质检角色与小程序入口已开通 |
