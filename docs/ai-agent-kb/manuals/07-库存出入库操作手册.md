# 操作手册 · 库存出入库（手把手）

**模块入口：** 电脑顶栏 → **库存管理**  
领料申请也在：**生产管理 → 领料管理**；现场可在小程序操作。

> 适合：仓管、车间主任（兼仓管）、管理员。  
> 学完应能：建仓库认知 → 处理领料出库 → 确认成品/采购入库 → 调拨/盘点 → （对内）确认完工扣减。

---

## 0. 新手必读：仓库至少要分清这三种

在 **基础配置 → 仓库管理 → 仓库列表** 里维护：

| 仓库类型（建议） | 干什么用             |
| ---------------- | -------------------- |
| 原料仓 / 发料仓  | 采购入库；向车间发料 |
| 线边仓           | 领料后的车间现场暂存 |
| 成品仓           | 成品入库；销售出库   |

没有仓库，后面所有出入库都会卡住。

**期初：** 先盘点或做期初入库，再跑日常业务，否则一直「库存不足」。

---

## 1. 领料出库（一步一步）

### 1.1 谁发起领料？

| 角色      | 在哪发起                                  |
| --------- | ----------------------------------------- |
| 工人/班长 | 小程序 → 领料管理（工单/订单/快速）       |
| 主任/仓管 | 电脑 → 生产管理 → 领料管理 → **申请领料** |

### 1.2 电脑申请领料（逐步）

1. 打开 **生产管理 → 领料管理**。
2. 点 **申请领料**。
3. 选择领料方式（工单领料 / 订单领料 / 快速等）。
4. 选关联工单或订单，添加物料行，填数量。
5. **选择领入仓库**（通常选线边仓）。页面提示大意：物料从领料仓出库后领入线边暂存。
6. 提交。

### 1.3 审核领料（若未自动审批）

1. 仍在领料管理列表，找到待审单。
2. 点 **通过** 或 **驳回**。
3. 是否免审：管理员在 **系统管理 → 功能参数 → 自动审批 → 领料申请**。

### 1.4 确认出库（仓管关键动作）

1. 顶栏 **库存管理** → **待出库列表** 或 **出库管理**。
2. 用源单号/工单号找到对应出库单。
3. 打开单据，核对：
   - 出库类型
   - 出库仓库（发料仓）
   - 领入仓库（线边仓，若有）
   - 明细数量是否超过可用库存
4. 点 **确认出库** 或 **保存并出库**。
5. 成功后：发料仓库存减少；自主领料模式下线边仓增加。

### 1.5 出库常见报错

| 提示                                | 处理                 |
| ----------------------------------- | -------------------- |
| 请选择出库类型 / 请输入出库单号     | 补必填               |
| 请至少添加一条有效明细              | 加明细               |
| 出库数量不能超过可用库存 / 库存不足 | 先入库或改数量或换仓 |
| 请先保存出库单后再确认出库          | 先保存再确认         |
| 请选择领入仓库                      | 领料场景补选线边仓   |

## 2. 入库（成品 / 采购等）

### 2.1 成品入库从哪来？

| 来源             | 说明                                              |
| ---------------- | ------------------------------------------------- |
| 小程序成品入库   | 工单入库 / 批量 / 快速 → 提交后电脑出现待审入库单 |
| 电脑手工建入库单 | 库存管理 → 入库管理                               |
| 采购收货生成入库 | 采购收货 → 生成入库单                             |

### 2.2 电脑确认入库（逐步）

1. **库存管理 → 待入库列表 / 入库管理**。
2. 打开待入库/待审批单据。
3. 核对：入库类型、入库仓库、数量、源单号；成品/半成品按规则可能要选销售订单。
4. 点 **确认入库** 或 **保存并入库**。
5. 成功后库存明细增加；若挂了销售单，有助于后续 **按单发货**。

### 2.3 自动审批

功能参数勾选 **成品入库** 自动审批后，现场提交可能免仓管点确认——小厂常用，管理严的企业可先关掉。

### 2.4 入库常见报错

| 提示                          | 处理                             |
| ----------------------------- | -------------------------------- |
| 请选择入库类型                | 必选                             |
| 成品/半成品入库须选择销售订单 | 补选销售单（按单场景）           |
| 请至少添加一条有效明细        | 加行                             |
| 入库数量须大于 0              | 填正数                           |
| 工单不存在或未完成            | 检查工单状态（小程序侧也可能拦） |

---

## 3. 调拨（仓与仓之间搬货）

1. **库存管理 → 调拨管理** → 新增。
2. **必选：** 调出仓库、调入仓库（不能随意留空）。
3. 添加物料与数量，填调拨日期/备注。
4. 点 **保存** 或 **保存并确认**。
5. 若功能参数要求「入库方签收」：调出确认后，调入方还要再确认一次才完结；否则出库确认后自动完结。

列表可批量确认/删除（按权限与状态）。

---

## 4. 盘点（手把手）

### 4.1 电脑新建盘点

1. **库存管理 → 盘点管理** → 新增。
2. **必选：** 盘点仓库、盘点类型。
3. 可用「加载本仓库存」带出账面数。
4. 录入实盘数量 → 保存。
5. **提交审核**。

### 4.2 审核与过账（只在电脑）

1. 审核人打开待审盘点单 → **审核通过**（或拒绝）。
2. 看功能参数 **盘点审核通过后是否自动过账**：
   - 自动：通过后生成盘盈入库 / 盘亏出库；
   - 手动：还需点 **生成盘盈盘亏**。
3. 过账后库存明细才会变。

### 4.3 小程序盘点

小程序可建单录实盘并提交，提示类似「已提交，请到 PC 审核」。  
**不要以为手机提交完库存就变了。**

---

## 5. 库存明细与流水怎么查账

| 菜单                | 用途                           |
| ------------------- | ------------------------------ |
| 库存明细            | 按仓库/物料看现存量、批次      |
| 出库详情 / 入库详情 | 按单据追溯                     |
| 随货查询            | 维护本票随货附件               |
| 下料结算            | 需下料结算物料的实耗与余料回库 |

对账口诀：**先查明细有没有数，再查出入库单卡在哪一步。**

## 6. 库存扣减记录（对内手把手）

> 对外培训请讲「领料、入库、账实一致」，不要单独卖「扣减场景」。  
> 菜单：**库存管理 → 库存扣减记录**

### 6.1 它什么时候出现？

工单被 **标记已完成** 后，按功能参数「库存扣减方式」可能生成扣减单：

| 模式（功能参数）          | 你会看到什么                           |
| ------------------------- | -------------------------------------- |
| 不领料                    | 通常不生成完工扣减                     |
| 完工后预扣+确认（无领料） | 待确认扣减，**必须人工确认**，扣发料仓 |
| 自主领料+完工预扣         | 待确认扣减（可自动确认），扣线边仓     |

### 6.2 确认扣减（逐步）

1. 打开库存扣减记录，看统计卡：待确认 / 失败等。
2. 打开 **待确认** 单据。
3. 核对物料、仓库、数量（可按规则改仓）。
4. 点 **确认**。
5. 库存不足会失败——先补库或改明细再处理。
6. 超时锁定后不可再操作，走冲正制度。

### 6.3 自动确认注意

只有 **自主领料** 模式勾选自动审批「库存扣减」才会生成即确认。  
**完工预扣无领料模式永远要人点确认**——这点培训时要讲透。

---

## 7. 下料结算（有板材/型材时）

1. 物料勾了「需要下料结算」，且功能参数为「需下料结算」。
2. 发料仍按出库数量扣库。
3. 到 **下料结算** 登记实耗；余料按策略回库。
4. 若参数为「无需下料结算」，余料可留线边，扣减单可能直接按 BOM 实扣。

细节见结算相关专题文档。

---

## 8. 仓管一日工作流（建议）

```
1. 看待出库：领料/发货出库确认
2. 看待入库：成品/采购入库确认
3. 看调拨待签收（若有）
4. （对内）看待确认库存扣减
5. 抽查库存明细与现场是否大致一致
6. 盘点日：审核并过账
```

---

## 9. 端到端练习（场景二最小）

1. 建好原料仓、线边仓、成品仓；给原料做一笔期初入库。
2. 小程序或 Web 领料 1 笔 →（如需）审核 → 出库确认 → 线边有账。
3. 工人报工（可快速）→ 主任审核。
4. 小程序成品入库 → 电脑确认入库 → 成品仓有账。
5. （若有工单完工）查看扣减记录是否按配置出现并确认。
