# 操作手册 · 库存出入库

**模块路径：** 顶栏 **库存管理**；领料亦见 **生产管理 → 领料管理**

## 1. 仓库主数据

**基础配置 → 仓库 / 货位 / 分类**

建议至少区分：

| 仓类型      | 用途                             |
| ----------- | -------------------------------- |
| 原料/发料仓 | 采购入库、向车间发料             |
| 线边仓      | 自主领料后的车间现场库存         |
| 成品仓      | 成品入库、销售出库               |
| 不良/报废仓 | 质检不合格、拆解报废等（按企业） |

期初：盘点或期初入库导入后再跑业务。

## 2. 领料与出库

### 2.1 领料申请

1. Web 领料管理或小程序领料 → 选工单/订单/快速模式
2. 填写物料、数量、领入仓库
3. 提交 → 待审核（若未开自动审批）→ 通过后生成/进入出库

### 2.2 确认出库

**库存 → 待出库 / 出库管理**

- 拣批：功能参数「出库规则」，本期多为 FIFO
- 需下料结算物料：有额外整批/余料优先策略
- 出库确认后按出库单数量扣减库存

### 2.3 与扣减模式关系

| 库存扣减模式         | 领料含义                           |
| -------------------- | ---------------------------------- |
| 不领料               | 可不走领料；无工单完工扣减         |
| 完工后预扣（无领料） | 可不领料；完工从发料仓预扣         |
| 自主领料+完工预扣    | 领料=调到线边；完工从线边按 BOM 扣 |

## 3. 入库

### 3.1 成品入库

1. 小程序或 Web 发起（工单/批量/快速）
2. 入库单常为待入库/待审批
3. 自动审批「成品入库」勾选则可免审
4. 入库数量须 > 0；工单不存在或未完成可能拦截（视规则）

### 3.2 采购/外协入库

采购收货后转入入库流程；状态机见采购手册与云效文档。

### 3.3 批次

入库可生成批次；销售「按单发货」依赖入库挂销售单批次。规则见 `docs/入库批次生成规则.md`。

## 4. 库存扣减记录（对内）

**库存管理 → 库存扣减记录**

### 4.1 何时生成

工单首次变为 **已完成** 时，按模式生成完工扣减单（BOM 领料件 + 倒冲件同单展示）。

跳过示例文案：当前为「不领料」模式，不生成工单完工库存扣减。

### 4.2 确认

1. 打开待确认记录 → 核对明细仓库与数量
2. 确认通过后按物料扣减
3. `self_issue_by_actual` 且勾选自动审批「库存扣减」→ 生成即自动确认
4. `post_complete_by_report` → **必须人工确认**
5. 库存不足 → 行/单失败，需补库或改明细后重试
6. 超时锁定：确认超过 N 天不可再操作

**对外话术：** 不讲「扣减场景」；讲领料、入库、账实一致。

## 5. 调拨

1. 新建调拨单：调出仓、调入仓、物料数量
2. 确认后软锁定调出仓并生成调拨出库
3. 若 `transferRequireInboundConfirm=true`：入库方签收完结；否则自动入库

## 6. 盘点

1. 小程序可建单录实盘并提交
2. **审核与过账在 PC**
3. `stocktakeAutoPostOnApprove=true`：审核通过即盘盈入库/盘亏出库
4. 否则手动「生成盘盈盘亏」

## 7. 下料结算

**库存 → 下料结算**

适用于勾选「需要下料结算」的物料：

1. 发料按出库数量扣库
2. 现场登记实耗
3. 余料按策略回库（需下料结算）或留线边（无需下料结算）

双单位/按件库存按重结算见 `docs/结算单位-按件库存按重结算.md`。

## 8. 库存明细与流水

- **库存明细**：按仓/物料看现存量、批次
- **出入库详情**：单据级追溯
- **随货查询**：本票随货附件维护

## 9. 检查清单

| #   | 项                               |
| --- | -------------------------------- |
| 1   | 仓库与线边仓已建                 |
| 2   | 扣减模式与领料习惯匹配（对内）   |
| 3   | 领料/成品入库自动审批符合企业    |
| 4   | 仓管角色含扣减记录权限（若需要） |
| 5   | 期初盘点完成                     |
| 6   | 对外材料未把「库存扣减」写成卖点 |
