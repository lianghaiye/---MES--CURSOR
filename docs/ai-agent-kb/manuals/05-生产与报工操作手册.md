# 操作手册 · 生产与报工（手把手）

**模块入口：**

- 顶栏 **生产管理**（工单、领料）
- 顶栏 **报工管理**（工序报工审核、报工确认）

> 适合：车间主任、计划员、跟单。  
> 学完应能：开/下发工单 → 看工人报工 → 审核通过/拒绝 →（需要时）报工确认调整。

工人手机怎么报：请另读 [10-小程序操作手册.md](./10-小程序操作手册.md)。

---

## 0. 先分清三条线

| 名称     | 在哪                | 干什么                                           |
| -------- | ------------------- | ------------------------------------------------ |
| 生产工单 | 生产管理 → 生产工单 | 下达任务给车间                                   |
| 工序报工 | 报工管理 → 工序报工 | 审核工人报上来的产量                             |
| 报工确认 | 报工管理 → 报工确认 | 调整、补贴、推送确认（和「审核」不是同一个按钮） |

**快速报工** 可以没有工单；**任务报工** 必须先有工单下发。由管理员在 **系统管理 → 业务规则 → 生产模式** 决定。

## 1. 生产工单（手把手）

### 1.1 打开列表

1. 顶栏 **生产管理** → **生产工单**。
2. 学会用筛选：工单编码/名称、来源（销售单/补货计划号）、产品、状态。
3. 工具栏常见：**批量下发**、**批量打印**。

**状态：** 待下发 → 已下发 → 执行中 → 已完成；另有暂停 / 终止。

### 1.2 工单从哪来？

| 来源             | 你怎么遇到它                        |
| ---------------- | ----------------------------------- |
| 生产计划下达     | 计划排产里点「生成加工工单」        |
| 销售审核自动生成 | 功能参数开了自动生成 + 供应型态自产 |
| 手工新建         | 本页点新增                          |

### 1.3 手工新建工单（逐步点）

1. 点 **新增**（或同类按钮）。
2. 重点填写：

| 字段          | 说明                                       |
| ------------- | ------------------------------------------ |
| 产品名称      | 必选；且通常需要有可用工艺路线             |
| 工艺路线      | 必选；没有路线先去产品工艺建               |
| 排产数量      | 必填                                       |
| 工作中心      | 必选（以页面为准）                         |
| 计划日期      | 必选                                       |
| 预入仓库      | 建议填成品要入哪个仓                       |
| 销售订单      | 按单生产时关联                             |
| 紧急度 / 备注 | 选填                                       |
| 工单编号      | 若手填需唯一，重复会提示「工单编号已存在」 |

3. 保存。若提示「该产品无自有生效 BOM…」——先去产品 BOM **发布生效**（按 BOM 建单时）。
4. 新单一般是 **待下发**。

### 1.4 下发工单（工人才能领）——最关键一步

1. 在列表勾选一张或多张 **待下发** 工单。
2. 点 **批量下发**（或行内下发）。
3. 下发成功后状态变为 **已下发**（领取后可能变执行中）。
4. 通知工人：打开小程序 → 工序报工 → **待领任务**。

**没下发 = 工人小程序通常领不到。** 这是现场最常见培训遗漏。

### 1.5 暂停 / 恢复 / 终止 / 完工

| 动作       | 何时用   | 注意                                                              |
| ---------- | -------- | ----------------------------------------------------------------- |
| 暂停       | 临时停   | 暂停后可再恢复                                                    |
| 恢复       | 暂停结束 | 回到可执行                                                        |
| 终止       | 不再做   | 若已有报工，可能弹出「仍终止（重置报工）」/「不处理（保留报工）」 |
| 标记已完成 | 整单做完 | 确认框可能提示：完成后将触发完工库存扣减                          |

**执行中的工单通常不可随意编辑/删除**——要改数量，若已有完成报工，可能提示先撤回报工状态。

### 1.6 打印报工二维码

1. 在工单列表/详情使用 **打印** / **批量打印**。
2. 用浏览器打印预览出工单或工序码。
3. 工人小程序扫码报工（分项任务走任务报工，不进快速报工）。
4. 码模糊、过期（如关闭超 7 天）会扫失败——重新打印或按制度处理。

### 1.7 详情里还能看什么？

详情常见 Tab：工单下发、领料信息等。可核对领料与执行进度。

## 2. 领料管理（Web）

**菜单：** 生产管理 → 领料管理

### 2.1 申请领料（逐步）

1. 点 **申请领料**。
2. 选择领料方式：工单领料 / 订单领料 / 快速领料等（以页面为准）。
3. 选择关联工单或订单，添加物料与数量，选择 **领入仓库**（常为线边仓）。
4. 提交。

### 2.2 审核领料

若未开「领料申请」自动审批：

1. 列表找到待审申请。
2. 点 **通过** 或 **驳回**。
3. 通过后到 **库存管理 → 出库** 做确认出库（见库存手册）。

小程序也能发起领料，规则相同。

## 3. 工序报工审核（主任每日必做）

### 3.1 打开列表

1. 顶栏 **报工管理** → **工序报工**。
2. 筛选：
   - 状态：**待审核**（每天先看这个）
   - 报工方式：任务报工 / 快速报工
3. 工具栏常见：**批量通过**、**批量拒绝**、导入报工记录、导出。

### 3.2 审核一笔（逐步点）

1. 点开一条待审核记录（或勾选多条）。
2. 核对：
   - 工单号（任务报工）
   - 产品、工序、报工日期
   - 良品/不良是否合理
   - 计薪金额是否异常
3. **通过**：状态变已审核。
   - 若工资推送=审核后推送，工人此后可在小程序看到。
4. **拒绝**：必须填 **拒绝原因** → 工人按原因重报。

### 3.3 绝对要注意的锁定规则

| 规则                           | 含义                                   |
| ------------------------------ | -------------------------------------- |
| 已审核不可拒绝                 | 审错了要走制度内冲正，不是再点拒绝     |
| 已审核不可改数量/单价/计薪方式 | 想改在审核前改，或用报工确认（看厂规） |
| 仅已报工数据可审核             | 工人没提交成功的审不了                 |

### 3.4 批量操作

- **批量通过**：适合信任度高、抽查过的一批。
- **批量拒绝**：同样需要原因（按页面要求）。

### 3.5 导入报工

若用 Excel 导入：

- 报工方式填：任务报工 / 快速报工
- 任务报工须填工单号；快速报工可空
- 导入失败看行级错误提示

## 4. 报工确认（和审核分开记）

**菜单：** 报工管理 → 报工确认

### 4.1 什么时候用？

- 要调整报工数量/工时
- 要加补贴
- 要推给工人再确认一次

### 4.2 逐步操作

1. 看状态统计：待确认｜待工人确认｜已确认。
2. 找到任务 → 点 **调整** → 改良品/不良/时长/补贴等 → 保存。
3. 需要时点 **推送确认**（确认框会说明推送给执行人确认）。
4. 工人确认后状态变为已确认。

## 5. 主任一日工作流（建议贴墙上）

```
早上
  1) 生产工单：把今日要做的「待下发」批量下发
  2) 通知班组领取任务
上午/下午
  3) 工序报工：筛待审核，逐笔或批量审核
  4) 异常：拒绝并写清原因；必要时报工确认调整
下班前
  5) 再刷一遍待审核是否清零
  6) 若手动推送工资：到工资核算/工时管理推送
  7) 做完的工单：核对后「标记已完成」
```

## 6. 端到端练习（任务报工）

1. 产品有默认工艺路线与工价；BOM 按需已发布。
2. 新建工单排产数量 10 → 保存 → **下发**。
3. 手机：待领 → 领取 → 今日待报工 → 报良品 2 → 提交。
4. 电脑：工序报工待审核 → 通过。
5. 再报一笔故意超量或乱填 → 练习拒绝并填原因。
6. 全部完成后标记工单已完成（观察是否出现库存扣减待确认——对内）。

## 7. 检查清单

| #   | 项                                   |
| --- | ------------------------------------ |
| 1   | 会新建工单并选对工艺路线             |
| 2   | 会批量下发，并确认工人能领到         |
| 3   | 会筛待审核并通过/拒绝                |
| 4   | 拒绝必填原因                         |
| 5   | 分清「工序报工审核」和「报工确认」   |
| 6   | 会打印报工码（若启用扫码）           |
| 7   | 会暂停/终止/完工，并理解完工可能扣料 |
