# 操作手册 · 生产与报工

**模块路径：** 顶栏 **生产管理**、**报工管理**

## 1. 生产工单

### 1.1 开立来源

- 生产计划下达
- 销售审核后自动生成（功能参数「自动生成单据」）
- 手工新建

另有：**总装工单、拆解工单、质检工单**（按业务启用）。

### 1.2 生命周期

```
待下发 → 已下发 → 执行中 → 已完成
         ↘ 暂停 / 终止
```

### 1.3 主任操作

1. 核对产品、数量、工艺路线、交期
2. **下发** 到执行侧（小程序待领）
3. 监控执行；异常可暂停/终止
4. **标记完成**：完成后可能触发 **完工库存扣减**（视库存扣减模式）

### 1.4 派工与多人协作

- 任务粒度常见为「工单 × 工序」一条
- 多人协作同一工序：均分 / 主操作人 / 按比例（计薪口径确认）
- 已有任务完成报工后，可能拦截修改报工数量（需先撤回报工状态）

## 2. 领料管理（生产侧）

路径：**生产管理 → 领料管理**（与库存出库联动）

| 模式            | 说明                         |
| --------------- | ---------------------------- |
| 工单领料        | 绑定工单，按需求或手工改数量 |
| 订单领料        | 绑定销售订单                 |
| 快速 / 批量领料 | 降低门槛，适合场景二         |

领料审核是否自动：功能参数 **自动审批 → 领料申请**。

自主领料模式下：出库实质是 **发料仓 → 线边仓**；真正消耗在完工扣减。

## 3. 工序报工（Web 审核）

路径：**报工管理 → 工序报工**

### 3.1 列表筛选

- 来源：任务报工 / 快速报工
- 状态：待审核 / 已审核 / 已拒绝

### 3.2 审核操作

| 动作 | 规则                                          |
| ---- | --------------------------------------------- |
| 通过 | 待审核 → 已审核；可能触发工资推送（on_audit） |
| 拒绝 | 须填拒绝原因；已审核不可拒绝                  |
| 调整 | 已审核数据通常不可再改数量/单价/计薪方式      |

### 3.3 报工类型与计薪

| 报工类型 | 计薪                                |
| -------- | ----------------------------------- |
| 批量计件 | 计件工资（件数 × 单价）；不良按口径 |
| 时长报工 | **仅**计时工资                      |

分项报工：一期常见 `reportQtyMode=schedule`，`wageQtyMode=reported` → 件数 × 工序单价；分项多用于勾选追溯。

### 3.4 导入

支持导入模板；任务报工须填工单号；快速报工可空。方式填「任务报工 / 快速报工」。

## 4. 报工确认

路径：**报工管理 → 报工确认**（小程序主任端也有）

用于：调整、补贴、推送确认等。与「工序报工审核」分工不同，勿混用名词。

## 5. 扫码报工（工单二维码）

1. Web 打印工单/工序报工二维码
2. 小程序扫码进入填写报工
3. 分项任务扫码走 **任务报工**，不进快速报工
4. 常见拦截：二维码无效；工单关闭超 7 天；未领取任务；工序已报工

## 6. 生产模式对照

| 业务规则   | 现场表现                      |
| ---------- | ----------------------------- |
| 标准模式   | 下发→领取→报工→审核→核算→推送 |
| 极简·快速  | 以快速报工为主                |
| 极简·任务  | 以任务报工为主（与快速互斥）  |
| 下发即报工 | 跳过现场报工与确认            |

## 7. 检查清单

| #   | 项                         |
| --- | -------------------------- |
| 1   | 工艺路线已挂到工单产品     |
| 2   | 工人会领任务/快速报工      |
| 3   | 主任会审核与拒绝           |
| 4   | 完工与扣减模式匹配（对内） |
| 5   | 扫码报工试点通过（若启用） |
