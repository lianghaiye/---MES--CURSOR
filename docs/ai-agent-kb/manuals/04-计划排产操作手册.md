# 操作手册 · 计划排产

**模块路径：** 顶栏 **计划排产**

## 1. 设计任务

适用于非标/需出图或 EBOM 的订单行。

### 1.1 典型流程

```
销售订单审核 → 生成/创建设计任务
  → 待设计 → 设计中 → 待审核 → 审核通过（EBOM/设计结果回写）
  → 或已驳回退回修改
```

### 1.2 操作要点

1. 计划/技术在 **设计任务** 列表领取或打开任务
2. 维护设计结果 / EBOM / 附图
3. 提交审核；审核通过后订单可继续排产
4. BOM 来源与审核规则见云效「销售订单 BOM 来源与设计任务审核」需求

## 2. 生产计划

### 2.1 创建与下达

1. 由销售订单生成，或手工/补货生成计划
2. 维护计划数量、交期、工作项
3. 状态：待下达 → 部分下达 / 执行中 → 已完成
4. 下达后可生成 **生产工单**；缺料可生成 **采购申请**

### 2.2 计划上的库存提醒

若行需求已被软占用覆盖，系统可提示「可直接从仓库发货（可不排产或减计划数量）」——**由计划员决定**，不强制跳过。

### 2.3 工单物料相关参数

功能参数中可能包含：

- 启用工单物料需求计算
- 启用最后工序报工物料消耗计算

按企业开启。

## 3. 库存预警（补货中心）

**入口：** 计划排产 → 库存预警 / 补货中心（亦可能从生产计划页进入）

### 3.1 进入建议列表条件

- 产品/物料开启预警，且现存量 ≤ 最低库存
- 也可手工添加成品/零部件/毛坯

### 3.2 动作

| 动作 | 结果                                 |
| ---- | ------------------------------------ |
| 生产 | 生成补货生产计划，单号常见前缀 `BH…` |
| 采购 | 生成采购申请                         |

预警 **不强制** 计划策略=MTS。

### 3.3 补货台账

记录补货建议与执行结果，便于对账。

## 4. 与场景四的衔接

完整链路：

```
销售订单 →（设计任务）→ 生产计划 → 工单 / 采购申请
         → 任务报工 → 领料/入库 → 发货
```

实施建议：主数据（BOM/工艺/供应商）未齐前，不要同时开太多自动生成开关。

## 5. 检查清单

| #   | 项                                 |
| --- | ---------------------------------- |
| 1   | 标准产品能从订单生成计划并下达工单 |
| 2   | 缺料样例能生成采购申请             |
| 3   | 补货中心试点一条 BH 计划或采购申请 |
| 4   | 设计任务驳回/通过路径已培训        |
