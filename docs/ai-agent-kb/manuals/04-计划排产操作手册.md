# 操作手册 · 计划排产（手把手）

**模块入口：** 电脑顶栏 → **计划排产**

> 适合：计划员、技术（设计任务）、采购协同人员。  
> 学完应能：看懂生产计划行与物料缺口；下达生成工单/采购申请；处理设计任务；在库存预警执行补货。

---

## 0. 这个模块在整条链上的位置

```
销售订单审核通过
   →（非标）设计任务 / EBOM
   → 生产计划（看缺口、下达）
   → 生成：加工工单 / 总装工单 / 采购申请 / 外协工单
   → 车间生产与采购执行
```

若公司还在场景一/二（只做报工工资或简单领料），可以先不学本册。

---

## 1. 设计任务（非标/要出图时）

### 1.1 打开页面

左侧 **设计任务**。

列表常见列：状态、设计任务编号、来源、产品名称、型号规格、材质、紧急度、交货日期、EBOM 名称/编码、设计人、校核人等。

**状态：** 待设计 → 设计中 → 待审核 → 审核通过 / 已驳回

### 1.2 设计师怎么操作（逐步）

1. 在列表找到 **待设计**（或设计中）任务。
2. 点操作进入 **打开 EBOM 设计**（按钮文案以页面为准）。
3. 按技术要求维护设计结果 / EBOM / 工艺文件关联。
4. 完成后 **提交审核**，状态变为 **待审核**。

### 1.3 校核人怎么操作（逐步）

1. 筛选 **待审核**。
2. 打开任务，核对 EBOM、参数、附件。
3. **审核通过** 或 **驳回**（驳回后退回修改）。
4. 通过后，计划/生产侧才能按设计结果往下走。

### 1.4 新手注意

- 设计任务通常来自销售订单审核后的非标行，不是凭空乱建。
- 被驳回不要慌：按意见改完再提。

## 2. 生产计划（核心：看缺口并下达）

### 2.1 打开页面

左侧 **生产计划**。

你会看到计划行（成品侧）以及展开后的 BOM/物料行。

**成品侧常见列：** 状态、产品名称/编号、规格、订单数量、库存数量、计划数量、已发货数量、交付日期等。

**物料展开常见列：** 物料名称、供应型态、库存/可用/在途在制、需求数、缺口数、计划数、是否参与计划、指定供应商、工艺路线等。

**计划状态：** 待下达 / 部分下达 / 执行中 / 已完成

### 2.2 读懂「缺口」——计划员第一技能

对每一行物料问自己三句话：

1. **需求多少？**（需求数）
2. **现在能用多少？**（库存/可用/在途在制）
3. **还差多少？**（缺口数）

- 缺口 > 0 且供应型态=外购 → 倾向生成 **采购申请**
- 缺口 > 0 且供应型态=自产 → 倾向生成 **加工/总装工单**
- 缺口 > 0 且供应型态=外协 → 倾向生成 **外协工单/外协订单**

### 2.3 下达生成下游单据（逐步点）

1. 打开某张计划，展开物料。
2. 勾选要参与计划的行（或确认「参与计划」已勾选）。
3. 按需要点击工具区按钮（名称以页面为准）：
   - **生成加工工单**
   - **生成总装/部装工单**
   - **生成采购申请**
   - **生成外协工单**
4. 到对应模块检查是否生成成功：
   - 生产管理 → 生产工单 / 总装工单
   - 采购管理 → 采购申请
   - 外协管理 → 外协订单
5. 计划状态可能变为部分下达 / 执行中。

### 2.4 库存充足时的提醒

若行需求已被软占用覆盖，系统可能提示「可直接从仓库发货（可不排产或减计划数量）」——  
**这是提醒，不是强制。** 计划员自行决定减计划还是照常排产。

### 2.5 常见问题

| 现象                   | 处理                                            |
| ---------------------- | ----------------------------------------------- |
| 生成不了工单           | 查产品是否有生效 BOM/工艺路线；供应型态是否自产 |
| 生成不了采购申请       | 查供应型态是否外购；明细是否有效                |
| 已指定供应商却报错     | 按提示补「供方单位」等必填                      |
| 计划行很多不知道先做谁 | 按交期、缺口、紧急度排序处理                    |

## 3. 库存预警 / 补货中心（手把手）

### 3.1 打开页面

左侧 **库存预警**（别名：补货中心）。也可能从生产计划页进入补货入口。

筛选：来源、类型、产品名称、编码、规格等。

### 3.2 什么行会出现？

常见条件：物料启用了库存预警，且当前库存 ≤ 最低库存；也可以手工添加要补的料。

### 3.3 执行补货（逐步点）

1. 筛选出需要处理的预警行。
2. 看清：当前库存、最低/最高、建议数量。
3. 填写 **补货数量**（必须 > 0）。
4. 选择 **动作**（如：生产 / 采购——以页面选项为准）。
5. 点 **执行补货**。
6. 到生成的单据继续：
   - 生产：可能生成补货计划（单号常见前缀 `BH…`）再下达工单；
   - 采购：生成采购申请。

### 3.4 批量执行注意

若提示「勾选行包含不同动作，请只勾选同一动作后再批量执行」——按同一动作分批勾选。

若提示「库存高于最高水位，仅预警不可执行补货」——这条只提醒，不能执行。

### 3.5 补货台账

左侧 **补货台账**：查看历史补货执行记录，用于对账与追溯。

## 4. 与销售、生产的协作话术（培训用）

| 场景                   | 计划员怎么说                              |
| ---------------------- | ----------------------------------------- |
| 销售问交期             | 我按缺口看：缺料先采购/外协，齐套再排工单 |
| 销售催发货但库存被占用 | 先看自由备货；必要时走跨单调拨占用        |
| 车间问何时有工单       | 计划下达后才会在「生产工单」出现待下发    |
| 采购问申请哪来的       | 计划缺口或补货中心执行采购动作            |

## 5. 端到端练习

1. 准备：一张已审核的销售订单（自产件）进入计划（或手工有计划行）。
2. 打开生产计划 → 展开 BOM → 找出缺口行。
3. 对自产缺口 **生成加工工单**；对外购缺口 **生成采购申请**。
4. 到生产工单确认待下发；到采购申请确认单据存在。
5. （可选）把某物料最低库存调高制造预警 → 库存预警执行一次补货。
