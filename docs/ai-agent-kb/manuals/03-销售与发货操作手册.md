# 操作手册 · 销售与发货

**模块路径：** 顶栏 **销售管理**

## 1. 销售订单全流程

```
新建 → 待提交 → 提交 → 待审核 → 审核通过（进行中）
  →（可选）设计任务 / 自动生成计划·工单·采购
  → 申请发货 → 出库 → 完成 / 作废
```

### 1.1 新建订单

1. **销售管理 → 销售订单 → 新增**
2. 选择客户、交期、币种/税率等
3. 添加明细行：产品、数量、单价、交期、备注
4. 保存为待提交 → 提交审核

### 1.2 审核

- 审核通过后订单进入 **进行中**
- 系统可能：
  - 写入 **销售库存软占用**（`min(行需求, 当时自由备货)`）
  - 按功能参数 **自动生成** 采购申请 / 外协 / 生产工单 / 总装工单
  - 给出「库存充足可直接发货、可不排产或减计划」类提醒（由用户决定）

### 1.3 反审 / 作废 / 完成

| 动作 | 注意                                                        |
| ---- | ----------------------------------------------------------- |
| 反审 | 恢复待审核；释放整单软占用；若已有装牌/出库 SN 可能禁止反审 |
| 作废 | 释放占用；不可再编辑                                        |
| 完成 | 业务完结标记                                                |

### 1.4 订单变更

1. 仅 **进行中** 订单可申请变更
2. 已有待审核变更时，需先审完再开新变更
3. 销售数量不能小于已占用发货数量
4. 待审核变更未通过前，**通常不可申请发货**
5. 若勾选自动审批「销售订单变更」，提交即回写数量/交期/价格等

## 2. 库存提醒与跨单调拨（占用）

审核/查看订单时可看到：

- 现存量、本单软占用、自由备货、他单占用明细

**跨单调拨（急单借占用）：**

1. 订单 C 看到产品被订单 A 占用
2. C 申请从 A 调拨占用 → 确认后占用转到 C，A 记偿还欠量
3. 后续入库优先偿还 A 的欠量

详见 `docs/yunxiao/淄博泵产业互联网平台-以库存生产MTS场景说明.md`。

## 3. 发货管理

### 3.1 申请发货

1. 订单进行中 → 发货管理/订单内申请发货
2. 选择行与数量（不可超可发量；按单模式下不可超本单已入库量）
3. 若随货附件为「申请发货时确定」：勾选纳入附件与套数

### 3.2 仓管出库

1. **库存 → 待出库 / 出库管理** 确认出库
2. 发货扣批规则读取功能参数：
   - **按单发货**：优先本单批次；强制按单生产行不能拿他单货
   - **FIFO**：按仓内批次先后
3. 随货附件也可在 **库存 → 随货查询** 维护后随同出库

### 3.3 出厂质检门控

出库确认可能读取「出厂质检」弱/强管控：当期多为弱管控（预警不拦截）。

## 4. 销售明细与框架合同

- **销售明细**：跨订单行查询、发货/SN 等信息（视版本字段）
- **框架合同**：长期协议下的订单来源（按企业启用）

## 5. 检查清单

| #   | 项                                     |
| --- | -------------------------------------- |
| 1   | 客户档案已建                           |
| 2   | 行产品供应型态正确（影响自动下游单据） |
| 3   | 发货规则（按单/FIFO）与业务一致        |
| 4   | 强制按单生产行与备货策略已向销售培训   |
| 5   | 变更与发货互斥规则已知晓               |
