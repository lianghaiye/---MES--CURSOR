# 操作手册 · 销售与发货（手把手）

**模块入口：** 电脑顶栏 → **销售管理**

> 适合：销售员、跟单、仓管（发货出库协同）、实施顾问。  
> 学完应能独立完成：建销售订单 → 提交审核 → 审核通过 → 申请发货 → 配合出库。

---

## 0. 开始前准备

| 准备项           | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| 客户档案         | 基础配置 → 客户管理 → 客户档案（没有客户无法选客户）         |
| 产品已建         | 产品工艺 → 产品信息；行上要选的产品必须存在                  |
| 角色权限         | 销售能建单/提交；有人能审核；仓管能做出库                    |
| （可选）自动审批 | 功能参数若勾了「销售订单」，提交可能直接通过——培训时先搞清楚 |

**状态一条龙（务必记住）：**

```
待提交 →（提交审核）→ 待审核 →（审核通过）→ 进行中 →（发货/业务完结）→ 已完成
                              ↘（拒绝）→ 已拒绝
进行中还可：反审、作废、订单变更、申请发货
```

---

## 1. 新建销售订单（逐步点）

### 1.1 打开列表

1. 顶栏 **销售管理** → 左侧 **销售订单**。
2. 认一下列表：可按销售单号、合同编号、客户、业务员、状态、发货状态、单据日期筛选。
3. 找到 **新增**（或同类按钮）点进去。

### 1.2 填表头（基本信息）

按下表填写（名称以页面为准；标「必填倾向」的不填容易保存失败）：

| 字段                           | 建议     | 白话说明             |
| ------------------------------ | -------- | -------------------- |
| 客户名称                       | 必填     | 从客户档案选         |
| 交货方式                       | 必填倾向 | 如自提/物流等        |
| 紧急度                         | 必填倾向 | 影响优先级展示       |
| 合同类型 / 订单类型 / 结算币种 | 必填倾向 | 按厂规选             |
| 销售单号                       | 选填     | 空则可能系统生成     |
| 合同编号                       | 选填     | 有合同就填，便于对账 |
| 联系人 / 电话 / 交货地址       | 选填     | 发货常用             |
| 业务员                         | 选填     | 业绩归属             |
| 结算类型、付款比例、首付/定金  | 选填     | 财务相关             |
| 备注、附件                     | 选填     |                      |

### 1.3 添加销售明细（至少一行）

1. 在明细区点 **添加行**（或同类按钮）。
2. 每一行至少要能确定：
   - **产品**（从产品信息选）
   - **数量**
   - **单价**（及税率/折扣等页面字段）
   - 行交期（若有）
3. 可继续加多行。
4. **一张单至少要有一条有效明细**，否则保存会提示类似「请至少添加一条销售明细」。

### 1.4 保存

1. 点 **保存**。
2. 成功提示类似「销售订单已保存」。
3. 此时单据状态一般是 **待提交**（还不能算已经审核通过）。

### 1.5 提交审核

1. 在列表找到该单，或进入详情。
2. 点 **提交审核**。
3. 状态变为 **待审核**。
4. 若开了销售订单自动审批，可能直接变成 **进行中**——以现场为准。

---

## 2. 审核销售订单（审核人逐步点）

1. 打开状态为 **待审核** 的订单详情。
2. 核对：客户、交期、明细产品数量单价、库存提醒（若页面有现存量/占用提示）。
3. 点 **审核**：
   - **通过** → 状态 **进行中**；
   - **拒绝** → 状态 **已拒绝**（通常要填理由）。
4. 审核通过后系统可能同时发生（取决于功能参数）：
   - 写入 **销售库存软占用**；
   - **自动生成** 采购申请 / 外协订单 / 生产工单 / 总装工单；
   - 提示库存充足可直接发货（由人决定，不强制跳过计划）。

**仅「待审核」状态可审核**；状态不对会提示拦截。

---

## 3. 进行中订单：你还能做什么？

进入详情后，常见按钮（随状态/权限显示）：

| 按钮         | 什么时候用         | 注意                                            |
| ------------ | ------------------ | ----------------------------------------------- |
| 申请发货     | 要发货给客户       | 若有「订单变更待审核」横幅，**先审变更再发货**  |
| 订单变更     | 改数量/交期/价格等 | 进行中才可；同时只能有一条待审变更              |
| 反审         | 发现问题打回待审核 | 已装牌/已出库 SN 可能禁止反审；反审会释放软占用 |
| 变更交付方式 | 改交货方式         | 按页面                                          |
| 完成         | 业务完结           | 确认都发完/结清再点                             |
| 作废         | 整单作废           | 不可再当正常单用                                |
| 打印         | 打销售明细         | 浏览器打印                                      |

---

## 4. 订单变更（逐步点）

1. 打开 **进行中** 订单 → 点 **订单变更**（或列表「审核订单变更」相关入口）。
2. 修改需要变更的表头或明细（至少改一项，否则提示「请至少修改一项…」）。
3. 注意：**销售数量不能小于已占用发货数量**。
4. 提交后进入变更单 **待审核**。
5. 有权限的人审核通过后回写订单；驳回则变更不生效。
6. 变更待审期间：**不能申请发货**（页面会有横幅提示）。

若功能参数勾了「销售订单变更」自动审批，提交可能直接回写——培训前确认。

---

## 5. 申请发货（逐步点）

### 5.1 从订单发起（推荐）

1. 打开 **进行中** 且无待审变更的订单。
2. 点 **申请发货**。
3. 填写发货信息：

| 字段                          | 说明                                           |
| ----------------------------- | ---------------------------------------------- |
| 源销售订单                    | 一般已带出                                     |
| 客户名称                      | 必填倾向                                       |
| 交货方式                      | 必填倾向                                       |
| 本次发货数量（明细行）        | 每行要发的数量，须 > 0；不发的行请移出         |
| 物流单号 / 司机 / 车牌 / 地址 | 按需要                                         |
| 出库仓库 / 申请出库           | 按页面开关                                     |
| 随货附件                      | 若参数为「申请发货时确定」，在此勾选纳入与套数 |

4. 保存。成功提示类似「发货申请已记录」/「已保存」。

### 5.2 从发货管理发起

1. 左侧 **发货管理** → 新建。
2. **选择源销售订单** → 带出客户与可发明细。
3. 填本次数量与交货信息 → 保存。

### 5.3 常见报错

| 提示                                 | 处理                     |
| ------------------------------------ | ------------------------ |
| 请选择源销售订单 / 客户 / 交货方式   | 补必填                   |
| 请填写本次发货数量 / 须大于 0        | 填正数或移出行           |
| 本单产品均已发完，无法再次申请发货   | 没有剩余可发量           |
| 关联出库单已出库，不允许修改发货数量 | 改数量请新建发货单发剩余 |
| 存在待审核的订单变更…不可申请发货    | 先审完变更               |

---

## 6. 仓管确认出库（发货后半段）

1. 顶栏 **库存管理** → **待出库列表** 或 **出库管理**。
2. 找到对应出库单（可通过源单号/销售单号查）。
3. 核对仓库、批次、数量。
4. 点 **确认出库**（或保存并出库）。
5. 回到发货管理，发货状态应推进为已出库/已发货（以页面为准）。

### 6.1 按单发货 vs FIFO（要懂）

管理员在 **系统管理 → 功能参数** 配置「发货出库规则」：

| 规则          | 白话                                                    |
| ------------- | ------------------------------------------------------- |
| 按单发货      | 优先/必须扣「本销售单」挂标入库的批次，防止发错别人的货 |
| 先进先出 FIFO | 不区分是不是本单生产的，按仓里批次先后扣                |

若提示「本单按单库存不足」：先完成本单入库，或评估是否改规则（需管理员），不要强行乱发。

### 6.2 出厂质检

出库时可能弹出质检预警（弱管控）。当期多为预警不强制拦截；是否必须先做出厂检，问质检与管理员参数。

## 7. 库存提醒与「货被别的单占用了」

审核/查看订单时，页面可能显示：现存量、本单占用、自由备货、他单占用。

**白话：**

- 仓库里有货，但「自由备货」不够 → 可能被别的订单软占用了。
- 急单要借占用：按页面提供的 **跨单调拨/占用转移** 申请并确认（确认后占用转到急单，原单记偿还欠量）。
- 低库存补货：到 **计划排产 → 库存预警** 执行补货（见计划手册）。

---

## 8. 端到端练习（标准品）

1. 建客户「练习客户」；产品「练习件-A」已存在且有库存或可后续入库。
2. 新建销售订单 1 行数量 1 → 保存 → 提交审核 → 审核通过。
3. 申请发货，本次数量 1 → 保存。
4. 库存出库确认。
5. 订单发货状态变为已发货/可完成则点完成。
