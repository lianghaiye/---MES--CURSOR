# 操作手册 · 快速入门

## 1. 适用读者

首次使用 I-DOMS 的工人、主任、仓管、管理员；以及 AI Agent 回答「怎么开始用」。

## 2. 登录与端选择

| 端         | 用途                                              |
| ---------- | ------------------------------------------------- |
| WEB        | 主数据、开单、审核、工资推送、库存确认、系统配置  |
| 微信小程序 | 报工、领任务、现场领料/入库、质检填报、看工时工资 |

账号由管理员在组织人员中维护；工人以小程序账号为主。

## 3. 按角色的「第一天」路径

### 3.1 工人（场景一最小闭环）

1. 打开小程序 → **工序报工**
2. 若任务报工：在「待领」领取 →「今日待报工」填写良品/不良 → 提交
3. 若快速报工：进入「快速报工」选产品/工序 → 填数量 → 提交
4. 到 **工时工资** 查看（若看不到：工资推送模式可能是审核后/手动，属正常）

### 3.2 车间主任

1. WEB：**报工管理 → 工序报工** → 审核通过或拒绝（拒绝填原因）
2. 需要时：**报工确认** 调整数量/补贴
3. **工资核算**：按功能参数推送工资
4. **生产管理 → 生产工单**：开立/下发（场景三及以上）

### 3.3 仓管（场景二起）

1. 维护 **基础配置 → 仓库**（原料仓、成品仓、线边仓）
2. 处理 **领料** 发料出库；**成品入库** 审核入库
3. 对内：按配置确认 **库存扣减记录**（勿对外宣讲为独立功能卖点）

### 3.4 管理员实施首日

1. 导入人员、产品、工序、工价（场景一最少三张表）
2. **系统管理 → 业务规则**：生产模式
3. **系统管理 → 功能参数**：工资推送；场景二起配置库存扣减与自动审批
4. 签《计薪口径确认表》后再试点

## 4. 首页工作台

- 可收藏常用菜单入口
- 可能展示待办、消息（以现场配置为准）
- 找不到功能：顶部切换一级模块，或让管理员开权限

## 5. 最小验收标准（场景一）

| 检查项   | 通过标准                                 |
| -------- | ---------------------------------------- |
| 工人报工 | 小程序能提交一笔报工                     |
| 主任审核 | Web 能审核通过                           |
| 工资可见 | 按约定推送模式，工人或财务能看到对应明细 |
| 口径一致 | 与签字的计薪口径一致                     |

## 6. 常见卡点（入门）

| 现象                | 处理方向                                        |
| ------------------- | ----------------------------------------------- |
| 小程序没有报工入口  | 角色/产品包未开通；或业务规则关闭了对应报工类型 |
| 报工选不到产品/工序 | 主数据未建或已归档                              |
| 审核后工人仍无工资  | 查工资推送=手动且未推送                         |
| 菜单是空的          | 账号角色错误或租户未授权模块                    |
