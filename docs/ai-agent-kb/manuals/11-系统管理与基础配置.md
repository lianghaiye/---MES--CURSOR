# 操作手册 · 系统管理与基础配置

## 1. 基础配置（业务主数据）

**顶栏 → 基础配置**

| 菜单               | 用途                 | 场景依赖 |
| ------------------ | -------------------- | -------- |
| 员工组别           | 班组、便于派工与筛选 | 一～五   |
| 不良品项           | 报工/质检不良分类    | 一～五   |
| 材质 / 单位 / 包装 | 物料属性             | 二～五   |
| 业务字典           | 业务枚举扩展         | 按需     |
| 仓库 / 货位 / 分类 | 仓储结构             | 二～五   |
| 客户               | 销售订单             | 四～五   |
| 供应商             | 采购/外协            | 四～五   |

### 1.1 仓库配置建议

- 明确默认发料仓、线边仓、成品仓
- 货位（若启用货位管理 1.6.1）：按仓维护货位编码

### 1.2 客商

客户/供应商编码唯一；停用而非随意删除，避免历史单据断引用。

## 2. 系统管理

**顶栏 → 系统管理**

| 菜单                                        | 用途                           |
| ------------------------------------------- | ------------------------------ |
| 系统字典                                    | 系统级枚举                     |
| 业务规则                                    | 生产模式等核心流程开关         |
| 功能参数                                    | 自动化、库存、工资、质量门控等 |
| 组织人员 / 角色（若在本模块或独立权限中心） | 账号与授权                     |

详细参数说明见 [01-功能参数与业务规则.md](../reference/01-功能参数与业务规则.md)。

## 3. 推荐初始化顺序

```
1. 组织与角色、管理员账号
2. 系统字典 / 业务字典
3. 单位、材质、不良品项
4. 仓库（及货位）
5. 人员与员工组别 → 绑定小程序
6. 客户 / 供应商（场景四）
7. 产品、工序、工艺、BOM、工价
8. 业务规则（生产模式）
9. 功能参数（工资推送、扣减、自动审批/生成）
10. 签计薪口径 → 试点
```

## 4. 工程变更（ECN）

**顶栏 → 工程变更**

1. 新建变更单 → 草稿编辑
2. 提交进入审批 → 待审批/审批中
3. 可撤回（仅待审批/审批中）回到草稿
4. 审批通过后按方案更新 BOM/工艺等（以版本实现为准）

产品/工序名变更会导致工价失配，须走变更并通知计薪相关人员。

## 5. 工业标识

**顶栏 → 工业标识**

- 申请 SN、装牌确认、出库关联
- 已作废 SN 不可修改/装牌
- 已装牌或已出库可能禁止销售反审
- 补申请数量须 > 0

## 7. 管理员日常运维

| 事项               | 动作                               |
| ------------------ | ---------------------------------- |
| 新人入职           | 建人员 → 角色 → 小程序账号 → 组别  |
| 调薪/改工价        | 口径确认 → 改主数据 → 通知在制报工 |
| 开关自动审批       | 评估风险后改功能参数并公示         |
| 客户说「功能没了」 | 查角色权限 → 查参数 → 查单据状态   |

## 8. 检查清单

| #   | 项                             |
| --- | ------------------------------ |
| 1   | 角色菜单与五场景范围一致       |
| 2   | 功能参数已按场景勾选并截图存档 |
| 3   | 业务规则生产模式正确           |
| 4   | 仓库/线边仓齐全                |
| 5   | 字典与不良品项可用             |
