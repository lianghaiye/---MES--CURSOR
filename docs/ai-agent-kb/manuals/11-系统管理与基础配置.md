# 操作手册 · 系统管理与基础配置（手把手）

**模块入口：**

- 顶栏 **基础配置**
- 顶栏 **系统管理**

> 适合：系统管理员、实施顾问。  
> 学完应能：按推荐顺序初始化主数据；配好生产模式与功能参数；建仓库/客户/供应商；知道改参数后要通知现场。

---

## 0. 初始化总顺序（请严格按序，别跳）

把下面当作实施第一周检查表：

| 顺序 | 做什么                               | 菜单                        |
| ---- | ------------------------------------ | --------------------------- |
| 1    | 组织人员、角色、管理员账号           | 权限/组织（以现场入口为准） |
| 2    | 系统字典 / 业务字典                  | 系统管理、基础配置          |
| 3    | 单位、材质、包装、不良品项           | 基础配置                    |
| 4    | 仓库（及货位）                       | 基础配置 → 仓库管理         |
| 5    | 员工组别，绑定小程序账号             | 基础配置 → 员工组别 + 人员  |
| 6    | 客户、供应商（场景四）               | 基础配置                    |
| 7    | 产品、工序、工艺、BOM、工价          | 产品工艺（见手册 02）       |
| 8    | 业务规则：生产模式                   | 系统管理 → 业务规则         |
| 9    | 功能参数：工资推送、扣减、自动审批等 | 系统管理 → 功能参数         |
| 10   | 签计薪口径 → 小范围试点              | 附件 + 现场                 |

## 1. 基础配置逐项手把手

### 1.1 员工组别

1. **基础配置 → 员工组别**。
2. 新增班组/组别名称。
3. 把人员归入组别，便于派工筛选。

### 1.2 不良品项

1. **不良品项** → 新增。
2. 录入现场常用不良原因（名称简洁统一）。
3. 报工不良分摊、质检分类都会用到——**先定字典再培训工人**。

### 1.3 单位 / 材质 / 包装

分别进入对应菜单新增。  
产品信息里的库存单位、材质下拉依赖这里——先建再录产品。

### 1.4 业务字典

维护业务侧扩展枚举。改动前确认是否影响已有单据展示。

### 1.5 仓库列表（重点）

1. **基础配置 → 仓库管理 → 仓库列表**。
2. 点新增，填写：

| 字段         | 说明                                          |
| ------------ | --------------------------------------------- |
| 仓库名称     | 必填，如「原料仓」「线边仓-一车间」「成品仓」 |
| 仓库类型     | 必填                                          |
| 管理员       | 必填                                          |
| 仓库排序     | 必填（影响列表顺序）                          |
| 所属工作中心 | 选填                                          |
| 允许负库存   | 谨慎开启                                      |
| 地址 / 备注  | 选填                                          |
| 仓库编号     | 可填                                          |

3. 保存。建议至少建齐：发料仓、线边仓、成品仓。
4. 需要货位时：**货位管理** 按仓维护货位编码。
5. **仓库分类** 用于归类管理。

小程序领料选的「领入仓库」就来自这里——线边仓一定要建好。

### 1.6 客户档案

1. **客户管理 → 客户档案** → 新增。
2. **客户名称必填**；维护类型、分级、业务员、联系人、地址、价目等。
3. 销售订单必须能选到客户。

### 1.7 供应商档案

1. **供应商管理 → 供应商档案** → 新增。
2. **供应商名称必填**；维护分类、供货期、结算方式等。
3. 采购订单、外协订单都依赖供应商。

## 2. 业务规则（生产模式）——决定工人怎么报工

### 2.1 打开页面

**系统管理 → 业务规则**。  
列表常见列：业务场景、配置项、说明。

### 2.2 配置生产模式（逐步）

1. 找到 **生产模式** 配置项。
2. 选择其一：

| 选项       | 现场效果                                           |
| ---------- | -------------------------------------------------- |
| 标准模式   | 下发 → 领取 → 报工 → 审核 → 核算 → 推送            |
| 极简报工   | 再选子项：**快速报工** 或 **任务报工**（二者互斥） |
| 下发即报工 | 跳过现场报工与确认（特殊简化，慎用）               |

3. 保存。
4. **立刻通知主任和工人**：入口变了（有没有「快速报工」Tab）。

## 3. 功能参数——逐项会配

### 3.1 打开页面

**系统管理 → 功能参数**。  
左侧是分类导航，右侧是配置表。

常见分类：

- 流程自动化
- BOM与工艺文件
- 库存与出库
- 生产与计划
- 质量
- 辅助工具
- 消息通知

改完记得保存，并截图存档。

### 3.2 工资推送（必配）

位置：生产与计划相关区域 → **工资推送模式**

| 值        | 标签       |
| --------- | ---------- |
| on_report | 报工即推送 |
| on_audit  | 审核后推送 |
| manual    | 手动推送   |

详见《06-工时工资》。

### 3.3 库存扣减方式（对内必配，场景二起）

| 值                      | 标签（白话）                                    |
| ----------------------- | ----------------------------------------------- |
| no_issue                | 不领料：极简/无工单，不生成完工扣减             |
| post_complete_by_report | 完工预扣：无领料，扣发料仓，**必须人工确认**    |
| self_issue_by_actual    | 自主领料：发料→线边，完工扣线边，**可自动确认** |

对外话术不要讲「扣减场景」，见实施备忘。

### 3.4 自动审批（按企业收紧或放开）

勾选即「提交即通过」。常见项：

- 采购订单、销售订单
- 各类价格/订单变更
- 外协订单
- **成品入库**、**领料申请**
- **库存扣减**（仅自主领料模式真正自动确认）
- 报废单审批（是否完全接入以版本为准）

**建议：** 管理严的单先别勾；小厂领料/成品入库可勾，减少等待。

### 3.5 自动生成单据

销售审核后按供应型态生成：采购申请、外协订单、生产工单、总装/部装工单。

**主数据未清洗前建议全关。**

### 3.6 出库与发货规则

| 参数                 | 选项                    | 作用范围       |
| -------------------- | ----------------------- | -------------- |
| 出库规则             | 本期多仅 FIFO           | 领料、外协发料 |
| 发货出库规则         | 按单发货 / FIFO         | 仅销售发货     |
| 随货附件确定时机     | 申请发货时 / 仓管发货时 | 发货附件       |
| 调拨是否需入库方签收 | 是/否                   | 调拨           |
| 盘点审核后自动过账   | 是/否                   | 盘点           |
| 下料结算策略         | 余料留线边 / 余料回库   | 下料料         |

### 3.7 质检门控

五类分别配置弱/强；当期多仅弱管控可选。

### 3.8 辅助工具

面积换算、重量计算：BOM 下料与采购订货尺寸弹窗用；不需要可关。

## 5. 工程变更（ECN）简要手把手

1. 顶栏 **工程变更** → **ECN 列表**。
2. 新建草稿 → 编辑变更内容。
3. **提交**进入审批。
4. 待审批/审批中可 **撤回** 回草稿。
5. 审批通过后按方案更新 BOM/工艺等。  
   产品工序改名影响工价时，必须走变更并通知计薪人员。

---

## 6. 工业标识（简要）

**工业标识** 模块：标识申请、标识管理、企业信息、产品信息模板。

注意：

- SN 格式常为 4–64 位字母数字等；
- 已作废不可装牌；
- 已装牌/已出库可能禁止销售反审。

## 7. 管理员日常运维清单

| 场景                 | 动作                                 |
| -------------------- | ------------------------------------ |
| 新人入职             | 建人 → 角色 → 小程序绑定 → 进组别    |
| 调工价               | 确认口径 → 改产品工时配置 → 告知在制 |
| 客户说没菜单         | 查角色 → 查产品包 → 查是否进错环境   |
| 自动生成乱单         | 先关自动生成 → 清错单 → 修供应型态   |
| 工人突然少了快速报工 | 查业务规则生产模式是否被改           |

## 8. 端到端练习（管理员）

1. 新建仓库：原料、线边、成品。
2. 新建不良品项 3 条。
3. 业务规则设为「极简 + 快速报工」（或按试点需要）。
4. 功能参数：工资推送=审核后推送；领料自动审批按需。
5. 按手册 02 建一个产品+工序+工价。
6. 带 1 工人 1 主任跑通报工审核。
