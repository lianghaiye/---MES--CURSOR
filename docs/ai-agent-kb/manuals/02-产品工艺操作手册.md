# 操作手册 · 产品工艺

**模块路径：** 顶栏 **产品工艺**

## 1. 模块目标

维护「做什么产品、用什么料、走什么工序、工价多少」——报工、工单、BOM 展开、采购生成的共同底座。

## 2. 产品信息

### 2.1 新建/维护产品

1. 进入产品信息列表 → 新增
2. 填写：编码、名称、规格型号、单位、分类、材质等
3. 关键业务字段（按企业启用）：
   - **供应型态**：自产 / 外购 / 外协等（影响销售审核后自动生成单据）
   - **计划策略**：按单 / 以库存（标签与提醒；不单独当作「绝不建计划」开关）
   - SKU（若启用多规格）
   - 是否需要下料结算、库存预警上下限等

### 2.2 归档

归档后选品不再展示；已被 BOM/工单/订单引用的历史数据不受影响。

### 2.3 实施建议

- 场景一试点：先 3～5 个主力产品，编码唯一、工序名统一
- 禁止口头多名；改名走变更，避免工价失配

## 3. 产品 BOM

### 3.1 维护结构

1. 选择父项产品 → 新建/编辑 BOM
2. 添加子件：物料、单位用量、损耗（若有）、供应型态
3. 下料类物料可维护下料尺寸；可用面积换算/重量计算辅助（功能参数「辅助工具」）
4. 保存并按企业规则生效（草稿/生效策略以参数为准）

### 3.2 随货附件 BOM

随货附件可独立 BOM 类型；发货时按「随货附件确定时机」纳入出库清单。

### 3.3 与生产的关系

- 工单完工库存扣减：按 **BOM 单位用量 × 完工数量**
- 生产计划展开：按 BOM 展开需求（是否 BOM 级 MTS 见功能参数）

## 4. 工艺路线与工序

### 4.1 工序配置

维护工序名称、分类、关联表单模板、是否质检工序等。

### 4.2 工艺路线编辑

1. 新建路线并关联产品（或通用路线，视版本）
2. 按步骤添加工序；可配置并行步、选做完成
3. 配置完成模式（如全部完成 / 选做完成）
4. 归档后不可用于新工单下发

**校验示例：** 请至少配置一个工序步骤；并行/步数超限会提示。

### 4.3 工价 / 工时配置

在产品或工序维度配置计件单价、计时费率（入口以现场菜单为准，常见在产品/工序或工时相关页）。  
**改工价前必须计薪口径已确认。**

## 5. 工艺文件与表单模板

- 工艺文件：图纸、作业指导上传与版本管理（按企业启用）
- 工序表单模板：报工/质检表单字段定义

## 6. 操作检查清单

| #   | 项                                |
| --- | --------------------------------- |
| 1   | 产品编码唯一且与现场叫法一致      |
| 2   | 报工要用的工序都在路线中          |
| 3   | 计件工序已有单价                  |
| 4   | 领料/扣减依赖的 BOM 用量正确      |
| 5   | 外购/外协件供应型态正确（场景四） |
