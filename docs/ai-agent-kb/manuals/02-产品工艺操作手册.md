# 操作手册 · 产品工艺（手把手）

**模块入口：** 电脑顶栏 → **产品工艺**

> 本模块解决：系统里有哪些产品、用什么料（BOM）、走哪些工序（工艺路线）、报工怎么计价。  
> **建议学习顺序：** 工序配置 → 工艺路线 → 产品信息（含工时配置）→ 产品 BOM。  
> 场景一最少要会：产品 + 工序 + 工价；任务报工还要会工艺路线。

---

## 0. 开始前准备

请先准备一张纸或 Excel（可对照实施附件《主数据采集表》）：

| 要准备的内容               | 举例                | 用途                       |
| -------------------------- | ------------------- | -------------------------- |
| 产品编码与名称             | P001 水泵壳体       | 报工选产品、开单           |
| 规格型号 / 材质 / 图号     | DN50 / HT200 / T-01 | 现场辨认                   |
| 库存单位                   | 件、kg、㎡          | 出入库计量                 |
| 供应型态                   | 自产 / 外购 / 外协  | 影响后续自动生成工单或采购 |
| 工序清单与工价             | 车削 2 元/件        | 报工与工资                 |
| BOM 子件与用量（场景二起） | 螺栓 ×4             | 领料/扣减/计划             |

## 1. 工序配置（先建「车间会做哪些活」）

### 1.1 打开页面

1. 顶栏点 **产品工艺**。
2. 左侧点 **工序配置**。
3. 你会看到工序列表，上方一般有筛选：工序名称、工序分类、资源类型、状态；以及 **新增**、导入等按钮。

### 1.2 新增一道工序（逐步点）

1. 点右上角（或工具栏）**新增**。
2. 在表单里按下面说明填写：

| 字段            | 是否必填       | 怎么填（白话）                                                 |
| --------------- | -------------- | -------------------------------------------------------------- |
| 工序名称        | 必填           | 现场统一叫法，如「粗车」「焊接」「装配」。**全厂不要一名多叫** |
| 工序分类        | 必填           | 从下拉选分类（没有分类先去「工序分类」建）                     |
| 资源类型        | 必填           | 按页面选项选（人/设备等，以现场字典为准）                      |
| 默认执行人/工组 | 必填           | 方便派工默认落到谁/哪个班组                                    |
| 报工类型        | 选填           | 批量计件 / 时长等，按厂规                                      |
| 不良品项        | 选填           | 本工序常见不良原因                                             |
| 工序操作开关    | 选填           | 如 **下料 / 质检 / 外协 / 拆解** ——需要才打开                  |
| 质检类型        | 开了质检后必选 | 可多选；工单下发时可能按勾选项生成质检任务                     |
| 图片 / 备注     | 选填           | 作业示意、说明                                                 |

3. 点 **保存**。成功一般提示「已保存」或「已新增」。
4. 回到列表，确认能搜到这道工序，状态为可用。

### 1.3 常见报错

| 提示                   | 处理                     |
| ---------------------- | ------------------------ |
| 请输入工序名称         | 名称不能空               |
| 请选择工序分类         | 先选或先建分类           |
| 请选择资源类型         | 必须选                   |
| 请选择默认执行人/工组  | 必须选                   |
| 请至少勾选一种质检类型 | 打开了质检开关却没勾类型 |

### 1.4 练习题

新建两道工序：「下料」「机加」，并都能在列表里查到。

## 2. 工艺路线（把工序串成「先做什么后做什么」）

### 2.1 打开页面

左侧 **工艺路线** → 列表可见：路线编码、路线名称、适用范围、适用对象、工序数量、状态等。

### 2.2 新增一条路线（逐步点）

1. 点 **新增**。
2. 填写：

| 字段                | 是否必填 | 说明                             |
| ------------------- | -------- | -------------------------------- |
| 路线名称            | 必填     | 如「水泵壳体标准路线」           |
| 适用范围 / 适用对象 | 必填     | 按页面选项选，关系到哪些产品能用 |
| 备注                | 选填     |                                  |

3. 在路线编辑区（网格/步骤编辑器）**按生产顺序添加工序**：
   - 每一步选已建好的工序；
   - 如有并行、选做完成，按页面说明配置（选做步至少要选一道工序）。
4. 点 **保存**。成功提示类似「保存成功」。
5. 记下这条路线，后面要挂到产品的「默认工艺路线」。

### 2.3 归档与取消归档

- **归档**：详情或列表操作「归档」。确认文案类似：归档后不可用于新工单下发。
- **取消归档**：已归档路线可恢复后再用于新单。
- 已归档路线不可编辑，需先取消归档。

### 2.4 常见报错

| 提示                                  | 处理             |
| ------------------------------------- | ---------------- |
| 请至少配置一个工序步骤                | 路线里至少加一步 |
| 工序步数/并行数超过上限               | 简化步骤         |
| 第 X 步为选做完成，请至少选择一道工序 | 选做步勾选工序   |
| 已归档的工艺路线不可编辑              | 先取消归档       |

### 2.5 练习题

建一条含「下料 → 机加」两步的路线并保存。

## 3. 产品信息（建「要做什么货」）

### 3.1 打开页面并认界面

1. 左侧点 **产品信息**。
2. 注意列表可能有：
   - 视图：**SKU 视图** / **模板视图**
   - Tab：**在用** / **已归档**
3. 工具栏常见按钮：**新增**、删除、归档、同步规格属性、打印标签、批量导入/导出。

### 3.2 新增一个产品（逐步点）

1. 点 **新增**，打开产品表单。
2. **必填项先填完**（不填保存会被拦）：

| 必填字段     | 怎么填                                                                   |
| ------------ | ------------------------------------------------------------------------ |
| 产品名称     | 现场通用名                                                               |
| 条码类型     | 按下拉选择                                                               |
| 类型         | 按下拉选择（产品/物料等，以页面为准）                                    |
| **供应型态** | 自产 / 外购 / 外协等。**很重要**：后面销售审核自动生成工单还是采购，看它 |
| 规格型号     | 如 DN50                                                                  |
| 库存单位     | 件 / kg 等                                                               |

3. **建议一并填写的重要项**（按你们场景）：

| 字段                  | 什么时候要填                                    |
| --------------------- | ----------------------------------------------- |
| 编码                  | 有编码规则就填，保持唯一                        |
| 材质 / 图号           | 机加、泵阀类强烈建议                            |
| 计划策略              | 按单 / 以库存（提醒用，别误解成「绝不建计划」） |
| 默认工艺路线          | 任务报工、开工单时强烈建议选好                  |
| 默认存放仓库          | 有库存业务时建议                                |
| 默认采购/外协供应商   | 外购外协件建议                                  |
| **启用工时配置**      | 要算计件/计时工资时打开并维护工序单价等         |
| 库存预警（最高/最低） | 要做补货中心时填写                              |
| 需要下料结算          | 板材/型材等余料要结算时勾选                     |
| 入库质检要求          | 质量场景                                        |

4. 若打开了 **工时配置**，按工序维护例如：
   - 报工类型、单件标准工时、整批准备工时、计薪方式、单价等（以表单实际字段为准）。
   - **改工价前确认计薪口径已签字。**

5. 点 **保存**。
   - 若马上要搭 BOM，可点 **保存并维护 BOM**（若按钮存在）。
6. 成功提示类似「已保存」。回到列表，在「在用」中能搜到。

### 3.3 归档产品

1. 勾选或打开不用的产品 → **归档**。
2. 归档后选品列表不再展示；已被 BOM/工单/订单引用的历史不受影响。
3. 需要再用时走「取消归档」（若页面提供）。

### 3.4 常见报错

| 提示                             | 处理   |
| -------------------------------- | ------ |
| 请填写产品名称                   | 补名称 |
| 请选择条码类型 / 类型 / 供应型态 | 补选项 |
| 请填写规格型号                   | 补规格 |
| 请选择库存单位                   | 补单位 |

### 3.5 练习题（场景一最小）

新建产品「练习件-A」，供应型态选自产，单位选件，挂上默认工艺路线，并给「机加」工序配一个计件单价。

## 4. 产品 BOM（建「用哪些料、用多少」）

> 场景一可以暂缓；场景二/三/四做领料、扣减、计划展开前必须会。

### 4.1 打开页面

左侧 **产品 BOM**（随货附件在「随货附件」菜单，逻辑类似但类型不同）。

列表常见列：BOM 状态、名称、编号、类型、物品、版本、是否默认、生效日期等。  
按钮常见：**新增产品 BOM**、**新增基准 BOM**、批量审核发布、归档、导出。

### 4.2 新建并发布 BOM（逐步点）

1. 点 **新增产品 BOM**。
2. 在左侧树 **切换选中根产品/物料**（不选根物品会保存失败）。
3. 填写 **BOM 名称**（必填），BOM 类型、版本按需要填。
4. 在明细区 **至少添加一条子件**：
   - 选择子物料；
   - 填 **单位用量**（以及页面提供的损耗等字段）；
   - 下料类可维护下料尺寸；若功能参数开了「面积换算/重量计算」，可用弹窗辅助。
5. 先点 **保存**：
   - 通常状态为 **待发布**；提示类似「BOM 已保存，状态为待发布，审核发布后方可用于生产」。
6. 再点 **保存并发布**，或回列表做 **审核发布**：
   - 成功提示类似「当前版本已生效可用于生产」。
7. 回列表确认 **BOM 状态为生效/已发布**（以页面文案为准）。

### 4.3 为什么必须发布？

未发布的 BOM 往往不能用于生产建单、计划展开或完工扣料。  
**保存 ≠ 已可生产，发布后才算数。**

### 4.4 常见报错

| 提示                                      | 处理                      |
| ----------------------------------------- | ------------------------- |
| 请输入 BOM 名称                           | 补名称                    |
| 请先通过左侧树切换选择产品/物料           | 先选根物品                |
| 请至少添加一条物料明细                    | 加子件                    |
| 请为所有子项选择物料                      | 每行都要选物料            |
| 该产品无自有生效 BOM，不可按产品 BOM 建单 | 去发布生效 BOM 后再开工单 |

### 4.5 随货附件

菜单 **随货附件**：维护随货附件类 BOM；发货时是否在申请发货页勾选，看功能参数「随货附件确定时机」。

## 6. 端到端练习：从 0 做出一套可报工主数据

按顺序做一遍（预计 30～60 分钟）：

1. **工序分类**里建「机加类」（若没有）。
2. **工序配置**新增「下料」「机加」。
3. **工艺路线**新增「练习路线」，步骤：下料 → 机加，保存。
4. **产品信息**新增「练习件-A」：
   - 供应型态=自产，单位=件；
   - 默认工艺路线=练习路线；
   - 启用工时配置，给机加填计件单价。
5. （可选）**产品 BOM** 给练习件-A 加 1～2 个子件，**保存并发布**。
6. 让主任用该产品开一张工单下发，工人小程序能领到任务（或快速报工能选到产品工序）。

## 7. 日常维护规范（避免月底工资对不上）

1. **编码、工序名一经试点锁定**，改名走变更并通知计薪相关人。
2. 改工价：先确认是否影响在制报工；已审核记录通常不回溯改价。
3. BOM 变更：在制工单与新单用哪一版，走 ECN/厂规，不要私下改生效 BOM 却不沟通。
4. 不用的产品/路线用 **归档**，不要直接删除被引用数据。

## 8. 本模块检查清单

| #   | 检查项                     | 通过标准                     |
| --- | -------------------------- | ---------------------------- |
| 1   | 试点产品在「在用」可搜到   | 编码唯一、名称与现场一致     |
| 2   | 供应型态正确               | 自产/外购/外协与真实业务一致 |
| 3   | 工序名称统一               | 与报工、工价一致             |
| 4   | 工艺路线可用               | 未归档，步骤完整             |
| 5   | 产品挂了默认路线           | 开单/报工不选错路线          |
| 6   | 计件/计时工价已配          | 与口径表一致                 |
| 7   | （库存场景）BOM 已发布生效 | 列表状态为可生产             |
| 8   | （补货场景）预警上下限已填 | 库存预警能出建议             |
