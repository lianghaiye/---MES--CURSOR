# 流程 · P06 五场景选型与扩场景

## 1. 五场景一览

| 编码 | 对外名称                      | 一句话价值           | 建议周期        |
| ---- | ----------------------------- | -------------------- | --------------- |
| 一   | 快速报工 + 工资核算           | 手机报工，工资算得出 | 1～2 周         |
| 二   | 一 + 领料 + 成品入库          | 料出、货进留单       | 2～4 周         |
| 三   | 任务报工 + 工资 + 领料 + 入库 | 工单任务约束         | 3～5 周         |
| 四   | 订单→BOM→计划→生产→库存→采购  | 接单到采购闭环       | 6～10 周        |
| 五   | 四 + 质量管理                 | 出厂检/报废留痕      | 四之上 +2～4 周 |

| 强制出厂检             | 五（或四后紧跟）     | —      |

## 3. 四维诊断（选型问题清单）

### 3.1 组织

- 几个车间/班组/班次？
- 有无独立主任/计划/仓管/采购/质检？还是一人多岗？
- 工资谁审、入库谁点头、采购谁批？

### 3.2 职能是否要系统化

| 职能 | 要上系统的信号                   | 可暂缓信号         |
| ---- | -------------------------------- | ------------------ |
| 仓管 | 账实纠纷、要按单出入库           | 料少口头清点够用   |
| 采购 | 缺料频繁、供应商多、要按单算需求 | 老板亲自买、无计划 |
| 质检 | 客户要出厂报告、不良争议多       | 仅目视无留痕诉求   |

### 3.3 数据基础

弱：无统一编码 → 场景一，先三张表。  
中：Excel 不统一 → 二/三，先清洗。  
强：BOM/工艺完整 → 可评估四/五。

### 3.4 人员认知

弱：抵触手机 → 小范围试点+「报工=算钱」激励。  
强：用过 ERP → 可谈四/五，忌承诺一夜替换。

## 4. 各场景「做 / 不做」边界（对客）

| 场景 | 做                         | 不做（本期）                                   |
| ---- | -------------------------- | ---------------------------------------------- |
| 一   | 快速报工、审核、计件/计时  | 完整工单任务；销售/BOM/采购/质量；对外不讲扣减 |
| 二   | 一 + 领料 + 成品入库       | 完整任务派工；对外扣减卖点                     |
| 三   | 任务报工 + 工资 + 领料入库 | 订单驱动计划采购（四）                         |
| 四   | 销售到采购闭环 + 车间能力  | 完整 QMS（见五）；对外扣减卖点                 |
| 五   | 四 + 质检模板/出厂/报废    | 实验室 LIMS、大图质量追溯平台                  |

## 5. 配置随场景升级清单

| 从→到          | 新增配置重点                                     |
| -------------- | ------------------------------------------------ |
| →一            | 工资推送；极简快速；计薪口径                     |
| 一→二          | 仓库；扣减模式；领料/入库自动审批                |
| 二→三 或 一→三 | 生产模式任务/标准；工艺路线；工单下发            |
| 三→四          | 客户供应商 BOM；自动生成单据；发货规则；设计任务 |
| 四→五          | 质检模板；门控；报废；小程序质检                 |

## 6. Agent 选型回答模板

1. 用 4～6 个诊断问题确认现状
2. 给出推荐场景 + 一句话理由
3. 说明本期明确不做的边界，管理期望
4. 给出试点周期与验收标准
5. 指向对应 manuals / checklists
