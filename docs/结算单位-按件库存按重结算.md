# 结算单位改造方案（白话版）

厂里记账、领料往往按「件 / 米 / 张」；跟供应商结账有时按「公斤」等另一套单位。

以前系统默认：**库存怎么记，钱就怎么算**。铸件、管材等「库存一件、按秤重结账」对不上。

**结算单位**就是专门管「跟供应商算钱用哪个单位」，跟厂里库存记账分开。

| 项       | 内容                                                             |
| -------- | ---------------------------------------------------------------- |
| 适用范围 | 物料主数据、采购订单计价、收货/入库/采购退货结算数量、采购结算单 |
| 典型物料 | 铸件毛坯：库存/采购=件，结算=kg；管材：库存=米，结算=kg          |
| 低值易耗 | 仍用「领料属性」，与结算单位无关                                 |

---

## 三个单位各干什么

主数据只配三项（结算可空）：

| 叫什么   | 白话                                                  | 例子                       |
| -------- | ----------------------------------------------------- | -------------------------- |
| 库存单位 | 仓库记账、领料、出库用这个                            | 件、米、㎡                 |
| 采购单位 | 跟供应商下单、点货件数用这个                          | 根、张、件（可与库存相同） |
| 结算单位 | 跟供应商算钱用这个；**空着 = 跟库存一样，不算单独开** | kg                         |

系统自己判断，业务员不用开开关、也不用懂「双单位 / 计量形态」：

- 采购单位 ≠ 库存单位 → 入库要先填「到货件数」，再填库存数量
- 结算单位有值且 ≠ 库存 → 入库还要再填「结算数量」（实重等）
- 三个都一样 → 入库只填一个数量

界面灰字用上面这套白话提示（见 `src/utils/unitCaliber.js`）。

主数据相关字段：

| 字段                 | 说明                                         |
| -------------------- | -------------------------------------------- |
| `settleUnit`         | 结算单位；空或不填 = 不启用                  |
| `settleConvertType`  | 本版固定为浮动实填（`floating`）             |
| `standardUnitWeight` | 可选标准单重，仅开单估算，**不参与最终结算** |

校验：结算若填写，须与库存单位不同。

演示料：`WL-CAST-BLANK-PUMP-01` 泵体铸件毛坯（件 / kg）。

## 和「可变长 / 双单位」的关系

两件事互不替代，可以叠在一起：

```text
只双单位：买「根」，库存记「米」——钱仍可按库存量×单价
只结算：买「件」，库存也「件」，结账按「kg」——钱按结算数量×单价
两者都有：买「张」、库存「㎡」、结账「kg」——入库字段最多
```

厂内领料、出库：**只认库存单位**，不要求填结算数量。

---

## 单据上怎么走

```text
主数据（库存 / 采购 / 结算）
  → 采购订单（有结算单位时可估预计结算量；单价按结算单位理解）
  → 收货 / 入库（有结算单位则必填结算数量；库存仍按库存单位入账）
  → 采购结算（金额 = 结算数量 × 单价）

厂内出库 / 领料：只用库存单位，不碰结算单位
```

1. **主数据**：填库存 / 采购 / 结算；可选「标准单重」——只用于开单时估算，**最终结账以实填结算数量为准**。
2. **采购订单**：有结算单位时，预计结算量可按「件数 × 标准单重」估；单价按结算单位理解。
3. **入库 / 收货**：有结算单位则必填结算数量（如过磅实重）；库存数量仍按库存单位入账。
4. **采购结算**：有结算单位时，金额 = **结算数量 × 单价**（不是库存件数 × 单价）。
5. **出库 / 领料**：不碰结算单位。

计价规则集中在 `src/utils/settleUnit.js`：有结算单位 → 用 `settleQty`；否则用采购/库存数量。

---

## 入库界面原则

- **缺什么填什么**：该双单位才出「到货件数」；该结算才出「结算数量」。
- 不做「型材 / 板材 / 通用」三选一。
- 板材「长×宽」只是可选快捷（功能参数「面积录入快捷」，默认关），不是第三套单位逻辑；仅库存单位为㎡且开启时出现。
- 列表上数量与单位同列展示（如 `55.5 kg`），避免数量、单位拆两列。

## 本版明确不做

- 小程序采购双数量
- 「固定换算」结算（件永远 × 固定系数自动结账）
- 财务应付凭证对接
