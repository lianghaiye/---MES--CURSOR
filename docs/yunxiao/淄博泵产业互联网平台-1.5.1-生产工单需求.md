## WO-151-01 新增生产工单弹窗优化

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
原新增/编辑生产工单弹窗字段分散、组件 Tab 信息不足，与销售订单、产品/BOM、工艺路线联动不完整，不利于计划员快速建单与备料核对。

**功能描述**

1. **弹窗尺寸与顶部字段**：弹窗加宽（1280px）；顶部无区块标题，一行展示：工单编号、工单名称、**工单类型**（生产工单/外协工单）、销售订单（选择按钮）。
2. **销售订单摘要**：选择销售订单后，下方蓝色摘要行展示：`销售订单号 / 客户名称 / 业务员`。
3. **生产明细**  
   - 左侧：产品名称（必填，产品/物料选择器）、选择产品后在下方**蓝色信息框**展示规格型号、材质、图号、技术参数、配套要求（只读；空项显示「-」）。  
   - 右侧竖排：物料清单（关联 BOM 选择）、工艺路线（默认带出，可改）、计划数量、排产数量（初始=计划数量，可改）。  
   - 排产数量、工作中心、计划日期**必填**。
4. **生产安排**：一行 4 字段——工作中心 | 负责人 | 预入仓库 | 紧急度；下一行计划日期（宽度与工作中心一致）；再下一行**工单备注**（多行输入）。  
   - **负责人**：支持搜索选择与「搜索更多」弹窗；切换工作中心时自动带出默认负责人（可改）。
5. **Tab 页**  
   - **组件**：展示 BOM 物料清单（序号、产品名称、编码、规格型号、材质、图号、供应型态、单位、单位用量、库存数、需求数、备注）；需求数 = 单位用量 × 排产数量；清空产品或 BOM 时同步清空组件表。  
   - **作业**：占位「作业内容后续补充」。
6. **联动规则**：选产品后自动带出产品字段、关联 BOM、默认工艺路线、工作中心、预入仓库；修改计划数量时，若排产数量仍等于原计划数量则同步；切换 BOM 刷新组件明细。

**业务规则**

- 工单编号/名称留空则按系统规则自动生成。
- 组件 Tab 数据以所选 BOM 为准；未选 BOM 时不展示组件行。
- 保存工单时持久化 `bomId` 及生产明细/安排全部字段。

**验收标准**

- [ ] 弹窗布局、字段顺序、蓝色信息框与右侧竖排字段符合设计。
- [ ] 工单类型、销售订单摘要、负责人选择与工作中心联动正确。
- [ ] 排产数量/工作中心/计划日期必填校验生效。
- [ ] 组件 Tab 列完整，需求数随排产数量联动；清空产品/BOM 后组件表为空。
- [ ] 保存后列表与详情可读到新增字段。

## WO-151-02 工单详情与工单下发优化

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
工单详情、下发页基础信息字段与新增弹窗不一致；工序配置展示不完整；EBOM/当前 BOM 与保存时物料清单不一致；下发页需支持工序内容与关键字段编辑。

**功能描述**

1. **详情页头部**：工单编号/名称后展示**工单类型**标签（与状态标签并列）；右上角增加**打印**入口。
2. **工单基本信息**（详情 Tab + 下发页可编辑区）  
   - 展示新增弹窗「生产明细 + 生产安排」全部字段；字段名与值**同行平行**展示，一行 4 字段；只读项以文本展示，不使用输入组件或表格。  
   - **销售单号**字段名统一（原「销售订单号」）；详情只读展示销售单号；**下发页不展示**销售单号、客户名称、业务员。  
   - **下发页可编辑**：工艺路线、计划数量、排产数量、工作中心、预入仓库、紧急度、计划日期、工单备注。
3. **工单下发 · 工序列表**  
   - 在「选择执行人」列后增加**工序内容**（单行输入，可保存）。  
   - 保留执行人/投料等既有能力。
4. **工单详情 · 工序配置**  
   - 由卡片改为表格：序号 | 工序名称 | **工序内容** | **投料** | 执行者 | **完工日期** | **检验** | **备注**。
5. **EBOM / 当前 BOM**  
   - 未下发：EBOM Tab 展示保存时关联的产品 BOM。  
   - 下发后：自动生成当前工单 **EBOM 快照**，EBOM Tab 展示快照数据（与下单时组件 Tab 一致）。  
   - **当前 BOM**：若工单产品为 BOM 顶级物料，展示完整 BOM 树。
6. **下发联动**：下发并开始后同步移动端任务、报工确认等既有流程（不在本需求扩展范围）。

**业务规则**

- 基础信息区与 `WorkOrderProductionSections` 共用字段定义，避免详情/下发/新增三处不一致。
- EBOM 快照以下发时刻 BOM 组件明细为准，修复「EBOM 与下单物料清单不一致」问题。
- 工序扩展字段（工序内容、完工日期、检验、备注）在工艺路线带入时初始为空，下发/详情可展示与维护。

**验收标准**

- [ ] 详情头部工单类型标签、打印按钮可见。
- [ ] 详情/下发基础信息字段完整，布局为一行四列、标签值平行；下发页隐藏销售侧三字段。
- [ ] 下发页指定字段可编辑并保存；工序列表可填工序内容。
- [ ] 详情工序配置表含 8 列且数据正确展示。
- [ ] 未下发 EBOM=产品 BOM；下发后 EBOM=快照且与组件 Tab 一致；当前 BOM 顶级物料展示完整树。

**关联说明**

- 云效已有「WEB--生产工单--工单下发--优化工单下发的逻辑」（NYVC-1297）可合并至本需求或关闭重复项。

## WO-151-03 生产工单打印

- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
车间现场需要打印生产工单备料与工序信息；需统一打印模板、支持单张与批量打印，并与销售交付信息联动。

**功能描述**

1. **打印入口**  
   - 工单详情页头部「打印」按钮。  
   - 生产工单列表「新增工单」旁 **批量打印**（需先勾选工单；未勾选提示）。
2. **打印弹窗**（`WorkOrderPrintModal`）  
   - 纸张（A4/A3）、方向（纵/横）；**预览** / **直接打印** 两个操作卡片样式一致，**直接打印无默认高亮**。  
   - 支持单工单与多工单批量（弹窗提示已选条数）。
3. **预览页**（新标签，`production-work-order-preview`）  
   - 页眉：产品名称 + 工单类型（不展示编号/状态徽章）。  
   - **基本信息**（3 列网格）：销售单号、**交付日期**（取关联销售订单明细交付日期，按 lineId 或产品/编码匹配）、产品名称、规格型号、材质、图号、排产数量、工作中心、预入仓库、紧急度、计划日期、负责人、技术参数、配套要求、工单备注。  
   - **不打印**：工单编号/名称/类型/状态、客户/业务员、BOM、工艺路线、计划数量、任务状态、创建日期、物料清单/BOM 整段。  
   - **工序配置**表格：序号 | 工序名称 | 工序内容 | 投料 | 执行者 | 完工日期 | 检验 | 备注（工序内容、投料列宽加宽）。  
   - 批量打印时每张工单独立分页（`sheet-page-break`）。  
   - 页脚：打印时间、制单人/审核人签字栏。
4. **空值展示**：打印模板中空字段**留空**，不显示「-」。

**业务规则**

- 交付日期通过 `resolveWorkOrderDeliveryDate()` 从销售订单明细解析。
- 打印数据经 `buildWorkOrderPrintPayload` / `buildWorkOrderBatchPrintPayload` 构建，预览数据存 sessionStorage。
- 直接打印：打开预览页并 `autoPrint=1` 调起浏览器打印。

**验收标准**

- [ ] 详情打印、列表批量打印入口与校验（未勾选提示）正常。
- [ ] 弹窗预览/直接打印可用；直接打印无蓝色高亮。
- [ ] 预览字段与排除项符合要求；交付日期取自销售明细。
- [ ] 工序表列宽可读；批量多 sheet 分页正确。
- [ ] 空字段不显示「-」。
