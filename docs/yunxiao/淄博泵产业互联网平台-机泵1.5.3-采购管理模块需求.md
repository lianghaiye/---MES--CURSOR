## 一、已有模块 · 增量改造

### 1. 采购申请（增量）

**菜单：** 采购管理 / 采购申请  
**路径：** `/procurement/purchase-req`

#### 本期增量点

1. **生成采购订单改为新标签页**（不再用弹窗一次做完）
2. **行级采购状态**：`未生成采购` / `已生成采购`；支持移出后再次生成；可分多次生成
3. **草稿采购订单**：生成页可「保存草稿」；列表可继续编辑草稿 / 删除草稿
4. **库存预警列**：计划采购量后展示低于最低库存 / 高于最高库存
5. **库存数量列**：订货尺寸后展示
6. **供应商**：搜索、选择更多、弹窗内新增；无默认供应商时回写主数据
7. **打印**：采购申请明细打印预览字段收敛

#### 状态（抬头）

`待处理` → `处理中`（已绑草稿或部分生成 PO）→ `处理完成`；可 `已作废`

### 2. 采购订单（增量）

**菜单：** 采购管理 / 采购订单  
**路径：** `/procurement/purchase-orders`

#### 本期增量点

1. **列表周期统计**：订单数、已入库/采购总量、金额、逾期未到货
2. **工具栏 / 详情「采购退货」入口**（带单号跳转退货新建；列表行操作不展示）
3. **生成收货 / 生成入库**：进行中且有剩余可入量时可操作；入库弹窗按采购单位、不做换算、不填货位
4. **退货选单**：排除草稿等不可选状态
5. **审核页**：独立标签页审核（既有能力保持）

#### 状态

```
草稿 → 待提交 → 待审核 → 进行中 → 已完成
              ↘ 已拒绝（可编辑后重新提交）
待提交可作废
```

入库状态：`待入库` / `部分入库` / `已入库`  
完成条件：进行中且入库状态=已入库

## 二、新增模块 · 全量规格

### 4. 采购收货（新增）

**菜单：** 采购管理 / 采购收货  
**路径：** `/procurement/purchase-receipts`  
**创建方式：** 不从菜单「新增」，由**采购订单**「生成收货单」产生

#### 业务目标

对已审核通过的采购订单进行到货登记，作为质检与入库的前置单据（也可从订单直接入库，收货为可选环节）。

#### 列表

- **筛选：** 收货单号、采购单号、供应商、质检状态、入库状态、单据状态
- **列：** 单据状态、收货单号、采购单号、供应商、质检状态、入库状态、数量、创建/更新、操作
- **工具栏：** 生成质检单（可占位）、生成入库单、完成、批量打印
- **行操作（进行中）：** 质检（未质检/质检中）、入库（未完全入库且 PO 可入）

#### 详情

- Tabs：基本信息（收货明细）｜质检信息｜入库信息
- 操作：作废（仅新建且无下游单）、生成入库、完成、打印

#### 状态

```
单据：新建 → 进行中（已挂质检或入库） → 已完成
        ↘ 作废（仅新建）
质检：未质检 / 质检中 / 质检通过 / 部分通过 / 质检不通过 / 已终止
入库：待入库 / 入库中 / 部分入库 / 已入库
```

#### 关键规则

1. 强关联采购订单；收货数量不可超过订单剩余可入量
2. 生成入库后回写采购订单入库进度，并挂接收货单的入库单号
3. **生成入库：** 按采购单位入库，不换算库存单位，不填货位；去掉库存单位量/货位/当前库存等字段
4. **打印：** 单据状态跟单号后；质检结果；入库状态后展示入库单号；去掉副标题供应商与信息区重复单号

#### 验收

- [ ] 从采购订单可生成收货单并进入列表
- [ ] 进行中可按规则质检/入库
- [ ] 入库回写 PO 进度与收货入库单号
- [ ] 打印字段符合上述约定

### 5. 采购退货（新增）

**菜单：** 采购管理 / 采购退货  
**路径：** `/procurement/purchase-returns`  
**创建：** 菜单新增，或从采购订单详情/工具栏「采购退货」带单进入

#### 业务目标

对已采购到货的物料办理退供，生成退货单并进一步生成出库单完成实物退出。

#### 列表

- **筛选：** 状态、退货单号、采购单号、供应商、出货仓库、出库状态、创建日期、操作人
- **列：** 状态、出库状态、退货单号、采购单号、供应商、产品信息、退货数量、出货仓库、创建/更新、操作
- **工具栏：** 新增、生成出库单、打印
- **行操作：** 新建可编辑/作废

#### 创建/编辑

1. 选择采购订单（排除草稿等不可选状态）
2. 勾选明细行，填写退货数量（不超过可退量）
3. 指定出货仓库等头字段后保存 → 状态「新建」

#### 详情

- Tabs：基本信息（退货明细）｜出库信息
- 操作：编辑、作废、生成出库单、打印

#### 状态

```
单据：新建 → 进行中（已生成出库/出库中） → 已完成（出库状态=已出库）
        ↘ 作废（新建）
出库：待出库 / 出库中 / 部分出库 / 已出库
```

#### 关键规则

1. 无审批流
2. 生成出库单后回写出库进度；全部出库后单据完成
3. 打印退货明细

#### 验收

- [ ] 菜单新增与从 PO 带单新建均可用
- [ ] 选单过滤正确；数量校验正确
- [ ] 生成出库与状态流转正确
- [ ] 打印可用

### 6. 外协订单（新增）

**菜单：** 采购管理 / 外协订单  
**路径：** `/procurement/outsourcing-orders`

#### 业务目标

管理委外加工全流程：建单 → 审核 → 发料出库 → 回货收货/入库 → 异常处理 → 完成。结构对齐采购订单，但增加**发料**维度。

#### 列表

- **筛选：** 单据状态、外协单号、销售单号、供应商、发料状态、回货状态、逾期状态、创建日期、操作人
- **列：** 状态、外协单号、发料/回货/逾期状态、供应商、外协数量、销售单号、计划日期、加工总价、结算、创建/更新、操作
- **工具栏：** 新增、审核、生成发料出库单、生成收货单、生成入库单、异常处理、完成、批量打印（派单工/发料出库单）
- **行操作：** 按状态提交/撤回/重新提交/作废；进行中：发料/收货/入库
- **统计面板：** 外协订单数｜已回货/总量｜费用｜逾期未回货

#### 创建/编辑/审核

- 头：供应商、销售单、工单名称、计划日期、联系人电话、供货期、结算等
- 明细：产品、计划数量、价税、收货仓库等
- **审核：** 新标签页，意见通过→进行中 / 驳回→已拒绝

#### 详情 Tabs

基本信息（明细+审批记录）｜发料信息｜回货信息｜质检信息｜外协异常处理｜结算信息

Header：按状态展示编辑/提交/审核/发料/收货/入库/异常处理/完成

#### 状态

```
待提交 → 待审核 → 进行中 → 已完成
  ↘作废   ↘已拒绝（可编辑再提交）
发料：待出库 / 部分出库 / 已出库
回货：待入库 / 部分入库 / 已入库
```

完成条件：进行中且回货状态=已入库

#### 关键规则

1. 进行中可生成发料出库、收货单、入库单（有剩余可入量）
2. 详情/工具栏「异常处理」带单号跳转外协异常新建（列表行不展示该入口）
3. 打印：派单工、发料出库单

#### 验收

- [ ] 建单→提交→审核→进行中闭环
- [ ] 发料/收货/入库/完成规则正确
- [ ] 统计与异常处理入口正确
- [ ] 打印可用

### 7. 外协收货（新增）

**菜单：** 采购管理 / 外协收货  
**路径：** `/procurement/outsourcing-receipts`  
**创建：** 由外协订单「生成收货单」产生（无独立菜单新增）

#### 列表 / 详情 / 状态

#### 关键规则

2. 进行中：质检、入库（外协生成入库弹窗）
3. 打印口径与采购收货一致

#### 验收

- [ ] 从外协订单生成收货并列表可见
- [ ] 质检/入库/回写/打印符合规则

### 8. 外协异常处理（新增）

**菜单：** 采购管理 / 外协异常处理  
**路径：** `/procurement/outsourcing-returns`  
**创建：** 菜单新增，或从外协订单「异常处理」带单进入

#### 业务目标

外协加工异常（退回/补料等）单据；能力对标采购退货，但文案为「异常处理」，且**列表/打印不突出出库仓库筛选与出库状态列**（出库能力仍保留在详情出库信息中）。

#### 列表

- **筛选：** 状态、异常处理单号、外协单号、供应商、创建日期、操作人
- **列：** 状态、异常处理单号、外协单号、供应商、产品信息、处理数量、创建/更新、操作
- **工具栏：** 新增、生成出库单、打印

#### 创建/编辑

选择外协订单 + 明细行，填写处理数量 → 保存为新建

#### 详情

- Tabs：基本信息｜出库信息
- 操作：编辑、作废、生成出库、打印

#### 状态

同采购退货：`新建` → `进行中` → `已完成` / `作废`

#### 关键规则

1. 无审批流
2. 可生成出库单并回写出库进度
3. 打印异常处理明细（无出库状态/出库单号强调展示）

#### 验收

- [ ] 新建与带单新建可用
- [ ] 生成出库与完成正确
- [ ] 列表无出货仓库/出库状态筛选与列
- [ ] 打印可用
