# 基础配置 · 货位管理

| 项目        | 内容                           |
| ----------- | ------------------------------ |
| 迭代 / 版本 | 机泵1.6.1                      |
| 模块        | 基础配置 → 仓库管理 → 货位管理 |
| 端          | I-DOMS Web（`i-doms-web`）     |
| 类型        | 新增模块                       |

## 一、背景与目标

仓库仅有仓级档案时，入库/出库只能手输货位号，无法维护库区结构、容量与占用状态。  
目标：建立**货位主数据档案**，支持单条维护与批量生成，并与仓库详情、入库明细联动选位。

## 二、入口与菜单

- 菜单路径：**基础配置 → 仓库管理 → 货位管理**
- 路由：`/basic-config/warehouse-locations`
- 仓库详情页提供「货位管理」跳转，并可预览本仓库货位列表

## 三、列表页

### 3.1 筛选

| 条件     | 说明                                             |
| -------- | ------------------------------------------------ |
| 所属仓库 | 下拉，可清空                                     |
| 货位编码 | 模糊匹配                                         |
| 库区     | A区 / B区 / C区 / 发货区 / 不良区                |
| 货位类型 | 存储位 / 拣货位 / 收货暂存 / 发货暂存 / 不良品位 |
| 占用状态 | 空闲 / 部分占用 / 占用 / 锁定                    |

列表样式对齐项目 `list-*.mdc`（筛选区 + 工具栏 + 表体分区）。

### 3.2 工具栏

- **新增**：进入新增货位（单条）
- **批量生成**：独立弹窗，**保留在列表**（不并入新增页）
- 刷新、列设置

### 3.3 列表字段（主要）

货位编码、货位名称、所属仓库、库区、货位类型、通道/货架/层/位、占用状态、容量（最大件数/承重）、混放 SKU、混放批次、启用、操作（编辑 / 启用停用 / 删除）。

### 3.4 业务规则

- 编码在同一仓库内唯一
- **占用中**货位不可删除
- 停用货位不出现在入库货位下拉（启用筛选）

## 四、单条新增 / 编辑

表单字段（横排四列布局）：

| 字段                    | 必填 | 说明               |
| ----------------------- | ---- | ------------------ |
| 所属仓库                | 是   | 编辑时不可改       |
| 货位编码                | 是   | 如 `YL-A-01-01-01` |
| 货位名称                | 否   | 默认可与编码相同   |
| 库区                    | 否   |                    |
| 最大件数 / 最大承重(kg) | 否   | 空=不限制          |
| 货位类型                | 是   |                    |
| 占用状态                | 否   | 默认空闲           |
| 通道 / 货架 / 层 / 位   | 否   |                    |
| 启用                    | —    | 开关               |
| 允许混放 SKU / 批次     | —    | 开关               |
| 备注                    | 否   | ≤200 字            |

## 五、批量生成（列表入口）

独立弹窗「批量生成货位」：

1. 选择所属仓库；编码前缀可按仓库名自动建议（如原料仓→`YL`）
2. 选择库区、货位类型
3. 配置通道 / 货架 / 层 / 位的**起止范围**，笛卡尔积生成
4. 编码格式：`前缀-库区-通道-货架-层-位`（数值两位补零）
5. 已存在编码跳过；勾选混放 SKU / 批次默认值

**交互约定**：批量生成留在列表工具栏，**不**并入「新增货位」页内切换。

## 六、联动

1. **仓库详情**：展示本仓货位摘要，可一键进入货位管理（可带仓库筛选）
2. **入库明细**：有档案时货位号改为下拉选择（按行仓库过滤启用货位）；无档案时仍可手输

## 七、验收要点

- [ ] 菜单可进入货位管理列表，筛选与分页正常
- [ ] 单条新增/编辑校验：仓库必选、编码必填且同仓唯一
- [ ] 列表「批量生成」可按范围生成，重复编码跳过并提示成功条数
- [ ] 占用中不可删；停用后入库下拉不可见
- [ ] 仓库详情可跳转并看到本仓货位
- [ ] 入库明细在有档案时可下拉选货位
- [ ] 列表结构符合 list 页规范；批量入口仍在列表（非新增页内切换）

## 八、非目标

- 不改造出库拣货算法 / 库位推荐策略
- 不做货位库存实时台账（本需求主数据 + 入库选位）
- 不改移动端货位录入
