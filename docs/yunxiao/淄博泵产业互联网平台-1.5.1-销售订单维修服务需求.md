## SO-151-01 添加产品业务类型扩展与维修服务自动生成维修工单

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
销售订单「添加产品」明细原仅支持自产/外购销售；售后维修、定制选品等场景需在选品行直接选择对应业务类型。维修服务审核通过后需自动创建维修类生产工单，与自产计划、外协工单分流。

**功能描述**

### 1. 添加产品 — 业务类型扩展

选品明细（添加产品）业务类型由 `自产销售 / 外购销售` 扩展为：

- 自产销售
- 外购销售
- **维修服务**
- **定制销售**（与手填明细定制销售一致）

切换为 **维修服务** 时清空 BOM 字段；切换为 **定制销售** 时清空 BOM 并设产品属性为定制产品。

### 2. 审核通过 — 维修服务自动生成维修工单

- 业务类型为 **维修服务** 的明细 **不进入** 自产生产计划分支。
- 审核通过后，每条维修服务明细自动生成 1 条生产工单：
  - 工单类别：**维修工单**（新增，与「返修工单」并存）
  - 关联销售订单号、明细行 ID（幂等防重复）
  - 带入产品名称/编码、规格、材质、图号、数量、交货日期等
  - 不绑 BOM（`skipEbom: true`）

### 3. 定制销售（选品行）

- 选品行可选 **定制销售**，审核走现有定制逻辑：生成设计任务 + 生产计划，不校验 BOM。

### 4. 维修工单类别注册

- 生产工单列表筛选增加 **维修工单**
- 维修工单详情不展示 EBOM / 当前 BOM / BOM 版本 Tab

**业务规则**

- 维修服务独立于自产/外购/外协分流。
- 维修工单与外协工单类似，不强制 BOM。

**验收标准**

- [ ] 添加产品明细可选：自产销售、外购销售、维修服务、定制销售。
- [ ] 维修服务明细审核不因无 BOM 拦截。
- [ ] 审核通过后生产工单列表出现 `orderCategory = 维修工单` 且关联销售订单。
- [ ] 重复审核不产生重复维修工单。
- [ ] 选品行定制销售审核仍生成设计任务与生产计划。
