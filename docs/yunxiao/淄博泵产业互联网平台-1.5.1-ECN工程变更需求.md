## 整体流程说明

ECN（工程变更通知单）状态流转：

```
草稿 ──提交审批──► 审批中 ──逐级审批──► 已通过 ──执行──► 已执行
                      │                    │
                      └──驳回──► 已驳回      └──（执行中，瞬时态）
```

- **三级审批**：工艺主管 → 生产主管 → 质量主管（顺序审批，任一级驳回则整单驳回）
- **执行**：已通过单据确认执行后，自动升级产品 BOM 版本并归档旧版
- **ECR** 与 ECN 共用页面组件，但 ECN 执行时会触发 BOM 升版，ECR 不会

## ECN-151-01 ECN 列表与详情

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
工程变更需统一入口管理 ECN 单据，支持按单号/状态/产品等条件检索，并按单据状态提供对应操作（编辑、审批、执行、详情等）。

**功能描述**

1. **列表页**（`/engineering-change/ecn-list`）  
   - 筛选：单据编号（ECN/销售单/工单）、单据状态、变更类型、产品名称、客户名称、创建时间范围。  
   - 工具栏：新增 ECN 变更、刷新、列设置。  
   - 表格列（可配置）：序号、状态、 ECN 单号、变更类型、变更原因、关联单据、产品名称、销售单号、客户名称、工单编号、执行配置、申请人、紧急度、创建时间、审核人、审核时间、操作。  
   - 分页：10/20/50 条。  
   - 点击 ECN 单号：在系统 Tab 中打开详情页。

2. **状态与行操作**

   | 状态 | 操作 |
   |------|------|
   | 草稿 | 编辑、删除、提交审批 |
   | 审批中 | 审批 |
   | 已通过 | 执行 |
   | 已执行 | 详情 |
   | 已驳回 | 编辑、重新提交 |

3. **详情页**（`/engineering-change/ecn/:id/detail`）  
   - 展示基本信息、变更技术内容（只读对比表）。  
   - **草稿/审批中**：不展示 BOM 版本时间线与审批记录。  
   - **已通过及以后**：展示 BOM 版本变更时间线（查看 BOM、对比占位）、审批记录。  
   - 支持打印入口、返回列表。

**业务规则**

- 仅 **草稿** 可删除。  
- 筛选状态下拉不含「执行中」「已撤销」。  
- 执行配置列展示文案：仅升级 BOM 档案 / 在制工单切换新版。  
- 状态颜色：已通过=blue，已执行=green。

**验收标准**

- [ ] 筛选、分页、列设置正常。  
- [ ] 各状态行操作与上表一致。  
- [ ] 单号点击打开 Tab 详情；详情区段按状态显隐正确。  
- [ ] BOM 版本时间线在已执行单据上可查看关联 BOM。

## ECN-151-02 ECN 新增与变更内容编辑

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
工程师需基于销售订单或工单关联产品 BOM，录入变更项并提交审批；需支持草稿保存与完整校验。

**功能描述**

1. **基本信息**  
   - 变更类型：固定 BOM 变更（不可改）。  
   - 变更原因、紧急程度（普通/紧急/特急）。

2. **关联单据**（单选）  
   - 根据销售订单：选销售单 → 选关联产品行 → 自动带出 EBOM/BOM 树。  
   - 根据工单：选工单 → 自动带出产品与 EBOM。  
   - 根据 ECR / 根据产品：UI 禁用（预留）。

3. **变更技术内容**  
   - 从 BOM 多选添加变更行，或手动新增空行。  
   - 变更操作类型：修改、替换、取消、新增。  
   - 每行字段：变更前/后物料（编码、名称、规格、材质、图号、单位用量、工艺文件）、父级物料、关联工序、变更说明等。  
   - 支持行内编辑与弹窗编辑（`EcnChangeItemEditModal`）。

4. **变更说明、影响分析（展示）、附件、执行配置**  
   - 影响分析为展示卡片（影响产品、BOM 行、在制工单、库存预警，当前为 mock）。  
   - 附件：拖拽上传，≤50MB，前端元数据（未实际上传）。  
   - **BOM 执行方式**（二选一，默认「仅升级 BOM 档案」）：  
     - 仅升级 BOM 档案：已下发计划/工单保持原绑定版本。  
     - 在制工单切换新版：在制工单将在下一工序切换新版。

5. **提交**  
   - **存草稿**：状态=草稿，生成 ECN 单号（`ECN-YYYY{seq}`），返回列表。  
   - **提交 ECN 审批**：校验通过后状态=审批中，初始化三级审批流，返回列表。

**业务规则**

- 销售订单/工单来源时，关联产品与 BOM 必填。  
- 至少 1 条变更项；ADD 需新物料与父级；MODIFY/REPLACE 需变更后单位用量等。  
- 勾选「关联生成单据」时，计划数量与计划日期必填。  
- 默认申请人 mock 为「张工」。

**验收标准**

- [ ] 销售订单/工单两种来源均可选产品并加载 BOM 树。  
- [ ] 四种变更类型编辑、校验、保存草稿/提交审批正常。  
- [ ] 执行配置默认「仅升级 BOM 档案」且可切换。  
- [ ] 提交后列表状态为审批中，单号已生成。

**已知缺口**

- 列表「编辑/重新提交」跳转带 `?edit=` / `?from=` 参数，Create 页尚未实现回填（待后续迭代）。

## ECN-151-03 ECN 审批

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
ECN 提交后需经工艺、生产、质量三级主管顺序审批，审批人需查看变更技术内容与执行配置后再决策。

**功能描述**

1. **审批页**（`/engineering-change/ecn/:id/approve`）  
   - 头部：ECN 单号、变更类型、产品、状态。  
   - 摘要：变更原因、申请人、创建时间。  
   - **变更技术内容**：只读对比表，变更高亮（变更前红、变更后绿）。  
   - **执行配置**：只读展示所选 BOM 执行方式。  
   - **审批意见**（仅审批中状态）：文本框 + 驳回 / 通过。  
   - **审批记录**：历史列表（层级、审批人、结果、时间、意见）。

2. **审批逻辑**  
   - 三级顺序：工艺主管（王工艺）→ 生产主管（李生产）→ 质量主管（赵质量）。  
   - **通过**：非最后一级停留本页；最后一级通过后状态=已通过，返回列表。  
   - **驳回**：意见必填，状态=已驳回，返回列表。  
   - 每步写入 `approvalRecords` 并更新审核人/审核时间。

**业务规则**

- 仅 **审批中** 单据可进入审批页操作。  
- 驳回后可在列表「编辑 + 重新提交」再次进入审批流（重新提交逻辑待 Create 回填完善）。

**验收标准**

- [ ] 审批中单据可填意见并通过/驳回。  
- [ ] 三级顺序正确，末级通过后状态为已通过。  
- [ ] 驳回必须填写意见；审批记录完整展示。  
- [ ] 变更内容与执行配置只读展示正确。

## ECN-151-04 ECN 执行与 BOM 升版

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
审批通过的 ECN 需由执行人确认变更生效，并自动将产品 BOM 归档旧版、发布新版本，供销售/计划/工单等页面展示最新 BOM 版本信息。

**功能描述**

1. **执行页**（`/engineering-change/ecn/:id/execute`）  
   - 只读展示变更技术内容、执行配置及在制工单提示（mock 数量）。  
   - **确认执行**按钮（已通过状态可见；执行中/已执行隐藏）。

2. **执行过程**  
   - `startExecution`：已通过 → 执行中。  
   - `completeEcnExecution`：执行中 → 已执行，记录 `executedAt`、`executor`。  
   - 调用 `executeEcnBomVersionUpgrade`：  
     - 克隆源 BOM，按变更项应用 ADD/MODIFY/REPLACE/REMOVE。  
     - 保存并启用新版 BOM；旧版归档。  
     - 回写 `bomId`、`bomVersion`、`versionGroupId`、`previousBomVersion`、`bomVersionHistory`。

3. **版本联动**（执行后）  
   - 详情页展示 BOM 版本变更时间线。  
   - 销售订单详情、生产计划、生产/总装工单详情通过 `BomVersionInfoSection` 展示 BOM 版本及「有新版」标识。

**业务规则**

- 仅 **已通过** 可执行。  
- 无变更项时执行应提示失败。  
- 当前 `wipHandling`（在制工单切换新版）为 **展示配置**，执行逻辑统一做 BOM 升版，WIP 切换规则待后端/后续迭代实现。

**验收标准**

- [ ] 已通过单据可确认执行，状态变为已执行。  
- [ ] 产品 BOM 产生新版本，旧版归档；详情时间线正确。  
- [ ] 销售订单/计划/工单页可看到 BOM 版本信息。  
- [ ] 执行配置只读展示与创建时一致。

## ECN-151-05 ECN 打印

- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
现场与归档需要纸质版工程变更通知单，需与生产工单打印交互一致，并适配黑白打印机与 Safari 浏览器。

**功能描述**

1. **打印入口**  
   - ECN 详情页「打印」按钮。

2. **打印弹窗**（`EcnPrintModal`，与生产工单一致）  
   - 纸张：A4 / A3；方向：纵向 / 横向。  
   - **预览** / **直接打印** 两个操作卡片。

3. **预览页**（`/engineering-change/ecn/print`，独立窗口）  
   - 工程变更通知单正式版式，包含：  
     - 单号、状态、基本信息 3×3 网格  
     - 变更说明  
     - 变更内容明细（逐字段对比：产品编码/名称、物料编码/名称/规格/材质/图号/单位用量/工艺文件；变更加粗）  
     - 影响分析（BOM 版本、执行配置）  
     - 审批记录、签字区、打印时间  
   - 黑白紧凑样式，无彩色填充，适配非彩印。  
   - iframe 隔离打印，避免 Safari 切换打印机后预览空白。

4. **数据传递**  
   - `buildEcnPrintPayload` 构建数据 → sessionStorage → 预览页读取。  
   - 直接打印带 `autoPrint=1` 自动调起浏览器打印。

**业务规则**

- 打印数据以单据实际字段为准，一个 ECN 对应一个受影响产品。  
- 签字区仅保留签字线，不预填人名。

**验收标准**

- [ ] 打印弹窗交互与生产工单一致。  
- [ ] 预览内容完整、字段对比清晰、黑白可读。  
- [ ] Safari 切换打印机后预览/打印内容不空白。  
- [ ] 直接打印与预览打印均可用。
