## IOD-151-01 出入库明细列表与单据状态优化

- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
库存管理下需独立「出入库详情」二级菜单，以明细维度查看入出库流水；原 mock「单据状态」与真实出入库单状态不一致，需汇总展示关联单据状态并去重。

**功能描述**

### 1. 菜单与页面

- 路径：`/inventory/in-out-detail`（库存管理 → **出入库详情**）
- 列表展示入出库明细行（物品维度）

### 2. 搜索条件

业务类型、单据类型、物品名称、条码编号/批次号、出入库单号、物品类型、**单据状态**、**出入库状态**（待入库 / 部分入库 / 全部入库）

### 3. 列表字段

含：出入库单号、业务类型、单据类型、**单据状态**、**出入库状态**、物品类型、物品名称、规格属性、数量、变动后库存数、单位、条码/批次、生产日期、过账日期、过期日期、操作人、备注、操作列等；支持**列显隐**。

### 4. 单据状态（汇总去重）

- **不再使用** mock 独立状态（草稿/待审核/已审核/已过账）
- 按行 `headerId` + 业务类型，从**入库单/出库单 store** 读取头表真实 `status`
- 同一出入库单的多行明细展示**相同状态**（按单去重）
- 筛选下拉选项 = 入库状态 ∪ 出库状态 **去重合并**：
  - 待审批、待处理、待出库、待申领人确认、已完成、已出库、已拒绝、拒绝领料
- 状态标签颜色与入出库模块一致

### 5. 操作与跳转

- **点击出入库单号**：跳转对应入库/出库单详情页（新 Tab）
- **入库单**且出入库状态为「待入库」「部分入库」：操作列 **编辑**（打开入库单编辑弹窗）
- **入库单**且「全部入库」：操作列 **详情**
- **出库单**操作列：暂留空（后续补充）

### 6. 详情弹窗（行级）

- 展示行完整信息；单据状态同样解析关联单头状态
- 出库单底部提示详情能力后续补充

**业务规则**

- `resolveInOutDocStatus`：优先查关联单，无关联时回退行内 `docStatus`
- 列表数据 `enrichInOutDetailRow` 统一 enrichment 后再筛选

**验收标准**

- [ ] 菜单与路由可进入出入库详情页
- [ ] 搜索含单据状态、出入库状态且筛选生效
- [ ] 单据状态列展示真实入出库单状态，同单多行一致
- [ ] 单据状态下拉为入出库状态去重合集
- [ ] 点击单号跳转详情；入库待入库/部分入库可编辑，全部入库为详情
- [ ] 列显隐可用

**涉及文件（主要）**

- `InOutDetailView.vue`、`InOutDetailModal.vue`
- `inOutDetailHelpers.js`、`inOutDetailOptions.js`
- `mock/inOutDetails.js`
