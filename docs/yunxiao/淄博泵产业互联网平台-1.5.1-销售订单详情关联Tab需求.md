## SO-151-01 关联业务单据列表字段优化（不含 EBOM）

- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：邓利佳
- **需求规划节点**：期初
- **状态**：已实现

**背景**  
销售订单详情页需集中展示与该订单关联的发货、出库、采购、生产、外协等业务单据。原各 Tab 列表字段较少或与对应业务模块列表不一致，用户需在详情页与业务模块间反复切换核对，信息不完整、口径不统一。

**目标**  
统一销售订单详情关联 Tab 的列表字段与交互，与发货管理、出库管理、采购管理、生产计划/工单、外协等业务模块列表 **字段口径对齐**，支持状态标签、数量格式化、关键单号跳转等。

### 六、通用交互与样式

1. 各 Tab 内表格：`size="small"`、`bordered`、支持 **横向滚动**（scroll.x）。
2. 状态类字段统一使用 **a-tag** 颜色语义（与对应业务模块一致）。
3. 数量类字段统一格式化（整数/小数位数与源模块一致）。
4. 移除原「查看 xxx 管理」类操作列，改为单号链接直达详情（采购申请、发货单、出库单等）。
5. Tab 标题括号内仍展示关联单据 **数量统计**。

---

**业务规则**

- 关联数据通过 `resolveSalesOrderRelations` 按销售订单号汇总各 store / mock 数据。
- 发货申请需通过发货单号反查发货单 store  enrichment 指标。
- 不在本需求范围内：EBOM 信息 Tab、概览 Tab 明细表结构变更、附件 Tab。

**验收标准**

- [ ] 发货申请 Tab 字段与上表一致，发货单号可跳转，状态/数量/金额正确
- [ ] 出库单 Tab 字段与上表一致，出库单号可跳转
- [ ] 采购 Tab 采购申请、采购订单两套列表字段与上表一致，申请单号可跳转
- [ ] 生产 Tab 计划/生产工单/总装工单字段与上表一致；生产工单含创建日期，总装不含
- [ ] 外协 Tab 字段与上表一致，状态与入库状态标签正确
- [ ] 各 Tab 表格可横向滚动，空态文案正确
- [ ] EBOM 信息 Tab 不受本需求改动影响
