## 一、背景与目标

1. 将销售侧回款/客户往来、采购侧对账/供应商往来、结算规则等能力，从分散菜单位置归集到统一一级菜单 **往来结算**，降低财务/供应链对账入口成本。
2. 打通：采购入库入账 → 账期对账 → 收票付款 → 供应商往来台账；以及销售回款/开票 → 客户往来台账。
3. 提供票款流水统一查询，支持争议挂账登记与核销。

## 三、结算规则（STL-163-02）

**标题**：采购结算规则（工厂默认与供应商覆盖）· NYVC-2693

**功能要点**

1. 维护工厂级默认结算规则：账期、生成维度（按入库 / 按采购单已完成）、是否允许追加未结算量等。
2. 支持按供应商覆盖默认规则。
3. 规则变更留痕（日志抽屉）。
4. 生成对账单时按「供应商覆盖 → 工厂默认」解析生效规则。

**验收**

- [ ] 可新增/编辑/停用规则；供应商覆盖优先于工厂默认
- [ ] 按规则账期与生成维度扫单结果符合预期

## 四、采购对账

### 4.1 列表 · 账期生成 · 占量 · 退货红冲（STL-163-03）· NYVC-2694

1. 按账期窗、供应商筛选生成对账单；支持「追加未结算量」。
2. **生成维度**
   - 按入库：入库业务日落入账期窗的可结入库行
   - 按采购单（已完成）：仅已完成采购单，明细仍来自可结入库 + 可红冲退货
3. **占量**：草稿对账单即占用可结量，防重复出单。
4. **退货**
   - 未入库退货：不进对账单
   - 已入库退货且出库完成：对账明细数量为负（红冲），来源=退货

细则与场景矩阵见：`docs/ai-agent-kb/reference/05-采购对账退货红冲规则.md`。

### 4.2 详情 · 确认/反确认 · 费用补差（STL-163-04）· NYVC-2695

1. 详情展示对账头、明细（来源：入库/采购/退货）、金额汇总。
2. **确认对账**：回写入库行/退货行已结量。
3. **反确认**：未开票、未付款前提下可反确认释放占量。
4. **费用补差**：支持运费/尾差/调价等补差行，计入对账金额。
5. **行级争议挂起**：差额 / 整笔；不阻断确认与付款；同步争议挂账。

### 4.3 收票 · 付款 · 账龄分配（STL-163-05）· NYVC-2696

1. 对账单确认后可登记收票、付款。
2. 付款支持按账龄/明细分配到对账行。
3. 状态联动：未收票/部分收票/已收票，未付款/部分付款/已付款等。

### 4.4 打印与导出（STL-163-06）· NYVC-2697

1. 对账单打印预览（可给供应商）。
2. 列表/详情导出字段与界面口径一致。

### 4.5 采购订单入账状态联动（STL-163-09）· NYVC-2700

1. 采购订单侧展示入账/对账相关状态。
2. 对账确认、付款进展回写或可穿透查询到采购单。

**采购对账验收摘要**

- [ ] A1–A3、B1–B4 退货红冲场景通过（见规则文档 §3）
- [ ] 草稿占量后同账期追加不重复已占量
- [ ] 确认/反确认/补差/收票付款路径可用
- [ ] 打印导出可用

## 五、供应商往来（STL-163-07）· NYVC-2698

路径：`/settlement/supplier-ledger`

1. 按供应商汇总应付、已付、余额、账龄等。
2. 可下钻到对账单、付款、收票、争议挂账。
3. 与采购对账、票款流水数据同源。

**验收**

- [ ] 台账金额与对账确认/付款登记勾稽
- [ ] 可跳转关联单据

## 六、客户往来（STL-163-08）· NYVC-2699

路径：`/settlement/customer-ledger`

1. 按客户汇总应收、已回款、开票、余额等。
2. 关联销售订单、回款单、开票登记。
3. 与回款管理、票款流水数据同源。

**验收**

- [ ] 回款/开票后台账更新正确
- [ ] 可穿透到订单与回款明细

## 七、回款管理

路径：`/settlement/payments`（实现页可复用销售侧组件）

1. 回款登记、关联销售订单/发货分配。
2. 开票登记与回款节点维护（可与合同付款节点预设联动）。
3. 统计面板：待回款、逾期等。

> 合同付款节点预设设计见：`docs/superpowers/specs/2026-10-23-contract-payment-term-preset-design.md`。

---

## 八、争议挂账

路径：`/settlement/dispute-accruals`

1. 来源：采购对账行级差额/整笔争议登记。
2. 列表查询、核销（采纳我方/对方/折中）。
3. 挂出金额规则：差额 = |主张 − 账面|；整笔 = |行金额|。

**验收**

- [ ] 挂起不阻断对账确认与付款
- [ ] 核销后金额回写符合规则文档 §5

---

## 九、票款流水（STL-163-11）· NYVC-2710

路径：`/settlement/ticket-fund-flow`

1. 统一查询：回款、开票、付款、收票四类流水。
2. 筛选：往来对象、日期、单据号、金额区间等。
3. 行可跳转来源业务单。

**验收**

- [ ] 四类流水可筛可选中跳转
- [ ] 与回款管理、采购对账登记一致
