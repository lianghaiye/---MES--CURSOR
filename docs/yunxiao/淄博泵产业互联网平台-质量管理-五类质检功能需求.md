## 〇、跨模块共性（平台能力，可建父需求）

**建议云效标题**：`WEB--质量管理--QC-000 质检任务共性能力（状态/模板/录入/打印）`

- **优先级**：P0
- **状态**：已实现（共性能力）

### 背景

质量管理需覆盖采购来料、外协回货、生产过程、成品、发货出厂等不同场景；检验项与判定规则需可配置，避免各业务各写一套录入表单。

### 功能描述

#### 1. 质检状态与结果

| 维度     | 枚举                                                   |
| -------- | ------------------------------------------------------ |
| 质检状态 | 待质检 / 已完成 / 已终止（历史「检验中」归一为待质检） |
| 质检结果 | 质检通过 / 部分通过 / 质检不通过                       |

- 待质检可「质检」「终止」
- 已完成不可再录；已终止不可质检

#### 2. 质检模板

- 菜单：质量管理 → **质检模板**、**检验项库**
- 模板按 **业务类型（bizScope）** 区分：来料质检 / 外协回货检 / 生产过程检 / 成品检 / 出厂质检
- 匹配优先级：指定编码 > 单产品 > 产品类别 > 全局自定义 > 系统通用 > 内置兜底
- 建单时将模板字段 **冻结到质检明细行**；一行一模板，允许多模板（单头摘要「多模板」）

#### 3. 模板录入页（共用）

- 路由形态：`/quality/{biz}/:id/inspect`
- 组件：`QcTaskInspectView`
- 能力：按模板分区展示检验项、整单结论、整单合格规则校验、确认提交后回写结果与质检人/时间

#### 4. 打印

- 列表支持勾选/行内「打印质检单」
- 预览按模板展开各产品行检验项（标准 / 实测 / 判定）
- 标题随业务类型变化（来料质检单 / 外协回货质检单 / 生产过程质检单 / 成品质检单 / 出厂质检单）

#### 5. 与上游门控（说明）

- **功能参数 → 质检门控**：按五类业务类型配置「弱管控 / 强管控」；**当期仅开放弱管控**（强管控选项置灰，后续开放）
- 弱管控：未检/不合格等场景 Toast 预警，**不拦截**下游按钮；强管控：阻断入库/报工/出库（待开放）
- 出厂：销售出库确认出库已读功能参数门控（见 QC-05）；未发起出厂质检仍可直接出库
- 通用门控服务、过程报工门控、工单下发预生成过程/成品检等：**评估逻辑已有，业务入口未全量挂接**

### 验收标准（共性）

- [ ] 五类业务均可配置启用态质检模板
- [ ] 待质检单据可进入模板录入页并提交得出质检结果
- [ ] 打印预览能带出模板检验项（有录入数据时）

## QC-01 来料质检

> 云效标题建议：**WEB--质量管理--QC-01 来料质检（收货生成→模板录入→采购入库）**

- **优先级**：P0
- **状态**：已实现
- **菜单路径**：质量管理 → 来料质检（`/quality/incoming-qc`）

### 背景

采购收货后需按质检模板检验，合格/部分合格后方可生成采购入库；不合格需支持处置（退货/换货/让步接收）。

### 功能描述

#### 1. 任务来源

- 从 **采购收货** 生成质检单（列表/收货侧「生成质检单」）
- 一收货单对应一质检单；明细行按物料匹配「来料质检」模板
- 质检列表 **不支持手工新增**（点新增提示从采购收货生成）

#### 2. 列表

- **筛选**：质检单号、质检状态、质检结果、供应商、采购收货单号
- **主要列**：质检单号、状态、结果、入库状态、供应商、来源单号、入库单号、质检人、质检时间等
- **工具栏**：生成入库单、打印质检单、终止
- **行操作**：质检、入库、打印

#### 3. 质检录入

- 跳转模板录入页
- 支持整单结论；不合格/部分场景支持 **处理方案**（退货 / 换货 / 让步接收）
- 支持数量处置：合格入库数量、退货数量、换货数量（合计约束与质检数量相关）

#### 4. 详情

- 基本信息 + 明细（模板、收货/检验数量、处理方案、合格入库/退换货数量）
- 可质检、打印、生成入库单

#### 5. 下游闭环

- 已完成且非「质检不通过」→ 可生成 **采购入库单**（部分通过按合格入库数量控制）
- 待质检可终止

### 业务规则

- 模板业务类型必须为「来料质检」（或通用系统模板兜底）
- 生成入库受质检结果与处置数量约束

### 验收标准

- [ ] 采购收货可生成来料质检单且行上已绑模板
- [ ] 列表筛选/终止/打印可用
- [ ] 模板录入可提交并回写状态与结果
- [ ] 通过/部分通过可生成采购入库；不通过不可违规入库
- [ ] 处理方案与数量处置规则生效

### 主要涉及

- `QcTaskListView.vue`、`QcTaskInspectView.vue`、`QcTaskDetailView.vue`
- `qcTaskStore.js`、`GenerateIncomingQcModal.vue`、采购收货相关入口

## QC-02 外协回货检

> 云效标题建议：**WEB--质量管理--QC-02 外协回货检（回货收货生成→模板录入→外协入库）**

- **优先级**：P0
- **状态**：已实现
- **菜单路径**：质量管理 → 外协回货检（`/quality/outsourcing-qc`）

### 背景

外协回货收货后需质检，再生成外协入库；处置规则与来料类似，并支持「返工」。

### 功能描述

#### 1. 任务来源

- 从 **外协收货** 生成质检单（`bizScope=外协回货检`）
- 列表不支持手工新增

#### 2. 列表

- 筛选同来料结构，来源单号文案为 **外协收货单号**
- **工具栏**：生成外协入库单（单选约束）、打印、终止
- **行操作**：质检、打印（无行内「入库」按钮，入库走工具栏/详情）

#### 3. 质检录入

- 同模板录入页
- 处理方案：退货 / 换货 / 让步接收 / **返工**
- 支持数量处置（同来料逻辑）

#### 4. 详情 / 打印 / 闭环

- 详情可生成外协入库单
- 打印标题：外协回货质检单
- 已完成且门控通过 → 外协入库；待质检可终止

### 验收标准

- [ ] 外协收货可生成回货检质检单
- [ ] 录入含「返工」处置选项
- [ ] 可打印；可生成外协入库单
- [ ] 终止仅对待质检生效

### 主要涉及

- 同 QcTask 三件套；`createOutsourcingQcFromReceipt`；外协收货 / `OutsourcingGenerateInboundModal`

## QC-03 生产过程检

> 云效标题建议：**WEB--质量管理--QC-03 生产过程检（列表/模板录入/打印）**

- **优先级**：P1
- **状态**：已实现（列表与录入）；**工单下发自动生成、报工门控未全量挂接**
- **菜单路径**：质量管理 → 生产过程检（`/quality/process-qc`）

### 背景

生产过程按工序/物料检验，沉淀过程质量数据；与报工、工序质检配置联动为后续增强点。

### 功能描述

#### 1. 任务来源（现状）

- 列表 **不开放手工新增**
- 演示/种子数据可查看与录入
- 工单下发预生成（`ensureProcessQcTasksOnDispatch`）及工序 `qcConfigs`：**能力已实现，业务入口未挂接**（建云效时可拆「待开发/待联调」子项）

#### 2. 列表

- **筛选**：质检单号、状态、结果、物料编码、工单号
- **主要列**：质检单号、状态、结果、工单号、**工序**、物料、检验方式/数量、排产批次、质检模板、质检人、质检时间、创建人等
- **工具栏**：打印、终止（无入库）
- **行操作**：质检、打印

#### 3. 质检录入

- 模板录入页；**无**来料式退换货/合格入库数量处置区
- 结论与检验项按「生产过程检」模板

#### 4. 详情 / 打印 / 闭环

- 详情可质检、打印；无「生成入库」
- 打印标题：生产过程质检单
- 待质检可终止
- 报工质检门控：服务已写，**未挂接报工提交**

### 验收标准（按现状）

- [ ] 列表筛选、列、打印、终止可用
- [ ] 待质检可进入模板录入并完成
- [ ] （可选子需求）工单下发自动生成过程检、报工门控生效

### 主要涉及

- `QcTaskListView.vue`（process 列）、`qcTaskStore.js`、`qcTriggerService.js`、`qcProcessConfig.js`

## QC-04 成品检

> 云效标题建议：**WEB--质量管理--QC-04 成品检（模板录入→生成成品入库单）**

- **优先级**：P0
- **状态**：已实现（列表/录入/成品入库）；**工单自动生成未全量挂接**
- **菜单路径**：质量管理 → 成品检（`/quality/finished-qc`）

### 背景

成品检验合格后可生成成品入库单，形成「检 → 入」闭环。

### 功能描述

#### 1. 任务来源（现状）

- 同过程检：列表不开放新增；自动生成能力待挂接；以种子/既有任务为主可操作

#### 2. 列表

- 列/筛选与过程检同属「生产型」列结构
- **工具栏**：生成成品入库单、打印、终止
- **行操作**：质检、打印

#### 3. 质检录入

- 模板录入页；无来料处置三字段
- 生成入库时数量取合格入库数量或回落检验数量

#### 4. 下游闭环

- 已完成、非「质检不通过」、尚未关联入库 → **生成成品入库单**（`createInboundFromFinishedQc`）
- 详情页不提供生成入库（入口在列表工具栏）
- 待质检可终止；打印标题：成品质检单

### 验收标准

- [ ] 成品检可模板录入并完成
- [ ] 合格/部分通过可生成成品入库单；不通过不可生成
- [ ] 已关联入库的不可重复生成
- [ ] 打印、终止可用

### 主要涉及

- QcTask 三件套；`inboundOrderStore.js`（成品入库）

## QC-05 出厂质检

> 云效标题建议：**WEB--质量管理--QC-05 出厂质检（销售出库发起→模板录入→出库门控/复检）**

- **优先级**：P0
- **状态**：已实现
- **菜单路径**：质量管理 → 出厂质检（`/quality/factory-qc`）  
  （旧路径 `/quality/inspection` 重定向至本列表）

### 背景

销售发货前可对出库明细做出发检；与销售出库确认联动，不合格可复检后放行。

### 功能描述

#### 1. 任务来源

1. **销售出库**（类型=销售出库、状态=待出库）列表/详情：**发起出厂质检**
2. 质检结果为不通过/部分通过时：**重新发起出厂质检**（仅带入不合格明细）
3. 出厂质检列表 **新增**（按销售单选择，同销售单不可重复「待质检」）

#### 2. 列表（独立页 `FactoryQcView`）

- **筛选**：质检状态、质检结果、销售单号、客户名称
- **主要列**：质检单号、状态、结果、**源单号（出库单号）**、客户名称、销售单号、发货数量、来源、质检模板、质检人、质检时间、创建人、创建时间
- **工具栏**：新增、打印质检单、终止
- **行操作**：质检、打印
- 支持列设置

#### 3. 质检录入

- 与前四类共用 `QcTaskInspectView`（`bizScope=出厂质检`）
- 建单/打开录入时匹配并绑定「出厂质检」模板；无模板则提示先配置
- 检验数量不可大于发货数量
- **无**来料退换货处置区

#### 4. 详情

- `FactoryQcDetailView`：基础信息（含出库单号、销售单号、模板）+ 明细合计
- 可「执行质检」进入录入页；打印入口在列表

#### 5. 下游闭环（出库门控）

门控强度读取 **功能参数 → 质检门控 → 出厂质检**（当期仅弱管控）：

| 场景                  | 弱管控（当期）       | 强管控（后续）         |
| --------------------- | -------------------- | ---------------------- |
| 未发起出厂质检        | 允许确认出库         | 允许确认出库（同现网） |
| 已发起且待质检        | Toast 预警，仍可出库 | 禁止确认出库           |
| 质检不通过 / 部分通过 | Toast 预警，仍可出库 | 禁止确认出库，引导复检 |
| 质检通过              | 允许确认出库         | 允许确认出库           |

- 待质检可终止
- 配置入口：基础配置 → 功能参数 → 质检门控

### 业务规则

- 源单号展示出库单号；销售单号单独列展示
- 一出库单同时仅允许一条「待质检」出厂质检任务
- 复检仅携带上次不合格明细

### 验收标准

- [ ] 销售出库可发起/重新发起出厂质检
- [ ] 列表源单号=出库单号，销售单号独立展示
- [ ] 「质检」进入模板录入页（非旧简易弹窗）
- [ ] 提交后回写结果；打印可带模板项
- [ ] 出库确认门控符合上表
- [ ] 待质检可终止；新增受同销售单待检约束

### 主要涉及

- `FactoryQcView.vue`、`FactoryQcDetailView.vue`、`QcTaskInspectView.vue`
- `factoryQcStore.js`、`outboundStore.js`、`CreateFactoryQcModal.vue`
- `QcTaskPrintModal` + `buildFactoryQcPrintPayload`
