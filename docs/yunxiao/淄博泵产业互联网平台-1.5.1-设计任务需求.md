## DT-151-01 设计任务页面优化

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
定制泵 EBOM 需在设计任务中完成设计与定稿，再供生产计划使用。原设计任务列表与 EBOM 设计页交互不完整，缺少与产品 BOM 新增页一致的设计体验，以及 EBOM 管理入口。

**功能描述**

### 一、设计任务列表页（`DesignTaskView`）

1. **筛选区**：状态、设计任务编号、紧急度、客户名称、订单日期区间、订单类型；支持搜索与清空。
2. **工具栏**：批量**审核**、**撤回申请**、列显隐设置、刷新（不含本次范围的「新增」弹窗逻辑）。
3. **列表列**：任务编号（可点查看详情）、状态 Tag、来源、客户、产品、EBOM 编码/名称、设计人/时间、校核人/时间等；列显隐持久化。
4. **行操作**：
   - **查看**：右侧抽屉展示任务详情（基础信息、产品信息、EBOM 信息、校核信息）。
   - **设计**：状态为「待设计」且可编辑时，进入 EBOM 设计页。
   - **草稿**：已有 EBOM 草稿且非「待设计」时，继续编辑 EBOM。
5. **审核联动**：审核通过后，若关联生产计划则写入 EBOM 快照；手工新增类任务审核通过可生成生产计划（列表页审核能力，不含新增表单本身）。

### 二、EBOM 设计页（`EbomDesignView`）

1. **布局**：左侧 BOM 树 + 可拖拽分隔条 + 右侧工作区，对齐产品 BOM 新增页；左侧树**隐藏**「切换产品」入口（`hide-switch-product`）。
2. **顶部工具栏**（右侧）：收起/展开信息、概览、打印、取消、保存为草稿、保存并提交；收起后在工具栏展示 EBOM/产品摘要。
3. **基础信息区**（可收起）：
   - **EBOM 头**：EBOM 编码（可编辑，不填则保存时自动生成）、EBOM 名称、BOM 类型（固定只读「EBOM」）。
   - **父项产品信息**：物品名称、规格型号、材质、图号、工艺路线、技术参数、配套要求；选中根节点时可编辑，选中子节点时只读展示对应子项信息。
4. **物料清单**：复用 BOM 物料表格，支持列设置、按 BOM 添加、添加子项、拖拽排序、引用模板等。
5. **根节点同步**：修改根节点父项名称/规格等字段时，左侧 BOM 树根节点名称同步更新。
6. **保存逻辑**：
   - **保存为草稿**：EBOM 状态保持草稿，设计任务标记 `hasEbomDraft`，状态进入「设计中」。
   - **保存并提交**：EBOM 定稿，设计任务进入「待审核」。
   - **取消**：关闭当前 Tab 返回列表。
7. **进入校验**：仅「待设计 / 设计中 / 已驳回」可进入；无基准 BOM 时提示并从空白结构开始。

### 三、EBOM 管理页（`EbomManagementView`）

1. 筛选：状态、EBOM 编码、产品名称、设计任务编号、客户名称。
2. 列表展示 EBOM 定稿记录，含状态 Tag、关联设计任务、产品、客户等；支持列显隐。
3. 提示文案：EBOM 由设计任务产出，定稿后供生产计划使用，不回写产品 BOM。

**业务规则**

- EBOM 与产品 BOM 分离：设计产出为 EBOM，定稿后快照供生产计划，不反写产品 BOM 库。
- 销售订单来源的设计任务，定制产品审核销售单后自动生成（自动生成逻辑不在本需求范围）。
- 设计任务状态机：待设计 → 设计中（有草稿）→ 待审核 → 审核通过 / 已驳回。

**验收标准**

- [ ] 列表筛选、列显隐、详情抽屉、审核/撤回可用；待设计/草稿入口正确。
- [ ] EBOM 设计页布局与产品 BOM 新增页一致；EBOM 头、父项信息、物料清单可正常维护。
- [ ] 根节点字段修改后左侧树同步；保存草稿/提交后任务与 EBOM 状态正确。
- [ ] EBOM 管理页可查询定稿记录；不可编辑状态下无法进入设计页。

## DT-151-02 EBOM 设计页打印与概览

- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
设计人员在 EBOM 设计过程中需预览 BOM 结构并打印物料清单，便于评审与现场备料；需复用产品 BOM 打印能力，场景为 EBOM 设计页。

**功能描述**

1. **概览入口**：EBOM 设计页工具栏「概览」按钮，打开 `BomOverviewModal`，展示 BOM 编号、规格、层级结构及物料汇总（需已存在根节点）。
2. **打印入口**：工具栏「打印」按钮，打开 `BomPrintModal`；无根节点时禁用。
3. **打印弹窗**：支持打印数量、纸张、方向；**预览**（新标签页）与**直接打印**；**直接打印**选项无默认蓝色高亮。
4. **设置打印项**：弹窗内可配置打印列显隐与排序；配置持久化（与产品 BOM 打印共用列配置体系，读取 EBOM 当前 `treeNodes + lineItems`）。
5. **预览页**：新标签打开 BOM 清单预览，支持再次打印与设置打印项；列配置变更后预览表格即时刷新。
6. **打印数据范围**：当前 EBOM 设计页内存中的树节点与物料行（含未保存草稿内容按页面当前态打印）。

**业务规则**

- 本需求范围为 **Web 端 EBOM 设计页**；生产计划 EBOM 打印见 PP-151-02，二者列配置与数据字段相互独立。
- 打印前需有 BOM 根节点；概览/打印按钮在无根时置灰。
- 打印清单不含生产计划专用的库存数/需求数列。

**验收标准**

- [ ] EBOM 设计页可打开概览弹窗，结构信息正确。
- [ ] 打印弹窗可预览、直接打印；直接打印无默认高亮。
- [ ] 设置打印项可用，配置持久化，预览页即时生效。
- [ ] 打印内容与设计页当前 BOM 树/物料行一致。

## DT-151-03 设计任务关联销售订单信息展示

- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
来源于销售订单的设计任务，设计人员需在 EBOM 设计时查看原始销售订单需求（技术参数、配套要求、附件等），避免来回切换模块。

**功能描述**

1. **入口**：EBOM 设计页工具栏「查看销售订单」按钮；仅当设计任务**来源为销售订单**且存在 `salesOrderNo` 时显示（手工新增任务不显示）。
2. **展示方式**：右侧抽屉 `DesignTaskSalesOrderDrawer`（宽 640px），分三块：
   - **基础信息**：销售订单号、客户名称、合同编号、业务员。
   - **销售明细**（按 `salesLineId` 匹配，若无则按产品编码兜底）：产品名称/编码、规格型号、业务类型、产品属性、材质、交付方式、交付日期、销售数量、含税价、技术参数、配套要求、补充说明。
   - **图片文档信息**：订单级附件列表 + 明细行附件；表格列：归属（订单/明细）、文件名、类型、上传时间。
3. **空态**：
   - 找不到订单：「未找到关联销售订单」。
   - 找到订单但无匹配明细行：「未找到关联销售明细行」。
   - 无附件：「暂无图片或文档」。

**业务规则**

- 销售订单数据从销售订单 store 按 `salesOrderNo` 查询；明细行优先 `task.salesLineId`，其次 `task.productCode`。
- 行业务类型展示使用 `resolveLineBusinessType` 与订单头汇总规则一致。
- 抽屉只读，不在此修改销售订单；设计页父项信息仍由设计人员维护 EBOM。

**验收标准**

- [ ] 销售订单来源任务显示「查看销售订单」；手工新增任务不显示。
- [ ] 抽屉基础信息、明细字段、附件列表展示完整正确。
- [ ] 明细行匹配规则正确（lineId 优先，产品编码兜底）。
- [ ] 订单/明细不存在时有明确空态提示。
