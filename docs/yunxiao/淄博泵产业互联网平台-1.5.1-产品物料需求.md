## PM-151-01 产品/物料新增编辑页 Tab 布局与页头结构

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
原产品/物料表单字段过多、纵向堆叠，不利于按业务域维护；需对齐主数据分层录入习惯，将销售、采购、生产、工时、预警分 Tab 管理。

**功能描述**

1. 新增/编辑弹窗改为 Tab 布局：基本信息、销售、采购、生产控制、工时配置、预警信息。
2. 页头固定展示实体名称输入框（产品名称 / 物料名称），下方为业务能力勾选项区域。
3. 查看模式（点击列表编号进入）全表单只读，Tab 切换正常。

**业务规则**

- 新增默认打开「基本信息」Tab。
- 弹窗宽度约 92%，与 BOM 等大表单视觉一致。

**验收标准**

- [ ] 产品信息与物料信息新增/编辑页均为 Tab 结构，六个 Tab 均可访问。
- [ ] 页头名称输入与 Tab 内容分区清晰，查看模式不可编辑。

## PM-151-04 物料可销售与产品物料双向联动

- **优先级**：P0 | **需求负责人**：邓利佳 | **验收负责人**：梁海曳 | **状态**：已实现

**功能描述**

- 物料勾选「产品物料」时，「可销售」同步勾选。
- 取消「可销售」时，「产品物料」同步取消。
- 保存时若 isProductMaterial 为 true，同步产品信息表（字段映射见 productMaterialMap）。

- 开启产品物料必须可销售；不可销售则不可为产品物料。

**验收标准**

- [ ] 物料开启产品物料后，产品信息列表出现同编码记录。
- [ ] 取消可销售后产品物料自动取消。

## PM-151-09 产品/物料详情 BOM 信息 Tab 与列表 BOM 信息列

- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
产品/物料主数据与产品 BOM 存在一对多版本关联，用户需在主数据详情中集中查看关联 BOM 版本及状态，并在列表快速识别当前生效或最新 BOM，无需跳转 BOM 模块逐条查找。

**功能描述**

1. **详情页 BOM 信息 Tab**（产品信息、物料信息编辑/查看弹窗，仅编辑/查看模式展示，新增时不显示）：
   - 新增「BOM信息」Tab，展示该物品关联的全部 BOM 版本列表。
   - 列：状态、BOM编码、BOM名称、BOM版本、创建人、创建时间、生效日期、失效日期。
   - BOM 编码可点击，在新 Tab 打开对应 BOM 详情页。
   - 无关联 BOM 时展示空状态「暂无关联 BOM」。
2. **列表 BOM 信息列**（产品列表、物料列表）：
   - 新增「BOM信息」列，展示格式为「BOM名称 + 版本号」拼接（如 `化工流程泵 BOM V2026.1`）。
   - 无关联 BOM 时显示「—」。
3. **数据范围**：按物品类型（product / material）与物品 ID 匹配产品 BOM 表中关联记录，含生效、待发布、已归档全状态。

**业务规则**

- Tab 内列表排序：优先生效版，其次待发布，再已归档；同状态按版本号降序，再按创建时间降序。
- 列表列取值优先级：优先生效版 → 其次待发布 → 再取最新关联版本；与 Tab 排序规则一致。
- BOM 信息 Tab 只读展示，不在此 Tab 内维护 BOM 结构（维护入口仍为列表「BOM维护」）。

**验收标准**

- [ ] 产品/物料编辑或查看详情时可见「BOM信息」Tab；新增弹窗无此 Tab。
- [ ] Tab 正确列出该物品全部关联 BOM，状态标签与 BOM 模块一致；点击 BOM 编码可跳转详情。
- [ ] 产品列表、物料列表「BOM信息」列展示正确；无 BOM 显示「—」。
- [ ] 存在生效版时列表与 Tab 均优先展示生效版信息。
