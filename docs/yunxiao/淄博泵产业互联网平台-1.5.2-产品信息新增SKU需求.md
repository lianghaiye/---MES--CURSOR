## 背景与改造动机

原「产品信息」按单条产品/物料维护，同一规格族下需重复录入名称、能力位、销售采购信息；变体差异仅体现在规格/材质字段，无法表达「族 → 多个 SKU」关系，后续 BOM、销售投产也难以按 SKU 精确绑定。

**目标能力**

1. 引入 **产品族（SPU）**：一套变体轴 + 编码规则，批量派生 **SKU**。
2. 产品信息入口统一为 **SKU 列表 + 模板（族）列表** 双视图。
3. 新增页支持 **单规格物料** 与 **多规格变体** 两种创建模式。
4. 销售/生产投产 **仅认 SKU 自有生效 BOM**；族模板 BOM 仅作设计参考。

## SKU-152-01 产品信息列表 SKU 视图改造

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **依赖**：无（列表基线）

### 背景

产品信息列表需承接「合并后的产品+物料主数据」，并展示 SKU 归属的产品族，让业务人员能区分普通主数据与变体 SKU。

### 功能描述

1. 「产品信息」菜单唯一入口（原物料信息入口重定向至此）。
2. **默认 SKU 视图**：合并产品表 + 物料表（产品物料去重展示规则沿用主数据列表工具）。
3. 列表新增/调整列：
   - **产品族**：展示 `spuName`（无族则为空或「—」）。
   - **BOM 信息**：变体 SKU 且无自有生效 BOM 时，展示「继承模板」等语义提示（不可误导为可投产）。
   - 保留编号、名称、产品类型、规格型号、材质、图号、业务类型、类别、操作等原有主列。
4. 行操作保留：编辑、BOM 维护、删除、克隆。
5. 变体 SKU 行可有轻量标识（如角标/标签「变体 SKU」），便于识别。

### 业务规则

- SKU 视图数据来源：`productInfo` ∪ `materialInfo` 统一列表。
- 存在 `spuId` 的记录视为归属某产品族的变体 SKU。
- 点击编号进入查看模式；点击编辑打开同一套主数据表单。

### 验收标准

- [ ] 默认进入 SKU 视图，可见产品族列。
- [ ] 变体 SKU 无自有生效 BOM 时，BOM 列提示清晰，不与「已启用可投产」混淆。
- [ ] 编辑/删除/BOM 维护对变体 SKU 与普通主数据均可操作。

### 关联文件（实现参考）

- `src/views/product-process/MasterItemInfoView.vue`
- `src/utils/masterItemList.js`

## SKU-152-02 产品信息列表模板（族）视图与切换

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **依赖**：SKU-152-01（同一入口）

### 背景

产品族（SPU）需要独立管理：变体维度、BOM 策略、已生成 SKU 数量；不宜与 SKU 行混在一张表里编辑。

### 功能描述

1. 列表工具栏提供 **SKU 视图 / 模板视图** 切换（`listViewMode`）。
2. **模板视图** 列：
   - 模板编码（族编码）
   - 模板名称
   - 分类
   - **变体维度**（如规格型号、材质）
   - **BOM 策略**（继承族模板 / 每 SKU 独立）
   - **SKU 数**
3. 模板行操作：
   - **编辑模板**：打开多规格表单（编辑 SPU）
   - **变体矩阵**：打开矩阵弹窗/预览，勾选组合后批量生成
   - **模板 BOM**：维护族模板 BOM（`itemType=spu`）
4. 切换视图时保留左侧类别树筛选习惯；空状态有明确引导（去新增多规格 / 去生成 SKU）。

### 业务规则

- 模板数据来自 SPU 存储；SKU 数由关联产品/物料中 `spuId` 聚合。
- 删除模板前需明确是否校验仍有下属 SKU（建议：有 SKU 时禁止删除或二次确认）。

### 验收标准

- [ ] 可在 SKU 视图与模板视图间切换，列集完整。
- [ ] 编辑模板、变体矩阵、模板 BOM 三个入口均可跳转且回到正确视图。
- [ ] SKU 数与实际下属变体 SKU 一致。

### 关联文件（实现参考）

- `MasterItemInfoView.vue`（模板视图分支）
- `src/store/spuStore.js`
- `SpuFormModal.vue` / 主数据多规格编辑

## SKU-152-03 新增页创建模式与单规格 SKU 保存

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **依赖**：SKU-152-01

### 背景

多数场景仍只需建一条具体可售/可产物料；需在新增页保留「单规格」路径，并与能力勾选推导产品类型逻辑兼容。

### 功能描述

1. 新增入口：列表「新增」→ 主数据新增页/弹窗（`MasterItemCreateView` / `MasterItemFormModal`）。
2. 页头能力勾选：可销售、可生产、整机、零部件、可采购、可外协（规则沿用 PM-151 系列）。
3. **创建模式**（仅新建）：
   - **单规格物料**（默认）
   - **多规格变体**
4. 单规格路径：
   - 基本信息 Tab 直接维护规格型号、材质、图号等。
   - 保存走主数据保存：按能力写入产品表 / 物料表 / 双写产品物料。
   - **不创建** SPU，无 `spuId`。
5. 编辑已有无族主数据：保持单规格编辑体验；若记录带 `spuId`，展示「变体 SKU」只读归属条。

### 业务规则

- 产品「可销售」默认勾选且不可取消（与现网一致）。
- 单规格编码沿用主数据编码规则（如产品 CP 前缀）。
- 保存校验：必填项、编码唯一、能力位互斥（整机/零部件等）。

### 验收标准

- [ ] 新建默认可选单规格并成功保存，列表出现对应 SKU 行且无产品族。
- [ ] 能力勾选正确推导产品类型并落库。
- [ ] 编辑变体 SKU 时可见族归属提示，不会误改成无关族。

### 关联文件（实现参考）

- `MasterItemFormModal.vue`
- `MasterItemCreateView.vue`
- `src/utils/masterItemSave.js`

## SKU-152-04 新增页多规格变体配置与矩阵预览

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **依赖**：SKU-152-03（同源表单）、SKU-152-05（编码预览）

### 背景

创建「泵产品族」类主数据时，希望一次配置变体轴与候选组合，保存族后立即（或稍后）生成下属 SKU，避免重复录入。

### 功能描述

1. 选择 **多规格变体** 后：
   - 页头「编号」语义变为 **族编码**（可自动生成，如 `F` + 流水）。
   - 出现 **变体配置** Tab（或等价分区）。
2. 变体配置区能力：
   - 配置 **变体轴**：系统锁定轴「规格型号」「材质」；可扩展枚举类自定义轴。
   - 材质轴取值来源于 **材质牌号库**（可跳转维护）。
   - 配置 **BOM 策略**：继承族模板 / 每 SKU 独立。
   - 可选关联 **族模板 BOM**（`baseBomId`）。
3. **矩阵预览**：按轴值域笛卡尔积展示待生成 SKU 行（编码预览、名称预览、BOM 来源、是否已有、启用开关）。
4. 保存多规格：
   1. 先落库/更新 SPU；
   2. 再按启用组合批量 upsert SKU。
5. 编辑模板：强制多规格模式，回显轴、启用组合、BOM 策略。

### 业务规则

- 材质轴值域为空时，矩阵不把「全库材质」直接笛卡尔展开（防组合爆炸）。
- 未启用的矩阵行不生成 SKU。
- 共享字段（销售/采购/能力位等）从族写入下属 SKU，具体字段集以实现为准，需在测试用例中列清单。

### 验收标准

- [ ] 多规格保存后模板视图可见该族；SKU 视图可见勾选启用的变体 SKU。
- [ ] 变体轴增减后预览行数正确变化。
- [ ] 重复保存同一启用组合不会产生重复 SKU（与 SKU-152-05 呼应）。

### 关联文件（实现参考）

- `VariantAttributeEditor.vue`
- `VariantSkuMatrixPreview.vue`
- `src/utils/spuMatrix.js`
- `src/utils/spuSkuSave.js`

## SKU-152-05 SKU 编码规则与变体唯一性

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **依赖**：SKU-152-04（被依赖）

### 背景

变体 SKU 必须可预测、可解读；同族下同一变体组合不可重复建码。

### 功能描述

1. **产品侧固定编码规则**（只读展示）：  
   `{SPU_CODE}-{SPEC}-{MATERIAL}`  
   例：`F0001-HT250-M001`。
2. 名称规则：族名 + 各轴展示值拼接（如 `清水离心泵 HT250 304`）。
3. **变体唯一键**：同 `spuId` + 规范化后的 `variantValues` 唯一；匹配到则 **更新**，否则 **新建**。
4. 生成时写回：`isVariantSku=true`、`spuId`、`spuName`、`variantValues`、规格/材质同步字段等。
5. UI 展示编码规则说明（面板/Tooltip），避免业务手改导致规则漂移（产品侧不允许自定义 pattern；若物料族后续开放，需另开需求）。

### 业务规则

- 材质码优先用材质牌号短码（如 `M001`），避免超长 SKU。
- 编码冲突（与他族或非变体主数据编码撞车）时阻断并提示。
- 规格、材质等轴值变更后，编码与名称随规则重算（编辑路径需说明是「仅未引用可改」还是「允许改并重算」——本需求建议：**已生成 SKU 的变体键不可改，只能启用新组合**）。

### 验收标准

- [ ] 矩阵预览编码符合固定 pattern。
- [ ] 同一组合二次生成不产生第二条 SKU，字段可更新。
- [ ] 不同组合编码/名称可区分，列表可检索。

### 关联文件（实现参考）

- `src/constants/spu.js`
- `src/utils/spuVariant.js`
- `src/utils/spuMatrix.js`（`buildSkuCodeFromPattern`）
- `SkuCodeRulePanel.vue`

## SKU-152-06 变体矩阵批量生成 SKU

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **依赖**：SKU-152-02、SKU-152-05

### 背景

族创建后往往分批补充规格×材质组合；需要独立于「保存整单」的批量生成入口。

### 功能描述

1. 入口：模板视图行操作「变体矩阵」；新增多规格保存后也可同套预览组件。
2. 矩阵表列：各变体轴值、SKU 编码、预览名称、BOM 来源、状态（已有 SKU / 待生成）、启用/勾选。
3. 操作：
   - 勾选待生成行（默认勾选「尚未存在 SKU」的行）。
   - **生成选中 SKU**：调用批量 upsert。
   - 生成后回写 SPU `enabledCombinations`（或等价启用集合）。
4. 结果反馈：新建条数、更新条数、跳过/失败原因。

### 业务规则

- 已有 SKU 的组合：允许「更新共享字段」或「跳过」，选项需在 UI 文案明确（默认更新同源字段、不动业务单据引用关键键）。
- 生成过程中途失败：已成功写入的保留，错误行可重试。

### 验收标准

- [ ] 勾选 N 条新组合 → 列表新增 N 条变体 SKU，均挂同一 `spuId`。
- [ ] 已有组合再生成不重复建档。
- [ ] 生成后模板「SKU 数」即时刷新。

### 关联文件（实现参考）

- `VariantSkuMatrixPreview.vue`
- `batchGenerateSkus` / `upsertSkuForSpu`（`spuSkuSave.js`）
- （可选旧入口）`SpuVariantMatrixModal.vue` — 应与主路径预览统一，避免两套笛卡尔逻辑

## SKU-152-07 SPU/SKU 与 BOM 策略关联

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **依赖**：SKU-152-04、SKU-152-06

### 背景

若误把「族模板 BOM」当成可投产 BOM，将导致销售/计划错误履约。需在主数据与矩阵中明确策略与来源。

### 功能描述

1. SPU **BOM 策略**：
   - **继承族模板**：族维护 `baseBomId`；下属 SKU 可先无自有 BOM，列表提示「继承模板（设计参考）」。
   - **每 SKU 独立**：不依赖族模板，各 SKU 自行维护生效 BOM。
2. 主数据表单 **BOM 信息 Tab**（编辑/查看）：
   - 展示 SKU 自有生效 BOM；
   - 变体 SKU 展示族模板提示：**不可直接投产**。
3. 「模板 BOM」入口：以 `itemType=spu` 打开 BOM 维护，保存后回写 `baseBomId`。
4. 行操作「BOM 维护」：始终进入 **当前 SKU（产品/物料）** 自有 BOM，而非族模板。
5. 矩阵「BOM 来源」列：自有 BOM / 继承 / 独立策略未配置 / 未配置 等枚举展示。

### 业务规则

- **销售投产、生产领用仅认 SKU 自有「使用中/生效」BOM**（与销售 BOM 来源改造口径一致）。
- 族模板 BOM 仅供设计任务预填参考。
- 策略从「继承」改为「独立」时：不自动删除 `baseBomId`，但列表/投产逻辑不再将其视为默认可用。

### 验收标准

- [ ] 两种 BOM 策略均可配置并回显。
- [ ] SKU 行 BOM 维护不会误进族模板页。
- [ ] 仅有族模板、无 SKU 自有生效 BOM 时，下游校验按「无可用产品 BOM」处理（与 SKU-152-08 联调）。

### 关联文件（实现参考）

- `src/constants/spu.js`（`SPU_BOM_STRATEGY*`）
- `ItemBomInfoTab.vue`
- `resolveMatrixBomSource`（`spuMatrix.js`）
- 产品/物料 BOM 创建路由

## SKU-152-08 下游选品与投产认 SKU BOM

- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **依赖**：SKU-152-07

### 背景

销售订单、BOM 子件拣选等下游必须选到具体 SKU；投产规则与「SKU 自有生效 BOM」对齐，避免选到未可售变体或仅有族模板的数据。

### 功能描述

1. **选品/拣选器**（如 `SelectBomMaterialModal`）：
   - 列表展示变体摘要（规格×材质或 `variantSummary`）；
   - 可选展示所属产品族列。
2. 销售订单明细绑定 **SKU 的 productId/物料Id**，不以 SPU 作为订单履约主键。
3. 审核/校验无自有生效 BOM 时：
   - 按销售订单「BOM来源」规则提示「需设计任务」或阻断（与 SO-152-01 一致）；
   - 文案可提示「请先为该 SKU 维护并启用产品 BOM」。
4. （可选增强，可另开子需求）提供「选产品族 → 选变体轴 → 锁定 SKU」两步选择器；本期若不做，需在范围中写明「本期仅直接搜索 SKU」。

### 业务规则

- 下游禁止仅保存 `spuId` 而无具体 SKU 主键（订单行必须可出入库、可报工）。
- 停用/删除 SKU 后，历史单据仍展示快照字段，新建不可再选。

### 验收标准

- [ ] 拣选器能区分同族不同变体 SKU。
- [ ] 仅族模板 BOM、无 SKU 自有生效 BOM 的明细，审核路径与「无产品 BOM」一致。
- [ ] 选中变体 SKU 下单后，明细展示规格/材质与主数据一致。

### 关联文件（实现参考）

- `SelectBomMaterialModal.vue` / `bomSubItemPicker.js`
- `CreateSalesOrderModal.vue`
- `src/utils/spuLineResolve.js`（可选完整接入）
