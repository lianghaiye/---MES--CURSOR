# 库存占用、跨单调拨与补货中心

> **不做 BOM 级 MTS**（子件策略不裁剪生产计划树）。  
> 业务规则里的「生产模式」（标准 / 极简报工）只控制报工流程，与本文无关。  
> 产品「计划策略」（按单 / 以库存）仅作标签与提醒文案，**不再**作为「审核绝不建计划」的唯一开关。

## 能力概览

1. **销售库存提醒**：现存量、本单软占用、自由备货（未挂单）、他单占用明细。
2. **跨单调拨**：紧急单可申请调用他单未发货占用；确认后转移占用，默认同步记「偿还欠量」。
3. **补货中心**：产品/物料开启预警且 ≤ 最低库存时进入建议列表；可改生产或采购；也可手工添加成品/零部件/毛坯再执行。

## 软占用规则

| 时机          | 行为                                        |
| ------------- | ------------------------------------------- |
| 销售审核通过  | 按 `min(行需求, 当时自由备货)` 写入本行占用 |
| 成品/相关入库 | 优先偿还调拨欠量，再补给来源销售行占用      |
| 销售出库确认  | 按出库数量释放本行占用                      |
| 反审 / 作废   | 释放整单占用                                |

自由备货 = 现存量 − 全部软占用。

## 跨单调拨示例

1. 订单 A 审核并占用产品 B 的库存，未发货。
2. 订单 C 要同产品且加急 → 库存提醒显示「他单占用（A）」。
3. C 申请从 A 调拨 → 确认后占用转到 C，A 记偿还欠量。
4. C 发货；后续入库优先还给 A 的欠量 → A 再发货。

## 补货中心

- 入口：生产计划页「补货中心」。
- 预警不强制计划策略=MTS。
- 动作：生产（生成补货生产计划 `BH…`）或采购（生成采购申请）。
- 手工添加：不受是否预警限制。

## 与旧「仅 MTS 跳过建计划」的差异

审核仍可按自产行生成生产计划；若本行软占用已覆盖需求，提示「可直接从仓库发货（可不排产或减计划数量）」，由用户决定，不强制跳过。
