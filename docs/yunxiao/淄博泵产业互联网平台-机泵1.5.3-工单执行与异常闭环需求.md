## 一、工单页面样式与排版优化

### 1.1 Tab 样式

- 工单详情 Tab 采用与采购申请/销售订单详情一致的**胶囊导航**：浅蓝底轨 + 选中蓝底白字。
- 覆盖生产工单、总装工单详情面板。

### 1.2 详情头信息

- Meta 栏：`状态`、`创建日期`、`创建人`（原「负责人」）、`更新时间`、`更新人`。
- 更新操作（含下发、暂停、终止、改紧急度、改排产数量等）需回写更新时间/更新人。

### 1.3 排产信息 Tab 内容

- **按批次分块展示**：批次号、批次状态、排产数量、工序任务数、下发时间；当前批次高亮。
- 批内工序顺序从 1 起编；避免多批同工序混排、任务编号串批。

### 1.4 列表交互

- 卡片视图：切换视图按钮前增加「刷新」。

## 二、工单状态合并与排产旁显

### 2.1 主状态（唯一）

| 状态   | 含义                             |
| ------ | -------------------------------- |
| 待下发 | 未下发                           |
| 已下发 | 已下发，尚无领取/报工事实        |
| 执行中 | 已有领取或极简单执行人直达待报工 |
| 已完成 | 完工                             |
| 暂停   | 挂起                             |
| 终止   | 结束且不可恢复执行               |

- **取消**「部分下发」作为主状态。
- **取消**无意义的「任务/正常」展示。

### 2.2 排产旁显（非主状态）

- 展示 `排产 x/计划`；未排满且已开始排产时旁显 **未排完**。
- 待下发且无下发事实时，已排产展示为 0（创建时填写的排产数不计入已排产）。

### 2.3 状态回写规则

- 下发后无人领取 → 已下发；有领取事实 → 执行中。
- 暂停/终止/已完成为锁定态，不被下发同步覆盖。
- 极简模式：单执行人工序任务下发后进入执行人「今日待报工」，工单可直接为执行中。

## 三、工单列表排序优先级

- **第一优先级**：工单操作更新时间倒序（`updatedAt`，无则 `createdAt`）。
- **不再**以状态优先级作为第一排序键。
- 小程序报工完工默认不刷新列表排序用的操作更新时间（与业务操作更新区分）。

---

## 四、工单分批次下发

1. 支持一张工单多个排产批次；每批独立数量、工序执行人。
2. 本批数量 > 0 且 ≤ 剩余可排（计划 − 已排）。
3. 可「仅保存批次」或「保存并下发本批」。
4. 下发后生成/同步小程序任务；排产信息按批次展示。
5. 修改排产数量时：
   - **已完成批次不可改**；
   - **多个未完成批次**须先选择批次再改；
   - 本批上限 = 计划 − 其他批次合计；
   - 确认后同步该批对应小程序任务目标数。

## 五、极简模式下工单异常处理闭环

适用：生产/总装工单详情操作栏（待下发/已下发/执行中等按按钮规则显示）。

### 5.1 修改排产数量

| 条件               | 行为                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------- |
| 已有任务完成报工   | 拦截：当前已有任务完成报工，不允许修改报工数量，请撤回任务报工状态后再修改            |
| 无报工             | 输入数量 → 确认：是否确认修改当前排产数量为【值】，确认后将同步修改小程序任务的目标数 |
| 分批且存在已完成批 | 已完成批次不可选/不可改                                                               |
| 分批且多未完成批   | 先选批次再改                                                                          |

> 不以「已下发 / 执行中」单独作为可否修改的判断（极简下发即可进执行中）。

### 5.2 调整紧急度

- 打开紧急度弹窗修改并保存；写入更新时间/更新人。

### 5.3 暂停

| 条件                        | 行为                                             |
| --------------------------- | ------------------------------------------------ |
| 已下发/执行中（或已有任务） | 二次确认：暂停后未完成任务显示「暂停」且不可报工 |
| 已有报工完成                | 强提示：是否仍要暂停；暂停不影响已完成任务       |
| 待下发                      | 普通确认后可暂停                                 |

- 暂停后工单状态=暂停；可「恢复」回到暂停前状态。

### 5.4 终止

| 条件     | 行为                                                    |
| -------- | ------------------------------------------------------- |
| 无报工   | 确认后终止；任务隐藏/终止                               |
| 部分报工 | 双分支：**仍终止（重置报工）** / **不处理（保留报工）** |

### 5.5 完成

- 二次确认后标记已完成，并触发完工库存扣减（既有逻辑）。

## 六、重置任务状态

- 入口：排产信息 → 工序行操作「重置状态」。
- 确认文案：重置状态会将任务状态重置，报工数量清零，是否确认？
- 确认后：对应小程序任务状态回到待报工/待领取，报工数量清零；列表与批次展示同步更新。
- 用途：支持「撤回报工后再改排产数量」等异常闭环。

## 七、详情页增排产 / 领料 / 入库 / 质检 Tab（NYVC-1898）

### 7.1 Tab 结构

在「工单详情」之后增加（生产/总装一致）：

1. 排产信息
2. 领料信息
3. 入库信息
4. 质检信息

### 7.2 排产信息

- 按批次分块：批次号、状态、排产数量、工序任务数、下发时间；当前批次高亮。
- 批内字段：顺序、工序名、状态、任务编号、执行者、排产数量、报工数量、良品数、不良品数、报工时长、报工时间、操作（生成任务 / 修改执行人 / 重置状态）。

### 7.3 领料信息

序号、状态、申请单号（跳转）、产品/摘要、数量、领用车间、出库单号（跳转）、出库状态、申请人、申请时间。

### 7.4 入库信息

序号、状态、入库单号（跳转）、产品/摘要、数量、入库仓库、创建人、创建时间、确认人、确认时间。

### 7.5 质检信息

序号、状态、质检结果、质检单号、质检方式、工序、任务编号、任务执行人、质检时间、质检人。

## 验收标准（汇总）

- [ ] 工单详情 Tab 为胶囊样式；排产信息按批次分组且能区分批次
- [ ] 主状态仅六态；未排完为旁显；列表无「部分下发」「任务/正常」
- [ ] 列表按更新时间倒序
- [ ] 可多分批排产/下发；改排产数遵守已完成批次不可改、多批先选批
- [ ] 暂停/终止/改排产数弹窗与规则符合极简模式报工判断
- [ ] 重置状态可清零报工并允许后续改排产数
- [ ] 详情含排产/领料/入库/质检四 Tab，字段与跳转符合第七节
- [ ] 生产工单与总装工单行为一致（在适用范围内）
