## BOM-EDIT-01 左右分栏：结构树可折叠与调宽

- **优先级**：P0
- **状态**：已实现

**功能描述**

1. 编辑页左侧为 BOM 结构树，右侧为根产品信息 + 物料清单。
2. 支持拖拽分隔条调整左侧树宽度（约 200–520px），宽度本地记忆。
3. 支持收起 / 展开结构树，折叠状态本地记忆（按编辑页/详情页作用域区分）。

**验收标准**

- [ ] 收起后仅保留右侧内容区；再次展开恢复上次宽度。
- [ ] 刷新页面后折叠状态与宽度保持。

## BOM-EDIT-02 顶栏固定与标题展示

- **优先级**：P0
- **状态**：已实现

**功能描述**

1. 顶栏固定展示操作按钮：收起/展开信息、概览、查看关联 BOM、保存、保存并发布、取消。
2. 顶栏左侧固定展示标题：`【BOM类型】/【产品名称】`（发运 BOM 显示发运包名称）。
3. **结构树展开/收起按钮固定在标题左侧**，不随树面板展开/收起换位置；展开显示「收起」图标，收起显示「展开」图标。

**验收标准**

- [ ] 右侧内容滚动时顶栏始终可见。
- [ ] 树折叠前后，顶栏左侧树开关按钮位置不变。

---

## BOM-EDIT-03 左侧结构树固定高度，不随右侧滚动

- **优先级**：P0
- **状态**：已实现

**功能描述**

1. 左侧 BOM 树高度 = 标题栏下边沿起至页面底边，上下各留 **8px** 间距（由 `page-body` padding 保证）。
2. 右侧根产品区、物料清单独立纵向滚动；左侧树**不随右侧滚动**。
3. 树节点过多时，在左侧面板内部滚动。
4. 搜索框右侧三个图标（字段配置 / 展开全部 / 收起全部）**同一行**展示。

**验收标准**

- [ ] 右侧长列表滚动时，左侧树位置与高度不变。
- [ ] 树内容超出时仅树区域内部出现滚动条。
- [ ] 三个小图标始终横排，不折行。

## BOM-EDIT-04 根产品可搜索选择与主数据同步

- **优先级**：P0
- **状态**：已实现

**功能描述**

1. 根产品字段为可搜索 AutoComplete，展示 `[编码] 名称`；支持「搜索更多…」、不存在时「创建「xxx」」。
2. 「同步到主数据」位于「根产品」标题右侧。
3. 可编辑状态（待发布/生效）允许更换根产品；工单侧继续使用 EBOM 快照，不受产品 BOM 换根影响。
4. BOM 版本字段放在顶部基础信息「BOM类型」之后（编辑态）。

**验收标准**

- [ ] 可通过搜索切换根产品；创建新产品流程可用。
- [ ] 换根后结构树与物料清单根节点同步更新。

## BOM-EDIT-05 物料清单树表与行操作

- **优先级**：P0
- **状态**：已实现

**功能描述**

1. 右侧物料清单为树形表格，序号层级如 `1`、`1.1`、`1.2`。
2. 操作列：每行「添加子项」（挂到该行下）、「删除」（纯文字，无垃圾桶图标）；横向排列、不换行。
3. 「从模板导入」固定在物料清单工具栏（与按BOM添加、添加子项同排），**不随左侧树折叠换位置**；左侧树内不再显示该按钮。
4. 表格下方提供「+ 添加明细行」；合计区在表格下方，含项数/单位用量/BOM 成本，以及第二行：`BOM版本 / 生效日期 / 创建人`。
5. 添加明细后，右侧内容区自动滚动至最新行附近。

**验收标准**

- [ ] 行内「添加子项」挂在当前行下级，而非根下。
- [ ] 树折叠前后「从模板导入」仍在物料清单工具栏同一位置。
- [ ] 合计区在表下，含版本/生效日期/创建人。

## BOM-EDIT-06 物料清单列宽、不换行与斑马底色

- **优先级**：P1
- **状态**：已实现

**功能描述**

1. 列表单元格默认不换行；过长文本省略（含子项名称、子项编码、变体、下料尺寸等）。
2. 列宽加宽（参考实现）：序号 `#` ≈72、子项名称 ≈280、子项编码 ≈180、操作列 ≈148。
3. **一级物料间隔底色**：第 2、4、6… 个一级物料及其全部下级使用浅灰底 `#fafafa`；下级继承所属一级物料底色。

**验收标准**

- [ ] 序号/编码/名称不易挤叠；操作列「添加子项」「删除」同一行。
- [ ] 同组（同一一级及其子孙）底色一致，相邻一级组底色交替。

## BOM-EDIT-07 标签页切换不丢编辑态

- **优先级**：P0
- **状态**：已实现

**功能描述**

1. 标签保存完整 `fullPath`（含 query）；切回标签时带 query 恢复。
2. 新建/编辑 BOM 草稿跨重挂载保留；初始化只跑一次，切回不反复弹选品窗。
3. 选品弹窗先关闭再回传选中结果，避免切标签后弹窗残留。

**验收标准**

- [ ] 编辑中途切到其他标签再切回，表单与明细不丢失、不重复弹选品。
- [ ] 选品完成后弹窗正常关闭。
