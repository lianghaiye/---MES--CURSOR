## DICT-152-01 系统字典优化（主数据列表与字典项配置）

- **优先级**：P0
- **菜单路径**：系统管理 → 系统字典
- **云效标题建议**：`WEB--系统管理--DICT-152-01 系统字典优化（主数据列表与字典项配置）`

### 背景

系统需要统一管理各类下拉枚举的「默认值源」。原系统字典能力不足：缺少标准主数据列表、字典项维护体验弱，且与后续业务字典覆盖能力未解耦。需将系统字典升级为可维护的字典主数据中心。

### 功能描述

#### 1. 菜单与页面入口

- 系统管理一级菜单下提供二级菜单 **系统字典**。
- 页面为列表 + 弹窗/抽屉配置，数据本地持久化（Mock 阶段）。

#### 2. 字典主数据列表

列表字段：

| 字段     | 说明                             |
| -------- | -------------------------------- |
| 序号     | 分页序号                         |
| 状态     | 启用 / 停用                      |
| 字典编号 | 唯一编码；内置字典带「内置」标识 |
| 字典名称 | 展示名称                         |
| 操作     | 编辑、删除、字典配置             |

筛选：关键字（编号/名称）、状态；支持分页、列设置、刷新。

#### 3. 新增 / 编辑字典

- **字典编号**：必填；以字母开头，仅含字母/数字/下划线；全局唯一；**内置字典编号不可改**。
- **字典名称**：必填。
- **状态**：启用 / 停用。
- 内置字典不可删除；非内置可删除。

#### 4. 字典配置（字典项）

抽屉维护字典项，字段：

- 显示名称（label）
- 字典值（value）
- 状态（启用/停用）
- 排序（上移/下移）

支持新增、删除字典项；保存后写入该字典。

#### 5. 内置种子字典（初始化）

| 编号               | 名称     | 用途示例     |
| ------------------ | -------- | ------------ |
| `scrap_reason`     | 报废原因 | 报废审核     |
| `replenish_method` | 补料方式 | 报废补料     |
| `process_method`   | 处理方式 | 报废处理     |
| `process_result`   | 处理结果 | 报废处理结果 |

兼容旧版扁平存储结构，自动迁移为「字典 + 字典项」模型。

### 业务规则

1. 仅 **启用** 状态的字典，且字典项为 **启用**，才可作为系统侧有效选项输出。
2. 内置字典：编号锁定、不可删除；字典项仍可配置。
3. 系统字典是业务字典的引用源；业务侧覆盖逻辑见 DICT-152-02。

### 验收标准

- [ ] 可新增/编辑/停用非内置系统字典；编号校验与唯一性正确。
- [ ] 内置字典不可删、编号不可改；可进入字典配置维护项。
- [ ] 字典配置支持增删改、排序、启用停用，保存后列表项数与取值一致。
- [ ] 关键字/状态筛选、分页正常。
- [ ] 报废等业务通过统一解析接口可读取到系统字典启用项（无业务覆盖时）。

## DICT-152-02 业务字典（企业覆盖与优先级解析）

- **优先级**：P0
- **菜单路径**：基础配置 → 业务字典
- **云效标题建议**：`WEB--基础配置--DICT-152-02 业务字典（企业覆盖与优先级解析）`

### 背景

不同企业可能对同一字典有差异化选项。需在系统字典之上提供「业务字典」：引用系统字典后按企业要求编辑字典值；运行时 **业务字典优先于系统字典**。

### 功能描述

#### 1. 菜单与定位

- 基础配置下提供二级菜单 **业务字典**。
- 列表以 **系统字典全集** 为视角，方便用户快速定位某一系统字典再做企业配置（而非孤立维护一套编号）。

#### 2. 列表与筛选

列表字段：系统状态、字典编号、字典名称、系统项数、业务状态（未配置 / 已配置启用 / 已配置停用）、操作「配置」。

筛选：关键字（系统字典编号/名称）、业务状态。

提示文案：从系统字典中查找并配置企业侧覆盖；启用后业务字典优先于系统字典。

#### 3. 配置抽屉

1. **未配置**：展示系统字典元信息 + 系统字典项预览；按钮「生成业务配置（复制系统项）」。
2. **已配置**：
   - 可改业务字典状态（启用/停用）并保存；
   - 「编辑字典项」打开与系统字典同款的字典项抽屉；
   - 「重置为系统默认」：用当前系统字典项覆盖业务项（需确认）。

#### 4. 运行时解析（统一入口）

`getEffectiveDictItems / getEffectiveDictOptions / getEffectiveDictValues`：

1. 若存在对应 `systemDictCode` 的业务字典且状态为 **启用** → 返回业务启用项（按 sort）；
2. 否则 → 返回系统字典启用项；
3. 业务字典已配置但 **停用** → 回退系统字典（不视为覆盖生效）。

#### 5. 业务接入示例

报废审核/补料等下拉已改为走有效字典解析，例如：

- `scrap_reason`、`replenish_method`、`process_method`、`process_result`

### 业务规则

1. **优先级**：业务字典（启用） > 系统字典。
2. 每个系统字典编号最多一条业务配置；不可重复生成。
3. 生成时复制当时系统字典项快照；之后系统项变更不自动同步，除非用户「重置为系统默认」。
4. 业务字典停用后，前端立即回退使用系统字典值。

### 验收标准

- [ ] 可按关键字/业务状态快速找到目标系统字典并打开配置。
- [ ] 未配置时可一键生成业务配置（复制系统项）；已配置不可重复生成。
- [ ] 可编辑业务字典项与启用状态；启用后业务下拉展示业务值。
- [ ] 业务字典停用或删除/重置后，下拉回退为系统字典启用项。
- [ ] 报废相关下拉验证：有业务覆盖用业务值，无覆盖用系统值。
