## MP-PR-151-01 待领/今日报工材质图号展示与任务详情

- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
一线工人在小程序「工序报工」的 **待领任务**、**今日待报工** 两个 Tab 中，需快速识别产品 **材质**、**图号**；原任务卡片信息不足，且无法从列表进入任务详情核对完整信息后再领取或报工。

**功能描述**

### 1. 待领任务 Tab

1. 任务卡片新增 **材质**、**图号** 展示（格式：`材质: xxx · 图号: xxx`，无数据显示「—」）。
2. **点击卡片**进入任务详情页，展示工单号、产品、工序、目标数量、材质、图号、规格型号、报工类型等完整信息。
3. 详情页底部 **领取任务**；领取成功后跳转「今日待报工」Tab。
4. 卡片右侧「领取 ›」快捷入口保留，与点击卡片进详情互不冲突。

### 2. 今日待报工 Tab

1. 任务卡片（按工序 / 按任务两种分组布局）同样展示 **材质**、**图号**。
2. **点击卡片**进入任务详情页：
   - **待报工**：状态「待报工」，底部 **去报工**
   - **已报工**：状态「已报工」，底部 **查看报工记录**
3. 复选框批量选择、「去报工 ›」快捷入口保留，交互不冲突。

### 3. 报工执行页

1. 从列表或详情进入报工页时，展示 **材质**、**图号**（有规格型号时一并展示）。
2. 展示位置：工序/产品标题下方信息条；快速报工入口不展示该信息条。

### 4. 数据来源

- 优先取任务字段 `material`、`drawingNo`；
- MOCK/种子未填时，按产品 `itemCode` 从主数据映射兜底。

**业务规则**

- 材质、图号与 Web 产品/物料主数据一致，只读展示。
- 详情页与报工页字段展示保持一致。

**验收标准**

- [ ] 待领任务卡片可见材质、图号
- [ ] 待领任务点击卡片可进详情并在详情页领取
- [ ] 今日待报工卡片可见材质、图号
- [ ] 今日待报工点击卡片可进详情并去报工/查看记录
- [ ] 报工执行页展示材质、图号
- [ ] 批量选择、快捷按钮交互不受影响
