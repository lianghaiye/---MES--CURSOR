# 产品 BOM · 下料 · 重量计算（简明说明）

更新日期：2026-08-25

---

## 一句话

在 BOM「下料」里按型材、尺寸、密度算出**理论单件重量（kg）**。

---

## 确认时回填什么

| 算出来的内容       | 写到哪里                                        | 用途                                |
| ------------------ | ----------------------------------------------- | ----------------------------------- |
| 各边尺寸 + 单位    | **下料尺寸**（`blankSize` / 文案 / 米或㎡派生） | 下料说明、按长/按面积场景仍可看尺寸 |
| **单件重量（kg）** | **单位用量**（`unitQty`）                       | 工单领料、库存扣料按重量计量        |

说明：

- 回填的是 **单件重量**（`pieceWeightKg`），不是「合计」；合计 = 单件 × 件数，仅弹窗里参考。
- 走重量计算这条路的子项，**单位用量 = 每件要用多少 kg**。
- 若物料库存单位是 kg（或按重双单位），领料需求 = 单位用量 × 父项数量 × 计划量等，与 BOM 其它行一致，只是用量来源是算出来的重量。

---

## 总公式（和你给的材料一样）

```
重量(kg) = 体积 × 密度
```

- **尺寸**：按 mm 参与计算（界面可选 mm/cm/m，系统会先换成 mm）
- **密度**：系统里用 **g/cm³**（碳钢 7.85），和 **7850 kg/m³** 等价：  
  `7.85 g/cm³ = 7850 kg/m³`

```
单件重量(kg) = 体积(cm³) × 密度(g/cm³) ÷ 1000
合计重量(kg) = 单件重量 × 件数（弹窗展示，可不写入 BOM）
```

---

## 各型材公式（尺寸先统一成 mm）

下面 `ρ` = 密度（g/cm³）。先算体积(cm³)，再：`单件重量 = 体积 × ρ ÷ 1000`。

### 1. 圆钢

直径 D、长 L

```
体积 = π × (D/2)² × L ÷ 1000
单件重量(kg) = 体积 × ρ ÷ 1000
```

### 2. 钢板 / 板材

长 L、宽 W、厚 T

```
体积 = L × W × T ÷ 1000
单件重量(kg) = 体积 × ρ ÷ 1000
```

### 3. 圆管

外径 D、长 L；内径 d 或壁厚 t

```
体积 = π × ((D/2)² − (d/2)²) × L ÷ 1000
单件重量(kg) = 体积 × ρ ÷ 1000
```

### 4. 方管

外宽 A、外高 B、壁厚 t、长 L

```
内宽 = A − 2t，内高 = B − 2t
体积 = (A×B − 内宽×内高) × L ÷ 1000
单件重量(kg) = 体积 × ρ ÷ 1000
```

### 5. 其它型材

| 型材   | 算法                           |
| ------ | ------------------------------ |
| 方钢   | 宽 × 高 × 长 → 体积 → ×密度    |
| 扁钢   | 宽 × 厚 × 长 → 体积 → ×密度    |
| 六角钢 | 对边距截面 × 长 → 体积 → ×密度 |

## 常用密度

| 材料   | g/cm³ | kg/m³ |
| ------ | ----- | ----- |
| 碳钢   | 7.85  | 7850  |
| 不锈钢 | 7.93  | 7930  |
| 铝     | 2.7   | 2700  |
| 铜     | 8.96  | 8960  |
| 铸铁   | 7.2   | 7200  |

可选「自定义」密度。后续可在物料主数据维护密度，选型自动带出。

---

## 举例

碳钢板：1000×1000×10 mm，密度 7.85

```
体积 = 1000×1000×10÷1000 = 10,000 cm³
单件重量 = 10,000×7.85÷1000 = 78.5 kg
```

确认后：下料尺寸带长宽厚；**单位用量 = 78.5**（kg/件）。父项做 2 台则领料约 157 kg（再乘损耗等规则）。

---

## 和按长/按面积下料的区别

| 场景                          | 下料尺寸     | 单位用量含义            | 领料扣料             |
| ----------------------------- | ------------ | ----------------------- | -------------------- |
| 按长/按面积（型材、板材常规） | 长、宽、厚等 | 件数或米/㎡用量         | 按米、㎡等库存单位   |
| **重量计算**（本功能）        | 同样回填尺寸 | **kg/件（算出的单重）** | **按 kg 领料、扣料** |

不要混用：走了「重量计算」并确认的行，应以回填的 **单位用量（kg）** 作为领料依据，而不是再用 blankLength 去当领料主数量（除非业务另定双轨规则）。

---

## 验收要点

1. 功能参数「重量计算」关 → 无该页签；开（默认）→ 可选型材、出 kg（BOM 下料与采购订货尺寸弹窗共用）
2. 公式与上表一致（可抽测圆钢、板材）
3. **确认后**：下料尺寸有值；**单位用量 = 单件重量（kg）**（订货尺寸确认只回填尺寸）
4. 工单/领料展开该行时，需求量按 **单位用量（kg）** 参与计算，库存按重扣减
5. 尺寸未填全或密度无效时，不允许确认或给出明确提示

---

## 实现备注（研发）

- 重量页确认：`pieceWeightKg` → `line.unitQty`；尺寸仍写 `blankSize`；清空 `blankLength`/`blankArea` 避免与按重领料混算。
- 双单位按重（`per_piece_weight` / kg 库存）：领料需求 = `unitQty × 排产 × (1+损耗)`，见 `materialReqEbom.enrichVariableLengthFields`。
- 物料主数据密度自动带出为增强项，非阻塞首版。
