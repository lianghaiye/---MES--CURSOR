## PP-151-01 生产计划生成单据弹窗（加工工单 / 外协工单 / 采购申请）

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
生产计划展开 EBOM 后，需对自制件生成加工工单、对外协件生成外协工单、对外购件生成采购申请。原弹窗交互与列配置不统一，缺少与工单生成弹窗一致的可编辑体验。

**功能描述**

1. **三个弹窗统一交互**（对齐加工工单弹窗样式）：列设置、列宽拖拽、行内点击编辑、合计行、删除行。
2. **加工工单**（`GenerateWorkOrderModal`）：按整单**自制件**筛选；左侧冻结列：序号、名称、编码；操作列固定右侧；「材质」后增加**图号**列；每行保存生成一张加工工单。
3. **外协工单**（`GenerateOutsourceWorkOrderModal`）：按当前工作项**外协件**筛选；「计划时间」改为**期望到货时间**（单日期 `expectedArrivalDate`）；每行保存生成一张外协工单。
4. **采购申请**（`GeneratePurchaseRequisitionModal`）：按当前工作项**外购件**筛选；**一张采购申请、多行明细**合并保存。
5. **空数据不弹窗**：无可生成数据时仅 `message.info/warning` 提示，不打开空弹窗。

**业务规则**

- 加工工单取整单参与计划的自制/组装物料；外协/采购取当前激活工作项对应供应型态物料。
- 指定供应商开启时，生成采购申请前校验供方单位已填（沿用原有规则）。
- 列显隐配置独立持久化（localStorage），互不影响。

**验收标准**

- [ ] 三个弹窗样式与交互一致：列设置、冻结列、合计行、行内编辑、删除可用。
- [ ] 加工工单含图号列；外协工单为期望到货时间（单日期）；采购申请一单一多行。
- [ ] 筛选范围正确（自制/外协/外购）；无数据时不弹出空窗。
- [ ] 保存后分别写入工单/外协工单/采购申请 store，数据字段完整。

## PP-151-02 生产计划 EBOM 物料清单打印

- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
生产计划现场需打印 EBOM 物料清单备料；与产品 BOM 打印为不同场景，需额外展示库存数、需求数，且打印字段可独立配置。

**功能描述**

1. **打印入口**：计划详情「收起详情」与「退出全屏」之间增加**打印**按钮（普通详情与全屏工具栏均可见）。
2. **打印弹窗**：复用 `BomPrintModal`，支持数量、纸张、方向、预览/直接打印；**直接打印**选项无默认高亮。
3. **生产计划专用列**：在「单位用量」后追加**库存数、需求数**（按 EBOM 物料编码匹配工作项物料行）；与产品 BOM 打印列配置**完全分离**。
4. **设置打印项**：打印弹窗与预览页均提供按钮，打开列配置抽屉，可调整显隐与排序；配置持久化至 `production-plan-print`。
5. **预览页**：新标签打开 EBOM 清单预览，支持打印与设置打印项；修改列配置后预览表格即时刷新。

**业务规则**

- 未选计划、未展开工作项、工作项「设计中」或无 EBOM 数据时拦截并提示。
- 产品 BOM 打印不包含库存数/需求数，不读取生产计划打印列配置。
- 打印数据取自工作项 `ebomSnapshot`（treeNodes + lineItems）及物料库存/需求映射。

**验收标准**

- [ ] 详情页与全屏均可打开打印；校验提示符合规则。
- [ ] 生产计划打印清单含库存数、需求数；产品 BOM 打印不含上述列。
- [ ] 设置打印项在弹窗与预览页均可用，配置持久化且预览即时生效。
- [ ] 直接打印选项样式与其他操作项一致（无默认蓝色高亮）。
