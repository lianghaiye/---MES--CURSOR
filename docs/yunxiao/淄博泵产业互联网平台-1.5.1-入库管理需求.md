## IB-151-01 入库单新增/编辑/详情优化

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
原入库单新增表单字段与明细列不完整，缺少按 BOM 添加、列显隐、行级编辑及与出库单一致的仓库联动逻辑；详情页按钮与明细展示需与业务状态对齐。

**功能描述**

### 1. 新增/编辑入库单弹窗（1400px）

**表头字段**

- **入库单号**：可手填，不填则系统自动生成（去掉「生成编号」按钮）
- **入库类型**（必填）、**入库日期**
- **入库仓库**（选填，逻辑与出库单表头/明细仓库一致）
- **供应商**、**送货日期**（供应商后）、**经手人**、**发票号码**、**备注**
- 移除：物品类型、原表单中独立的送货日期重复项（已整合至供应商后）

**入库仓库联动**

- 表头入库仓库选填；新建明细默认表头仓库
- 表头修改后弹窗确认是否同步明细仓库

**明细工具栏**

- **添加物品**
- **按 BOM 添加**（仅添加 BOM 下级结构）
- **列显隐**

**明细列**

物品编码、物品名称、规格型号、规格属性、**材质**、**图号**、入库数量、入库仓库、重量、单位、单价、总价、当前库存数、当前仓库数量、来源（选填）、关联业务单据（选填）、操作

- 行操作：**编辑**、**复制**、**删除**
- 行编辑弹窗可维护来源、关联业务单据及数量/仓库/单价等

### 2. 入库单详情页

**基本信息**：展示入库单号、类型、状态、入库日期、送货日期、仓库、供应商、发票、经手人及审批/确认信息等。

**按钮（按状态）**

| 状态 | 按钮 |
|------|------|
| 待审批 | 通过、拒绝、返回列表 |
| 待处理 | 确认入库、编辑、删除 |
| 已完成 / 已拒绝 | 返回列表 |

**明细表**

- 与新增/编辑共用 `inboundDetailLineColumns`（含材质、图号）
- 库存类字段经 `enrichInboundLine` 计算展示

### 3. 数据与状态

- 入库单状态：**待审批、待处理、已完成、已拒绝**
- 成品入库且关联小程序任务时，新建默认「待审批」；审批通过后为「待处理」
- 入库单号空值保存时 `generateInboundNo` 自动生成
- `updateInboundOrder` 支持编辑保存

**业务规则**

- 子模态置于父弹窗外部，避免选择确认失效
- 明细 helper 负责库存、总价、BOM 展开与行合并
- 出库单明细同步增加材质、图号字段（与入库对齐）

**验收标准**

- [ ] 表头字段完整，入库单号可空自动生成，送货日期在供应商后
- [ ] 入库仓库选填及同步明细确认正确
- [ ] 添加物品、按 BOM 添加、列显隐、行编辑/复制/删除可用
- [ ] 明细含材质、图号、来源、关联业务单据
- [ ] 详情页按钮按待审批/待处理/已完成/已拒绝正确展示
- [ ] 确认入库后状态为已完成并更新库存

**涉及文件（主要）**

- `InboundOrderFormModal.vue`、`InboundLineEditModal.vue`
- `InboundOrderDetailView.vue`
- `inboundOrderStore.js`、`inboundLineHelpers.js`、`inboundLineColumns.js`
- `inboundOptions.js`、`inboundOrders.js`
- `warehouseItemPicker.js`
