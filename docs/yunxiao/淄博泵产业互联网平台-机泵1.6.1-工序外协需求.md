## 一、工序配置（NYVC-2362）

- 极简报工 / 下发即报工：工序操作仅可配下料、质检、外协、拆解、拆解质检。
- 「下料」作为独立开关并入工序操作区；列表「下料工序」改为「工序配置」标签汇总。

## 二、生产工单 / 总装工单（NYVC-2363）

- 下发 / 详情 / 打印统一「工序配置」列。
- 可外协工序可发起工序外协；数量受可外协剩余约束；状态与外协量回写。
- 详情外协订单 Tab 展示关联单并可跳转。

## 三、外协订单（NYVC-2364）

- 外协类型：整件外协 / 工序外协；列表筛选与工序展示。
- 工序外协创建绑定工单工序；发料优先投料，无投料发产品本身且不展开 BOM。
- 收货/入库回写工单工序外协状态。
