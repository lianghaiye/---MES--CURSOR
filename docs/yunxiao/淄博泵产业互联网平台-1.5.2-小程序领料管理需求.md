## 公共能力说明（MR-152-01 / MR-152-02 共用）

### 领料管理首页

1. 提供两个入口：**根据工单领料**、**快速领料**。
2. 展示「我的领料申请」列表：申请单号、领料方式（工单领料 / **批量领料** / 快速领料）、关联工单（如有）、出库单号、出库状态、申请时间。
3. 支持下拉刷新；点击卡片进入申请详情。

### 申请详情

1. 展示申请单头：申请单号、领料方式、关联工单/产品（**批量领料时展示关联工单数量及工单清单**）、领用车间、领入仓库（工单领料）、出库单号、申请人、时间、备注。
2. 展示领料明细：物料编码/名称、规格、领料仓库、库存、领料数量；**批量领料时明细行展示来源工单及数量溯源标签**。
3. **标准模式**：提示提交后已在 WEB「出库管理」生成「领料出库」单，状态为待处理，需仓管审批后出库。
4. **极简报工模式**：无审批、无收货确认环节，出库完成后即视为领料完成。

### WEB 端联动

1. 小程序提交领料申请后，自动在 WEB「出库管理」生成 **领料出库** 单，来源标识 **小程序**。
2. 出库单携带：领用车间、关联工单号（工单领料 / **批量领料可关联多个工单**）、领入仓库（工单领料）、明细行（物料、数量、领料仓库、库存等）。
3. **标准模式**：出库单状态 **待处理**，需仓管审批 → 确认出库后，小程序申请详情同步展示出库状态。
4. **极简报工模式**（见 MR-152-02 §6）：跳过审批与收货确认，出库流程简化；工单完成后自动扣减关联领料库存。

### 物料明细卡片（共用组件）

1. 展示：物料名称、编码、规格、材质、图号。
2. **领料仓库**（出库来源）：可选原材料仓 / 成品仓 / 半成品仓；标注「出库来源」。
3. **当前库存**：按所选领料仓库查询；库存不足领料数量时高亮提示。
4. **领料数量**：步进器 + 手输；工单领料 EBOM 行展示「建议数量」。
5. 不展示 EBOM / 手工来源标签（内部字段，不对一线工人展示）。

### 添加物料弹窗（共用组件）

1. 底部弹层选择物料，支持搜索：**编码 / 名称 / 图号**。
2. 列表展示物料名称、编码、规格、图号；点击「添加」加入明细。
3. 已存在同编码物料时，数量 +1。

### 领料仓库默认规则（行级，两条需求共用）

| 物料类型 | 默认领料仓库 |
| -------- | ------------ |
| 物料     | 原材料仓     |
| 产品     | 成品仓       |

行级可单独修改，**不与领入仓库联动**。

## MR-152-01 快速领料

- **云效标题建议**：`小程序--领料管理--MR-152-01 快速领料`
- **优先级**：P1
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：原型已实现（待正式接口联调）

**背景**  
现场存在临时补料、试制领料等 **无工单** 场景，工人需快速手工选料、指定出库仓库并提交领料申请，由仓管在 WEB 端审批出库。

**功能描述**

### 1. 发起快速领料

1. 从领料管理首页进入「快速领料」。
2. 填写 **领用车间**（默认当前用户所属工厂/车间，可修改）。
3. 填写 **备注**（选填）。

### 2. 维护领料明细

1. 点击「+ 添加物料」打开物料选择弹窗。
2. 支持按编码、名称、**图号** 搜索；数据来源于产品/物料主数据。
3. 每条明细可修改：**领料仓库**、**领料数量**；展示当前库存。
4. 支持删除明细行；同编码重复添加时合并数量。
5. 至少 1 条明细且每条数量 > 0 方可提交。

### 3. 提交与结果

1. 点击「提交领料申请」，生成小程序领料申请记录。
2. 同步生成 WEB「领料出库」待处理单（来源：小程序）。
3. 跳转申请详情页，展示出库单号与状态。

**业务规则**

- 快速领料 **不关联生产工单**，无 EBOM 自动带出。
- 快速领料 **无领入仓库** 字段（仅工单领料需要领入线边仓）。
- 领料仓库按物料类型智能默认，行级可改。
- 领料数量须大于 0；提交前校验明细非空。

**验收标准**

- [ ] 首页可进入快速领料，填写车间与备注
- [ ] 添加物料弹窗支持编码/名称/图号搜索
- [ ] 明细可改领料仓库、数量，展示库存
- [ ] 提交成功生成申请单与 WEB 出库单（来源=小程序，状态=待处理）
- [ ] 详情页信息完整，出库状态可随 WEB 流转更新

## MR-152-02 工单领料（含批量领料）

- **云效标题建议**：`小程序--领料管理--MR-152-02 工单领料`
- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：原型已实现（含单工单领料、**批量合并领料**、按车间匹配线边仓，待正式接口联调）
- **云效编号**：NYVC-1365

**背景**  
生产工人需按 **生产工单** 领料：系统自动带出 EBOM 下级物料及建议数量，同时需明确 **从哪个仓库出库**（领料仓库）以及 **领入哪个线边仓**（领入仓库）。WEB 端仓库管理已支持按 **所属工作中心** 配置不同线边仓，小程序需对接该配置。

同一销售订单或同一批次往往包含 **多个生产工单**，现场希望 **一次合并领料**，减少重复出库与填报。本需求在单工单领料基础上，支持 **多工单勾选 → EBOM 物料合并 → 一次提交批量领料申请**。

**功能描述**

### 1. 选择工单（单选 / 多选 / 按销售订单）

1. 从领料管理首页进入「根据工单领料」→ 工单选择页。
2. 页顶提示：**选 1 个工单为单工单领料，选多个为批量合并**。
3. 提供两个 Tab：
   - **工单列表**：按工单卡片多选；
   - **按销售订单**：按销售订单分组，点击进入后勾选该订单下工单。
4. 支持搜索：工单号、产品名称、**图号**、**销售订单号**；支持按 **工作中心** 筛选。
5. 工单卡片展示：工单号、工单类型、产品名称/编码、**材质**、**图号**、**销售订单号**、计划数量、车间、状态。
6. 快捷操作：
   - **全选当前列表**：勾选 / 取消当前筛选结果全部工单；
   - **按订单全选**：搜索框输入销售订单号时可用，一键选中匹配订单的全部工单。
7. 底部栏展示「已选 N 个工单」；按钮文案：
   - 选 1 个 →「去领料」→ 进入 **单工单领料** 页；
   - 选 ≥2 个 →「合并领料 (N)」→ 进入 **批量领料** 页。
8. 「按销售订单」Tab：展示销售订单号、工单数量、产品摘要、车间；点击后底部弹层勾选该订单下工单，支持全选，确认后同上跳转。

### 2. 单工单领料（选 1 个工单）

1. 顶部展示工单摘要：工单号、产品、计划数量、车间。
2. **领用车间**：默认工单车间，可修改。
3. **领入仓库**：
   - 含义：物料从下方「领料仓库」出库后，**领入的目标线边暂存仓**。
   - 旁注说明：「物料从下方「领料仓库」出库后，领入至此线边暂存」。
   - **默认值**：根据领用车间匹配线边仓；有匹配则自动选中第一个，**无匹配则不设默认值**。
   - 下拉选项始终为 **全部线边仓**，用户可手工选择；未匹配时提示「请手动选择领入仓库」。
4. **备注**（选填）。

### 2.1 按车间匹配线边仓（核心逻辑，单工单 / 批量共用）

WEB「仓库管理」已支持为仓库配置 **仓库类型**、**所属工作中心**。小程序工单领料对接规则如下：

**匹配条件（同时满足）**

1. `仓库类型 = 线边仓`
2. `所属工作中心` 与 **领用车间** 一致，或通过别名映射命中（见下表）
3. 仓库处于启用状态

**车间别名映射（示例）**

| 领用车间（小程序）  | 可匹配的 WEB 所属工作中心 |
| ------------------- | ------------------------- |
| 机加车间            | 机械中心、机泵            |
| 装配车间 / 总装车间 | 组装中心                  |
| 拆解车间 / 质检车间 | 默认工厂                  |

**交互规则**

1. 进入工单领料页：领用车间默认取工单车间 → 有匹配线边仓时自动默认选中第一个。
2. 用户修改领用车间（失焦后）：有匹配则更新默认值；**无匹配则清空默认值**，由用户从全部线边仓中手选。
3. 领入仓库下拉选项 = **全部线边仓**（不限于当前车间）。
4. **领入仓库与领料仓库不联动**（领入=线边暂存目标，领料=出库来源）。

**数据示例（WEB 仓库管理）**

| 仓库名称 | 仓库类型 | 所属工作中心 |
| -------- | -------- | ------------ |
| 库线边仓 | 线边仓   | 机械中心     |
| 原料仓   | 线边仓   | 默认工厂     |

→ 领用车间为「机加车间」时，默认领入仓库为「库线边仓」；领用车间为「默认工厂」时，默认领入「原料仓」。

**存储对接**

- 小程序读取与 WEB 共用的 `i_doms_warehouses` 本地存储（正式环境改为仓库管理接口）。
- 实现模块：`warehouseBridge.js` → `getReceiveWarehouseOptions` / `resolveDefaultReceiveWarehouse`。

### 3. 批量领料（选 ≥2 个工单）

1. 顶部摘要卡片：已选工单数、销售订单（单一订单显示号，多订单显示「多订单」）、可展开 **工单清单**（工单号、产品、计划数量）。
2. **领用车间**：默认取已选工单中 **出现次数最多的车间**；涉及多个车间时顶部提示「涉及多个车间，请确认领用车间」。
3. **领入仓库**：规则同 §2.1；修改领用车间后重新匹配默认线边仓。
4. **备注**（选填）。
5. 若部分工单 **无 EBOM / 解析为空**，顶部警告列出工单号，不影响其他工单物料合并；用户可手工补料。
6. 若已选工单归属 **多个销售订单**，提示「涉及多个销售订单」（不阻断提交）。

### 4. 领料明细（EBOM 带出 + 手工增补）

**单工单领料**

1. 进入页面后，根据工单 EBOM **自动解析**下级物料明细（数量 = 单位用量 × 工单计划数量）。
2. 明细标题为「领料明细」，支持「+ 添加物料」手工加料（弹窗同 MR-152-01）。
3. 每条明细：规格、材质、图号；**领料仓库**、**当前库存**、**领料数量**（默认建议量，展示「建议 xx」）；可删除行。
4. 同编码物料合并时累加数量。

**批量领料**

1. 分别解析每个已选工单的 EBOM 明细，再按 **物料编码合并**：
   - **领料数量** = 各工单同物料数量之和；
   - **建议数量**同步累加；
   - 保留 **来源工单溯源**（内部字段 `sourceWorkOrders`：工单号 + 分摊数量）。
2. 明细标题为「**合并领料明细**」，其余编辑能力同单工单（领料仓库、库存、数量、手工加料、删除行）。
3. 申请详情页：明细行展示来源工单标签（如 `WO001 ×20`、`WO002 ×15`）；单头展示关联工单数及工单清单。

### 5. 提交与结果

**单工单领料**

1. 校验：至少 1 条明细、数量 > 0、领入仓库已选。
2. 提交后生成领料申请（方式 = **工单领料**），关联单个工单号/产品。
3. 同步 WEB「领料出库」单：携带工单号、领用车间、**领入仓库**、明细及行级领料仓库。
4. 跳转领料管理列表页。

**批量领料**

1. 校验同单工单；至少 1 条合并明细。
2. 提交后生成领料申请（方式 = **批量领料**），关联多个工单 ID 及工单清单快照。
3. 同步 WEB「领料出库」单：关联工单号取来源工单（单行单工单则带该工单号，多工单合并行带多个工单号摘要）；其余字段同单工单。
4. 跳转领料管理列表页；列表卡片展示「批量领料」及工单数量摘要。

### 6. 极简报工模式差异化（WEB + 小程序联动）

> **触发条件**：系统「业务规则 → 生产模式 = 极简报工」。以下规则仅在该模式下生效；标准模式仍走完整审批与投料配置流程。

#### 6.1 WEB · 工单下发隐藏投料

1. WEB 工单下发页 **工序列表不再展示「投料信息」列**。
2. 下发时可不为工序维护投料明细，界面更简洁，便于演示与现场快速下发。

#### 6.2 下发无投料仍可领料

1. 工单下发时 **未配置工序投料**，工人仍可按工单正常发起 **工单领料 / 批量领料**。
2. 领料明细 **仍以各工单 EBOM 为准** 自动带出建议数量，**不依赖** 工序投料配置。
3. 无 EBOM 或解析为空时，仍支持手工添加物料领料（同 §4）。

#### 6.3 领料出库免审批

1. 小程序提交领料申请（工单领料 / **批量领料** / 快速领料）后，WEB「出库管理」生成的 **领料出库单跳过审批环节**。
2. 出库单生成后可直接进入 **待出库 / 确认出库** 流程（或按配置自动确认出库），无需仓管先审批。
3. 小程序申请详情同步展示出库状态，无「待审批」中间态。

#### 6.4 领料不需要收货确认

1. 领料全流程 **取消收货确认环节**。
2. 出库确认完成后即视为领料完成，工人/仓管 **无需二次确认收货**。
3. 小程序详情页不展示「待收货 / 确认收货」等状态与操作入口。

#### 6.5 工单完成自动扣减领料库存

1. 极简报工模式下，生产工单状态变为 **完成** 时，系统自动 **扣减该工单关联的已领料库存**（含通过 **批量领料** 出库、且明细溯源包含该工单的数量）。
2. **扣减范围**：该工单下已通过领料申请 / 出库单实际出库的物料及数量（按出库明细汇总）。
3. **扣减对象**：对应领料仓库（出库来源仓）的库存台账。
4. **未领部分不扣减**：EBOM 中尚未领料或未出库的物料，不参与扣减。
5. **扣减时机**：工单完工（状态 → 完成）时一次性触发；若同一工单多次领料，按累计已出库数量扣减。

**业务规则**

| 字段     | 层级   | 含义                     | 默认值                     | 是否联动             |
| -------- | ------ | ------------------------ | -------------------------- | -------------------- |
| 领入仓库 | 单头   | 物料领入车间的线边暂存仓 | 当前车间配置的线边仓       | **不**同步到领料仓库 |
| 领料仓库 | 明细行 | 物料出库来源仓           | 物料→原材料仓；产品→成品仓 | 各行独立，可修改     |

| 领料方式 | 单头 | 工单领料 / **批量领料** / 快速领料 | — | — |

- 修改领用车间时，**重新匹配**该车间下的线边仓作为领入仓库默认值（已填明细的领料仓库不变）。
- 领入仓库与领料仓库 **禁止**一键同步（业务含义不同）。
- EBOM 来源为内部标识，界面不展示 EBOM 标签；批量合并后保留来源工单溯源（详情页展示）。
- **批量领料**：同编码物料跨工单合并数量；手工加料与 EBOM 行可再次合并。
- **极简报工模式**下：工单下发可不维护投料；领料出库免审批、免收货确认；工单完成后自动扣减已领料库存（见 §6）。

**数据来源**

- 工单列表 / EBOM：生产工单接口。
- 线边仓选项：WEB 仓库管理（`仓库类型 = 线边仓`，`所属工作中心` 与领用车间匹配，含别名映射）。
- 领料仓库选项：原材料仓、成品仓、半成品仓（或按仓库类型过滤）。
- 库存：库存接口，按 `领料仓库 + 物料编码` 查询。
- 物料搜索：产品/物料主数据（含图号）。

**验收标准**

- [ ] 工单选择页支持多选；选 1 个进入单工单领料，选多个进入批量领料
- [ ] 支持「工单列表 / 按销售订单」Tab、全选当前列表、按订单全选
- [ ] 工单选择页可搜索工单号/产品名称/图号/销售订单号，卡片含材质、图号、销售订单号
- [ ] 单工单：EBOM 物料自动带出，领入/领料仓库可编辑
- [ ] 批量：多工单 EBOM 按物料编码合并，明细保留来源工单溯源
- [ ] 批量：部分工单无 EBOM 时有警告提示，可手工补料后提交
- [ ] 切换领用车间后，领入仓库按新车间线边仓配置更新
- [ ] 明细行领料仓库、库存、数量可编辑；领入仓库与领料仓库不联动
- [ ] 提交后跳转领料管理列表；列表展示领料方式（含批量领料）
- [ ] 详情页：批量申请展示工单清单及明细来源工单标签
- [ ] WEB 出库单含工单号、领入仓库、来源=小程序
- [ ] 未匹配到默认线边仓时提示用户手选，且可正常提交
- [ ] **极简报工**：WEB 工单下发工序列表隐藏「投料信息」列
- [ ] **极简报工**：工单未配置投料仍可按 EBOM 发起工单/批量领料
- [ ] **极简报工**：领料出库单跳过审批，无收货确认环节
- [ ] **极简报工**：工单完成后自动扣减该工单已领料出库的库存（含批量领料溯源数量）
