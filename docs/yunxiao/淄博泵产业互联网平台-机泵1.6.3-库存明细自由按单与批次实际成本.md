| 云效项目 | 淄博泵产业互联网平台      |

---

## 一、背景

1. **数量**：业务需要在库存明细一眼区分「自由在库」与「按单在库」，避免只看现存量/可用导致误解（「可用」= 现存量 − 销售软占用，≠ 自由在库）。
2. **金额**：原「库存总金额 = 现存量 × 主数据标准单价」不合理——物料与人工成本浮动，标准单价仅适合计划/报价，不能代表库存金额。需改为 **批次实际成本** 汇总。

---

## 二、需求范围

### INV-163-01A 库存明细数量分列

| 列       | 口径                                          |
| -------- | --------------------------------------------- |
| 现存量   | 仓库 + 物料台账数量                           |
| 自由在库 | 未挂销售订单的在库批次数量合计                |
| 按单在库 | 已挂销售订单的在库批次数量合计                |
| 软占用   | 销售审核软占用（物料级数量账）                |
| 可用     | 现存量 − 软占用（保留，需与「自由在库」区分） |

- 列表、导出需包含上述数量列。
- 批次层（按批次查询 / 查看批次）继续支持按「自由备货 / 按单」筛选与展示。

### INV-163-01B 库存金额按批次实际成本

| 项         | 口径                                                                                   |
| ---------- | -------------------------------------------------------------------------------------- |
| 批次成本   | 确认入库时写入批次 `unitCost`（每库存单位）：优先 行总价÷库存数量，否则用不含税/行单价 |
| 库存总金额 | Σ（在库批数量 × 该批 unitCost）                                                        |
| 成本单价   | 有成本的在库批加权平均单价                                                             |
| 无批成本时 | 显示「—」，**禁止**用主数据标准单价冒充库存金额                                        |

- 余料入库继承原批成本。
- 按批次查询 / 查看批次展示「批次成本」。
- 导出字段与列表口径一致。

### 非目标（本期可不做）

- 成品/半成品工单成本归集后回写入库批成本（可后续单独立项）。
- 采购结算冲差后回写批成本。
- 移动平均 / FIFO 出库成本结转会计凭证。

---

## 三、验收标准

- [ ] 库存明细主表可见：现存量、自由在库、按单在库、软占用、可用；自由+按单与现存量在批次齐全时逻辑一致（允许演示数据略有差异时有说明）。
- [ ] 导出包含自由在库、按单在库及成本相关列。
- [ ] 采购等入库确认后，新建批次带 `unitCost`；库存明细成本单价/总金额按批汇总，不再等于「现存量 × 标准单价」。
- [ ] 无批成本时金额为「—」，不用标准单价填充。
- [ ] 批次抽屉/按批次查询可见批次成本。
