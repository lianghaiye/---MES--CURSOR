## OB-151-01 出库单新增/编辑/详情与列表优化

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
原出库管理新增/编辑能力不完整，明细字段与交互与业务要求不一致；列表筛选、状态流转、按 BOM 添加、列显隐等能力缺失，影响仓管日常出库作业。

**功能描述**

### 1. 列表页（出库管理）

1. **筛选**：移除「物品类型」；新增「出库时间」筛选（支持日/月/年粒度 + 区间）。
2. **工具栏**：「新增」打开出库单表单弹窗（非占位）。
3. **列表列**：调整默认列与展示（含出库数量合计、状态色等）。
4. **操作列**（按状态）：
   - **待处理**且需审批类型（领料出库/发料出库）：审批、编辑、删除
   - **待处理**其他类型：编辑、删除
   - **待出库**：确认出库、编辑、删除等（与详情一致）
   - 其他状态：详情

### 2. 新增/编辑出库单弹窗（1400px）

**表头字段**

- 出库单号：可手填，留空保存时自动生成（无「生成编号」按钮）
- 出库类型、出库时间、出库仓库（选填）
- 经手人、领用部门、所在车间、销售单号、备注等

**出库仓库联动**

- 表头出库仓库选填；新建明细行默认带入表头仓库
- 表头仓库修改后，若已有明细，弹窗确认「是否同步修改明细仓库？」

**明细工具栏**

- **添加物品**（原「选择物料」）
- **按 BOM 添加**：打开 BOM 选择 → 高级选择产品/物料；用量系数标签为「出库数量」；确定后仅添加 BOM **下级结构**（不含顶级物料）
- **列显隐**

**明细列（默认顺序，支持显隐）**

序号、物品编码、物品名称、规格型号、规格属性、**材质**、**图号**、当前库存数、当前仓库数量、仓库、出库数量、重量、条码/批次号、单位、单价、总价、来源（只读）、关联业务单据（只读）、操作

- 总价可编辑，与单价/数量联动
- 来源、关联业务单据不在行编辑弹窗中维护（表格只读展示）
- 行操作：**编辑**、**复制**、**删除**

**行编辑弹窗**

- 产品信息预览区；仓库、出库数量、成本金额/单价等字段
- 与新增表单字段对齐

### 3. 出库单详情页

**基本信息**：清理冗余字段，保留业务关键信息。

**按钮（按状态）**

- **待处理**：审批（仅领料/发料出库）、编辑、删除、返回列表
- **待出库**：确认出库、编辑、删除、发起质检（如有）、返回列表
- **已完成/已拒绝等**：返回列表

**明细表**

- 与新增/编辑共用列定义（含材质、图号）
- 底部**合计行**：项数、出库数量、总价

### 4. 状态与审批

出库单状态：**待处理、待出库、待申领人确认、已拒绝、已出库、拒绝领料**（共 6 种）。

- 仅 **领料出库、发料出库** 在「待处理」时需审批，通过后进入「待出库」
- 支持 `updateOutboundOrder` 编辑保存

**业务规则**

- 子模态（选择物品、按 BOM 添加、行编辑）置于父弹窗外部，避免确认无响应
- 库存数、仓库库存数、单价总价由 helper 统一计算 enrichment
- BOM 展开合并同物料行

**验收标准**

- [ ] 列表筛选含出库时间，无物品类型；新增/编辑/审批/删除按状态正确展示
- [ ] 表头出库仓库选填及同步明细确认逻辑正确
- [ ] 添加物品、按 BOM 添加、列显隐、行编辑/复制/删除可用
- [ ] 明细含材质、图号；总价可改；来源/关联业务单据只读
- [ ] 详情页按钮、明细合计行与列表状态一致
- [ ] 领料/发料出库审批流：待处理 → 待出库 → 已出库

**涉及文件（主要）**

- `OutboundManagementView.vue`、`OutboundOrderFormModal.vue`、`OutboundLineEditModal.vue`
- `OutboundOrderDetailView.vue`
- `outboundStore.js`、`outboundLineHelpers.js`、`outboundLineColumns.js`
- `outboundOptions.js`、`outboundOrders.js`
- `AddByBomModal.vue`、`SelectWarehouseItemModal.vue`
