## PM-151-10 新增产品/物料零部件属性与表单排版优化

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
产品/物料新增编辑表单在补充「是否组装件」、零部件属性联动后，基本信息 Tab 出现开关与输入框混排、列对齐混乱；同时业务要求零部件类产品属性取值范围收窄，物料侧开启「产品物料」时需与产品侧规则一致，且物料「可生产」应固定不可取消。

**功能描述**

### 1. 产品属性命名统一

- 原「标准-成品零部件 / 定制-成品零部件」统一为 **标准零部件 / 定制零部件**。
- 历史数据加载时自动迁移为新名称（兼容旧值）。

### 2. 新增产品 — 零部件联动

1. 页头勾选 **零部件** 时：
   - **产品属性** 自动设为 **标准零部件**；
   - 下拉框 **仅可选**「标准零部件 / 定制零部件」；
   - **产品物料** 由联动自动开启（与 PM-151-03 一致），选项区不再重复展示「产品物料」开关。
2. 取消 **零部件** 时，产品属性恢复为 **标准产品**，并清除「是否组装件」。
3. 非零部件时，产品属性下拉 **不展示** 标准/定制零部件选项。
4. 零部件或属性为零部件类型时，展示 **是否组装件** 开关（选项区独立一行，浅灰背景）。

### 3. 新增产品 — 基本信息排版

- 基本信息 Tab 采用规整 **三列网格**：编码/条码/类别 → 属性/规格/图号 → 材质/重量/库存单位 → 标准规范。
- 开关类字段（是否组装件、产品物料）合并为 **独立选项行**，避免与输入框同列造成留白错位。
- 表单标签宽度统一（84px），长文本字段标签 96px。

### 4. 新增物料 — 可生产固定

- 页头 **可生产** 默认勾选且 **disabled**，不可取消（与产品「可销售」固定逻辑一致）。
- 保存时固定写入 `canProduce: true`。

### 5. 新增物料 — 产品物料区块

1. 开启 **产品物料** 后展示 **产品物料信息** 区块（浅灰背景）：
   - **产品属性**：仅可选「标准零部件 / 定制零部件」，默认 **标准零部件**；
   - **产品类别**：必选；
   - **是否组装件**：开关展示。
2. 关闭产品物料时清除「是否组装件」。
3. 开启产品物料时「可销售」仍与产品物料联动（PM-151-04）。

### 6. 新增物料 — 基本信息排版

- 三列网格：编号/条码/类别 → 类型/供应/规格 → 图号/材质/重量 → 库存单位。
- **产品物料** 开关独立选项行；展开后的产品物料字段置于独立区块，不与基础字段混排。

### 7. 数据同步

- 产品/物料互转（`productMaterialMap`）同步 `isAssemblyPart` 字段。
- 零部件属性判断工具：`isPartProductAttribute`、`normalizePartProductAttribute`（`productInfoOptions.js`）。

**业务规则**

- 零部件产品：`isPart` ↔ `isProductMaterial` 联动；属性仅限标准/定制零部件。
- 是否组装件仅在零部件属性场景下有效，保存时非零部件场景写 `false`。
- 物料可生产不可编辑，始终为 true。

**涉及文件**

- `ProductFormModal.vue`
- `MaterialFormModal.vue`
- `productInfoOptions.js`
- `productMaterialMap.js`
- `masterDataMigrate.js`

**验收标准**

- [ ] 勾选产品「零部件」后，属性自动为「标准零部件」，且仅能改为「定制零部件」。
- [ ] 产品/物料表单基本信息 Tab 列对齐整齐，开关不在输入列中错位。
- [ ] 产品零部件场景展示「是否组装件」并可保存回显。
- [ ] 物料开启「产品物料」后，属性仅标准/定制零部件，并展示「是否组装件」。
- [ ] 物料「可生产」固定勾选且不可取消，保存后仍为 true。
- [ ] 历史「标准-成品零部件」等旧属性名加载后显示为新名称。
