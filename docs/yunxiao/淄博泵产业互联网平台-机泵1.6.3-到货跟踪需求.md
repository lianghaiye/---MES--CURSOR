## 一、背景与目标

关键件到货需要在生产侧持续跟踪：哪些已入库、哪些采购仍待入，并支持从已到货一键去领料；入库确认后同步工作台「关键件到货」提醒。

**仅统计/展示主数据标记为关键件的物料**（产品/物料 `isKeyPart` / `production.isKeyPart`）。

---

## 二、入口与导航

| 入口                         | 行为                                                                  |
| ---------------------------- | --------------------------------------------------------------------- |
| 生产管理 → **到货跟踪**      | 页面 `/production/arrival-tracking`                                   |
| 工作台「关键件到货」卡片点击 | 进入本页「已到货」Tab（`?tab=arrived`），**不弹抽屉**（见 NYVC-2736） |
| 工作台卡片数字               | **今日到货**条数，与概览「今日到货」一致                              |

---

## 三、到货概览

| 指标                    | 含义                                           |
| ----------------------- | ---------------------------------------------- |
| 已到货（近 7/15/30 天） | 关键件入库确认条数，随时段切换                 |
| 今日到货                | 当天入库确认条数，**不**随时段切换             |
| 预计待到                | 未关闭采购单中，关键件且仍有待入数量的明细行数 |
| 已逾期                  | 预计待到中，交货日早于今天且未到齐             |
| 今日到期                | 预计待到中，交货日为今天且未到齐               |

- 各指标标题旁提供问号提示说明含义。
- 概览区可折叠，偏好本地记忆。

---

## 四、已到货 Tab（NYVC-2737）

**数据源**：关键件入库确认消息（`keyPartArrivalStore`，由入库确认写入）。

**筛选**

- 到货时段：近 7 / 15 / 30 天（默认 7）
- 关键词：供应商 / 单号 / 仓库
- 物料编码、名称、规格型号

**列表列**

- 状态、关键件、到货数量、**库存数量**、单位、仓库、供应商
- 入库单号（跳转入库单详情）
- 来源采购单号（跳转采购单详情）
- 到货时间、操作

**操作「去领料」**

- 打开领料申请，预填关键件信息
- 默认工单领料；跨领料模式切换时**保留**到货跟踪带入的关键件行
- 命中 EBOM 时尽量带单位用量

**提示**：超出所选时段的到货记录不再出现在本列表。

---

## 五、预计到货 Tab（NYVC-2737）

**数据源**：未关闭采购订单中，关键件且待入数量 > 0 的明细行。

**状态**

| 状态     | 条件                   |
| -------- | ---------------------- |
| 待到货   | 交货日晚于今天且未到齐 |
| 今日到期 | 交货日为今天且未到齐   |
| 已逾期   | 交货日早于今天且未到齐 |

**能力**

- 筛选：状态、仅逾期、关键词、物料编码/名称/规格
- 展示进度：已入 / 待入 / 采购数量
- 预计到货日、采购订单号可跳转

---

## 六、入库确认通知与工作台（NYVC-2736）

1. **入库确认**时，对本次确认明细中标记为关键件的行写入到货消息（防重复：同入库单+行）。
2. 同步站内消息类型 `KEY_PART_ARRIVED`（消息中心可查）。
3. 工作台：
   - 卡片数字 = 今日到货条数
   - 点击进入到货跟踪「已到货」Tab（不再以抽屉作为主路径）
4. 支持已读 / 全部已读（历史抽屉能力可保留作兜底，主路径以页面为准）。

---

## 七、验收标准

- [ ] 菜单/路由：生产管理 → 到货跟踪
- [ ] 工作台「关键件到货」数字与概览「今日到货」一致，点击进入本页已到货 Tab
- [ ] 概览五类指标取值与问号提示正确；时段切换只影响「已到货」计数，不影响「今日到货」
- [ ] 已到货列表含库存数量；入库单/来源采购单号可正确跳转
- [ ] 预计到货展示未到齐关键件采购明细及待到货/今日到期/已逾期
- [ ] 「去领料」可预填关键件并进入领料申请，切换模式不丢关键件行
- [ ] 入库确认关键件后产生到货消息且工作台今日计数增加

---

## 八、非目标（本期可不做）

- 非关键件物料纳入到货跟踪
- 到货跟踪独立审批流 / 打印套打
- 小程序端到货跟踪
