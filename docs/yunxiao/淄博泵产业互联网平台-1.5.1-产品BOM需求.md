## BOM-151-01 BOM 版本管理与状态流转

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现

**背景**  
泵类产品 BOM 需版本化管理，支撑生产计划、工单投料与 EBOM 快照；同一物品仅允许一个生效版本。

**功能描述**

1. 版本号格式 V{年}.{次版本}，如 V2026.1；保存升版时自动归档旧生效版。
2. 状态：待发布 → 审核发布 → 生效 → 已归档。
3. 同物品仅一条生效 BOM；审核发布时自动归档原生效版本。
4. 历史版本 Tab、版本抽屉、操作记录。

**业务规则**

- 待发布可编辑、删除、审核发布；生效可编辑升版、归档；已归档可克隆。
- 仅生效 BOM 可用于生产领料/工单引用。

**验收标准**

- [ ] 新建 BOM 保存后为待发布；编辑生效 BOM 保存产生新待发布版本并归档旧版。
- [ ] 审核发布后状态变为生效，同物品其他生效版自动归档。
- [ ] 版本号按年度次版本递增展示正确。

## BOM-151-15 子件 BOM 归档时处理母件引用

- **优先级**：P0
- **需求负责人**：邓利佳
- **验收负责人**：梁海曳
- **状态**：已实现
- **更新日期**：2026-08-17

**背景**  
母件 BOM 明细可通过 `childBomId` 等字段引用子件 BOM。子件升版发布时已有「是否同步升级父级引用」（BOM-151-13）。用户**主动归档**子件 BOM 时，原先只改子件状态，母件仍挂着失效引用，缺少明确处理。  
在制工单使用 **EBOM 快照**，对产品 BOM 的结构调整**不影响已下达在制**；本次联动仅影响产品主数据及后续按母件 BOM 使用的结构。

**范围说明**

| 场景                                           | 是否走本需求弹窗      |
| ---------------------------------------------- | --------------------- |
| 列表 / 详情 / 批量：用户主动点「归档」         | 是（有母件引用时）    |
| 审核发布导致同物品旧生效版自动归档（版本更替） | 否，仍仅走 BOM-151-13 |

**功能描述**

1. **触发**  
   用户主动归档某 BOM 前，反查仍引用该 BOM 版本的非归档母件（`findParentBomReferences`）。
   - 无引用：按原逻辑直接归档（详情页可保留确认框）。
   - 有引用：打开「归档后如何处理母件中的该子件？」弹窗，确认后再归档。

2. **弹窗内容**
   - 提示：已下达工单使用 EBOM 快照，本次调整**不会影响在制**。
   - 展示即将归档的子件名称、版本，以及受影响母件列表（母件产品、母件 BOM、版本、引用行数）。
   - **每个母件单独选择处理方式**（非「勾选后统一一种处理」）。
   - 处理方式默认均为：**不改变母件**。

3. **三种处理方式（按母件行）**

   | 处理方式                         | 用户语义                                   | 系统行为                                                                                                                                                |
   | -------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | **不改变母件**（默认）           | 只归档子件，该母件不动                     | 不改该母件明细；引用仍指向已归档子件版本                                                                                                                |
   | **仅保留该子件本级，移除其下级** | 母件还挂着这个子件这一层，但不再带下级结构 | 保留该行物料/产品本级字段；清空 `childBomId` / `childBom` / `childBomVersion` / `referencedItem*`；删除该引用节点下展开的下级树与明细；节点改为普通物料 |
   | **从母件中移除该子件（含本级）** | 母件里不再出现这个子件                     | 删除该引用明细行，并删除对应树节点及其下级结构                                                                                                          |

4. **确认归档**  
   一次确认可对多母件分别应用上述三种方式的任意组合，然后完成子件归档。  
   成功提示可汇总：移除几处、保留本级几处。

5. **批量归档**
   - 无母件引用的选中项：直接归档。
   - 有母件引用的选中项：逐条弹出本弹窗确认（队列处理）。

6. **演示数据**  
   提供名称含「归档演示」的子件 BOM 与至少 3 个母件 BOM（含引用及展开下级），便于验收三种处理组合。

**非目标**

- 不把子件 BOM 明细「打平」成多级物料写入母件（与「仅保留本级」区分）。
- 不提供「取消归档」。
- 不因产品 BOM 变更回写已下达工单 EBOM。

**验收标准**

1. 归档无母件引用的 BOM：不弹本窗，可正常归档。
2. 归档有母件引用的子件：弹出窗；每行默认为「不改变母件」。
3. 同一弹窗内可对甲/乙/丙分别选三种方式，确认后：
   - 选「移除含本级」的母件：对应子件行及下级消失；
   - 选「仅保留本级」的母件：仍有该子件一行，无 BOM 引用、无展开下级；
   - 选「不改变」的母件：结构与引用字段不变。
4. 子件状态变为「已归档」。
5. 文案明确不影响在制 EBOM。
6. 审核发布自动归档旧版：不出现本弹窗、不删母件行。
7. 列表、详情、批量归档入口行为一致（批量对有引用项逐条确认）。
